# MemuDB

Включите **Настройки → Модули → MemuDB** и откройте модуль из боковой панели. Он открывает локальные SQLite (`.sqlite`, `.sqlite3`, `.db`, `.db3`) и DuckDB (`.duckdb`). Создание нового файла в интерфейсе доступно для SQLite; DuckDB создаётся внешним инструментом и затем открывается здесь. Драйверов PostgreSQL, MySQL и удалённых серверов в этой версии нет.

## Открытие и данные

Нажмите **Открыть базу** и выберите файл в системном диалоге. **Создать базу** создаёт новый файл и не перезаписывает существующий. Можно держать до восьми баз; переключение находится сверху. При первом открытии доступно только чтение. Соединения принадлежат текущему профилю и модулю и закрываются после часа бездействия или завершения приложения.

Слева выберите таблицу или представление. Поиск фильтрует строки, заголовки сортируют, а нижняя панель переключает страницы. В **Структуре** видны столбцы, типы, первичные ключи, ограничения, индексы, внешние ключи и исходное определение SQL. Большие значения и результаты ограничиваются при просмотре; экспорт сохраняет полные значения в пределах лимита.

## SQL и изменения

Вкладка **SQL** принимает запрос и отдельные параметры JSON: `[1, "текст"]` для `?` или `{"id": 1}` для `:id`. **Выполнить чтение** и `Ctrl+Enter` выполняют одно выражение, которое не может писать данные. **План запроса** показывает `EXPLAIN QUERY PLAN`. Выполнение можно остановить; запросы также имеют ограничение времени.

Для записи сначала нажмите **Только чтение** и разрешите подготовку изменений. Затем используйте **Подготовить изменения**. SQL выполняется на отдельной временной копии. Окно показывает SQL, число затронутых строк, возвращённые данные и изменения структуры. Закрытие окна отменяет предложение.

**Перейти к подтверждению** вызывает отдельное подтверждение MemuAI. При согласии создаётся резервная копия в `.memudb-backups` рядом с исходной базой, затем запечатанная SQL-транзакция применяется целиком. Ошибка откатывает запись. Просмотр действует 10 минут; если база изменилась извне, его нужно подготовить заново. Подтверждение относится к SQL, а не к гарантированно одинаковым результатам недетерминированных выражений вроде `random()`.

Кнопки **Создать таблицу**, **Добавить строку** и **Изменить** тоже создают предложения. Для изменения или удаления строки нужен полный первичный ключ. Импорт CSV принимает заголовки, совпадающие со столбцами, до 500 строк и 1 МБ; `.tsv` использует табуляцию. В SQL доступны более сложные изменения, индексы и представления. Подключение других файлов через `ATTACH`, расширения, файловые функции и управление транзакциями из пользовательского SQL запрещены.

История и сохранённые SQL-запросы хранятся локально в данных модуля. Они могут содержать значения, которые вы написали непосредственно в SQL. Результаты таблиц и учётные данные в историю не добавляются.

## Помощник ИИ

Выберите текстовую модель и опишите задачу: составить запрос, объяснить структуру, найти ошибку или подготовить миграцию. По нажатию **Спросить ИИ** модели передаются вопрос и структура открытой базы. Строки не передаются, пока вы явно не включите **Передать модели до 10 строк выбранной таблицы**. Применяются обычные условия выбранного провайдера.

Ответ ИИ не запускает SQL. Кнопка **Открыть предложение в SQL** переносит его в редактор. Чтение запускаете вы; запись проходит через ту же подготовку и подтверждение. Команда модуля из общего чата также только открывает предложение.

## Экспорт и резервные копии

Экспортируйте выбранную таблицу в CSV или JSON либо всю базу в SQL. CSV защищает значения, похожие на формулы электронных таблиц. Экспорт ограничен 32 МБ и 100 000 строк для таблицы. Бинарные данные JSON сохраняются в Base64. **Резервная копия** создаёт полноценный SQLite-файл рядом с базой; автоматическая копия также создаётся перед каждой записью. Восстанавливайте копию после закрытия соединения с исходной базой.

## DuckDB

Для DuckDB доступны таблицы и представления схемы `main`, SQL с позиционными параметрами `?`, создание таблиц, редактирование по первичному ключу, импорт CSV и подтверждённые изменения. Предпросмотр выполняется на временной копии; перед применением создаётся полная копия файла. Исходная база открыта только для чтения. Перед подготовкой изменений завершите запись во внешней программе и выполните в ней `CHECKPOINT`: непустой WAL не копируется и изменения с ним не применяются. Подключение внешних файлов, сеть, расширения и секреты через SQL отключены.

Экспорт DuckDB доступен в CSV/JSON до 100000 строк и 32 МБ; значения не сокращаются как при просмотре, больший результат отклоняется явно. Для полной копии используйте резервное копирование файла. Экспорт SQL доступен для SQLite. Индексы, связи и исходные определения в текущем обзоре структуры DuckDB пока не выводятся.

Помощник открывается рядом с данными. Он учитывает до трёх последних пар реплик текущего диалога; «Новый диалог», смена базы или переключение отправки примеров очищают контекст. Диалог не сохраняется между открытиями модуля. SQL по-прежнему сначала переносится в редактор как предложение и сам не выполняется.
