# Поиск везде

++Ctrl+K++ (или **Меню → Вид → Поиск везде**) открывает окно поиска поверх MemuAI. Результаты появляются, пока вы печатаете: индекс хранится на вашем компьютере и обновляется сам, когда меняются чаты, память или проекты, поэтому даже тысячи чатов ищутся без задержки. Ничего не отправляется в интернет. ++Ctrl+K++ работает и поверх открытых окон (настройки, память, экспорт): поиск откроется над ними, ++Esc++ вернёт к окну, а выбор чата или файла закроет его.

![Окно «Поиск везде»](docs-img/ru/search.webp "Один запрос — чаты, документация, память и другие разделы; справа — просмотр найденного")

Поле над списком чатов по-прежнему просто фильтрует список. Нажмите в нём ++Enter++ — тот же запрос откроется в поиске везде.

## Где ищет

| Раздел | Что находится |
| --- | --- |
| Чаты, Work, MemuCode | названия и текст сообщений, в том числе чаты из Telegram |
| Проекты и файлы | сохранённые Work-проекты, имена и текст файлов в них |
| Память | факты, которые MemuAI помнит о вас |
| Промпты и скиллы | системные промпты и библиотека скиллов ИИ |
| Планирование | задачи по расписанию |
| Панели и модули | панели главного экрана и установленные модули |
| Быстрый доступ | история вопросов окна ++Alt+Space++ |
| Настройки | разделы и отдельные строки настроек |
| Команды | действия приложения: новый чат, тема, режим фокуса… |
| Документация | статьи этой справки |

Строки настроек становятся доступны в поиске после первого открытия настроек — до этого находятся их разделы.

## Как писать запрос

Можно ошибаться: поиск понимает формы слов («чаты» найдёт «чат»), ё и е, опечатки в одну-две буквы и неправильную раскладку — «ghbdtn» найдёт «привет». Последнее слово ищется как начало слова, поэтому результаты видны уже после первых букв.

| Запрос | Что делает |
| --- | --- |
| `"точная фраза"` | слова именно в таком порядке |
| `-слово` | исключить результаты с этим словом |
| `in:work`, `in:code`, `in:telegram`, `in:docs`, `in:memory`, `in:files` | искать в одном разделе |
| `from:me`, `from:ai`, `from:deepseek` | только ваши сообщения, ответы ИИ или ответы одной модели |
| `model:claude` | ответы этой модели |
| `folder:Работа`, `project:сайт` | чаты из папки или проекта |
| `is:pinned` | только закреплённые чаты |
| `date:today`, `date:week`, `date:month`, `date:year` | за период |
| `after:2026-09-01`, `before:2026-10-01`, `date:2026-05..2026-06` | до или после даты, или диапазон |

Операторы можно писать без слов: `is:pinned` покажет все закреплённые чаты, новые сверху.

## Фильтры и разделы

Кнопки-разделы под полем сужают поиск (++Tab++ и ++Shift+Tab++ переключают их, ++Alt+1++…++Alt+9++ выбирают по номеру). **Фильтры** задают период, автора сообщения, модель, папку и закрепление; активные фильтры видны под полем, ++Backspace++ в пустом поле убирает последний.

## Результаты и просмотр

Результаты сгруппированы по разделам, совпадения подсвечены. У чата видны самые подходящие сообщения — на каждое можно перейти отдельно. Справа — просмотр: соседние сообщения, строки файла или раздел статьи.

| Клавиши | Действие |
| --- | --- |
| ++↑++ ++↓++ | выбрать результат |
| ++Enter++ | открыть |
| ++Ctrl+Enter++ | дополнительное действие: скопировать текст или показать файл в папке |
| ++Ctrl+P++ | скрыть или показать просмотр |
| ++Esc++ | очистить запрос, второй раз — закрыть |

Чат открывается на найденном сообщении: оно подсвечивается, слова выделены, а сверху появляется панель «найдено в этом чате» со стрелками (++F3++ и ++Shift+F3++) для перехода между совпадениями. Файл проекта открывается в MemuCode на нужной строке, настройка — на своей странице с подсвеченной строкой, статья — на нужном разделе.

## Недавние запросы и параметры

Пустое окно показывает недавние запросы, последние чаты и быстрые действия. Кнопка **⋯** внизу окна:

- **Запоминать недавние запросы** — выключите, и история запросов не сохраняется.
- **Искать в файлах Work-проектов** — текст файлов индексируется с ограничениями: не больше нескольких тысяч файлов на проект, большие и двоичные файлы — только по имени, служебные папки (`node_modules`, `.git` и подобные) пропускаются.
- **Перестроить индекс** — собрать индекс заново, если что-то не находится.

## Для модулей и Mini App

Модули могут добавить свои источники: на стороне окна — `MemuSearch.registerProvider(...)`, на стороне сервера — `register_provider(...)` из `app/search_index.py`. Telegram [Mini App](doc:telegram-miniapp) пользуется тем же индексом без файлов проектов и модулей: поле поиска в списке чатов находит сообщения по словоформам и с опечатками, а ниже показывает совпадения в памяти, промптах, задачах, персонажах, панелях и документации.
