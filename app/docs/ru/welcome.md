# Добро пожаловать в MemuAI

MemuAI — настольное приложение для Windows, в котором собраны модели всех ваших ИИ-аккаунтов: Claude, GPT, Gemini, Grok и других, а также модели, которые работают прямо на компьютере. Общение с ними, работа с файлами проекта, картинки, голос, память и расписания — в одном окне.

![Главное окно MemuAI](docs-img/ru/home.webp "Новый чат: подсказки для начала, поле ввода и панели на главной")

## Две программы

| Программа | Что делает |
| --- | --- |
| **MemuAI** | окно чата: диалоги, Work, MemuCode, модули, настройки |
| **MemuAI Proxy** | фоновое ядро в трее: хранит аккаунты, выбирает модель и аккаунт, раздаёт API для других программ |

Проще всего думать так: Proxy — двигатель с аккаунтами, MemuAI — кабина, из которой вы им управляете. MemuAI запускает Proxy сам; настраивать его нужно один раз, когда добавляете аккаунты. Подробно — [MemuAI Proxy](doc:proxy).

## Как пользоваться документацией

- Поиск — поле вверху слева или клавиша ++/++. Стрелки выбирают результат, ++Enter++ открывает.
- ++Alt+←++ и ++Alt+→++ — назад и вперёд по прочитанным страницам.
- Оглавление страницы — справа; текущий раздел подсвечивается при прокрутке.
- Любой текст можно выделить и скопировать. Правый щелчок по тексту даёт меню: скопировать, найти выделенное в документации, спросить MemuAI, скопировать ссылку на раздел.
- Меню ⋯ в шапке страницы копирует ссылку или Markdown страницы и сохраняет её файлом.

> [!TIP]
> Не нашли ответ? Выделите непонятное место и выберите в меню **Спросить MemuAI об этом** — вопрос с цитатой появится в поле ввода.

## Данные и приватность

Чаты, настройки, память и аккаунты хранятся на вашем компьютере в `%APPDATA%\MemuAI`. Сообщения уходят только тому сервису, чья модель выбрана, а локальные модели не отправляют ничего никуда. Подробно — [Где хранятся данные](doc:data).
