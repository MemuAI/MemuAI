# Контекст

**Окно контекста** — сколько текста модель видит за один раз: системные инструкции, историю разговора, вложения и ваш новый вопрос. Оно измеряется в токенах — это кусочки слов; в русском тексте один токен примерно равен 3–4 символам, в английском — 4–5.

Когда разговор перерастает окно, модель перестаёт видеть его начало или сервис отвечает ошибкой. MemuAI следит за этим сам.

## Счётчик контекста

Индикатор в верхней полосе показывает, какая часть окна текущей модели уже занята. Наведите курсор — появится разбивка: текст, изображения и итог, а также откуда взято число.

Счётчик учитывает всё, что действительно уходит модели:

- сообщения разговора (после сжатия — его краткое изложение вместо старых сообщений);
- системный промпт: инструкции MemuAI, ваши инструкции, скиллы, инструменты;
- изображения — по их размеру в пикселях и по тому, как их считает семейство модели (у Claude, Gemini и GPT разные правила);
- видео — те кадры и расшифровку речи, которые реально передаются;
- результаты инструментов, которые ещё нужны для ответа.

**Откуда число.** Если провайдер сообщает собственный счёт токенов (свои API, Antigravity), счётчик берёт его за последний запрос и добавляет оценку того, что появилось после. Если не сообщает — показывает оценку MemuAI по тексту. В подсказке это написано прямо.

Щелчок по счётчику переключает, учитывать ли изображения, — полезно, если модель обрабатывает их отдельно и оценка мешает.

## Автоматическая оптимизация

**Настройки → Чат и ответы → Длинные чаты → Сжимать историю автоматически** включена по умолчанию и делает две вещи:

1. **Сжимает историю.** Когда разговор заполняет заданную долю окна, старые сообщения фоном превращаются в структурированное резюме: решения, факты, договорённости, открытые вопросы. Последние сообщения остаются дословно.
2. **Отбирает код.** В Work и MemuCode модель получает не весь проект, а только релевантные файлы и фрагменты.

| Настройка | По умолчанию | Смысл |
| --- | --- | --- |
| Сжимать при | 90 % | доля окна, после которой начинается сжатие |
| Последних сообщений без сжатия | 20 | сколько свежих сообщений всегда идёт дословно |

> [!IMPORTANT]
> Сжатие не удаляет историю. Весь разговор хранится на диске и виден в чате полностью; сжатое резюме уходит только модели. Если изменить или удалить сообщение внутри уже сжатой части, резюме пересоздаётся.

## Как определяется окно

Размер окна каждой модели MemuAI находит сам. Откуда взято число, видно в подсказке счётчика («Окно модели: …») и в **Настройки → Чат и ответы → Окно контекста по моделям** («Определено: …»):

| Источник | Когда |
| --- | --- |
| задано вручную | вы указали своё значение для этой модели |
| настройка запуска llama.cpp | локальная модель — берётся контекст из её настроек |
| сообщил провайдер | провайдер прислал размер окна в списке моделей |
| известная модель | модель найдена в каталоге известных моделей; имена вроде `prefix-claude-opus-5.5` и `claude-opus-5-5` считаются одной моделью |
| оценка по семейству моделей | точной записи нет, но семейство известно |
| по умолчанию — не определено | ничего не подошло — используется значение «Если окно определить не удалось» |

## Лимит по моделям

Сервисы не всегда честно сообщают размер окна. В **Окно контекста по моделям** можно поправить автоматическое значение:

- **Своё значение (токенов)** для выбранной модели — главнее автоматического; «Вернуть автоматическое» его убирает;
- **Если окно определить не удалось** — 128 000 токенов, используется только для моделей с неизвестным окном.

Примеры: `260000` для модели примерно на 258 тысяч токенов, `1000000` — для модели на миллион. Сжатие начнётся раньше этого потолка.

## Как сэкономить контекст

- Начинайте новый чат для новой темы — история прошлой темы не нужна модели.
- Крупные файлы прикладывайте, только когда они нужны; в Work модель найдёт нужное сама.
- Для длинных документов выбирайте модели с большим окном.
- Кэширование промптов (**Настройки → Модели**) снижает стоимость повторяющихся инструкций у сервисов, которые это поддерживают.
