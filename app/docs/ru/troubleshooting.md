# Решение проблем

Сначала — два универсальных шага:

1. **Посмотрите журнал.** Proxy → **Логи**: у каждого запроса видна причина ошибки. Кнопка **Разобрать** рядом с ошибкой открывает [ИИ-помощника](doc:proxy-companion), который объяснит её простыми словами.
2. **Перезапустите службы.** Proxy → **Главная → Перезапустить службы** пересоздаёт соединения, не закрывая программу. Это лечит большинство «зависаний» после сна ноутбука или смены сети.

## MemuAI не отвечает

| Симптом | Причина | Что делать |
| --- | --- | --- |
| «MemuAI Proxy не запущен» внизу боковой панели | Proxy выключен или не запустился | нажмите «Запустить» рядом с состоянием или откройте MemuAI Proxy из меню «Пуск» |
| Список моделей пуст | нет аккаунтов или все модели выключены | добавьте аккаунт — см. [Аккаунты](doc:accounts) |
| Ответ не начинается долго, потом ошибка | провайдер молчит | проверьте журнал; Proxy сам переходит к другому аккаунту после таймаута первого байта |
| Ответ обрывается на середине | тишина стрима превысила предел или сервис оборвал соединение | повторите; при частых обрывах увеличьте «Таймаут тишины стрима» в настройках Proxy |
| «Модель не найдена» | модель выключена в каталоге или удалена у провайдера | обновите каталог: Proxy → Каталог моделей (панель слева) → Обновить с серверов |

## Аккаунт перестал работать

| Код в журнале | Значит | Что делать |
| --- | --- | --- |
| 401, 403 | кука или токен больше не действуют | войдите на сайт сервиса заново и обновите куку в карточке аккаунта |
| 403 и слово captcha | сервис требует проверку браузера | откройте сайт в браузере, пройдите проверку, обновите куку |
| 429 | исчерпан лимит | подождите или добавьте второй аккаунт — Proxy будет переключаться сам |
| 502 и непонятная ошибка у одного провайдера | сервис изменил свой протокол | проверьте обновление MemuAI; неофициальные протоколы иногда ломаются, и исправление выходит в новой версии |

Подробно о каждом сервисе — [Аккаунты и провайдеры](doc:accounts).

## Изображения

- **Модель «не видит» картинку.** Модель без зрения или сервис молча отбрасывает вложения. Выберите **Скрытое распознавание** в **Настройки → Изображения и видео → Отправка изображений** — см. [Модели](doc:models).
- **Генерация вернула ошибку про проверку.** Сервис хочет капчу — пройдите её на сайте и обновите куку.
- **Файл не скачивается.** Скачанное сохраняется в `Загрузки\MemuAI`; кнопка «Показать в папке» откроет его.

## Голос

- **Кнопка микрофона неактивна** — выбранная модель распознавания ещё не скачана или не задан адрес API. Откройте **Настройки → Голос и Live**.
- **Windows не даёт микрофон** — Параметры Windows → Конфиденциальность → Микрофон → разрешите доступ классическим приложениям.
- **Озвучка молчит** — проверьте, что в Windows установлен голос нужного языка, или выберите другой источник голоса.

## Work и MemuCode

- **Модель не видит файл** — он вне папки проекта или в служебной папке (`node_modules`, `.git`, сборки). Упомяните его через `@путь`.
- **Изменения не применяются** — режим «С подтверждением» ждёт вашего подтверждения: подтвердите изменение под ответом или переключитесь на «Полный доступ».
- **Команда в терминале отклонена** — в режиме Ask разрешены только команды чтения; опасные команды запрещены всегда.
- **Нужно вернуть файлы** — MemuCode → правая панель → **Откат**.

## Программа не запускается

- **Окно с путём к `startup-error.log`** — откройте этот файл в `%APPDATA%\MemuAI\memuai\`: в нём причина.
- **Белое окно** — переустановите «Microsoft Edge WebView2 Runtime».
- **Порт 8317 занят** — измените порт Proxy в **Настройки → Дополнительно → Сервер и API**.
- **После сбоя «пропали» настройки** — MemuAI восстанавливает повреждённые файлы из резервных копий автоматически; если не помогло, копии лежат в `%APPDATA%\MemuAI\backups`.

## Интерфейс

- **Что-то отображается странно** — ++Ctrl+R++ перезагружает интерфейс без потери данных.
- **Нечитаемые цвета после своей темы** — выберите встроенный вариант в **Настройки → Внешний вид**.
- **Значок MemuAI на панели задач стал белым листом** — в 3.5 причины этого исправлены, а ярлыки, указывающие на потерянный файл значка, MemuAI чинит сам при запуске. Если старый значок остался в кэше Windows после обновления, открепите MemuAI от панели задач и закрепите заново (или перезапустите «Проводник» в диспетчере задач).
- **Модуль открывается пустым** — откройте его мастерскую: ошибки кода показываются там. См. [Модули: решение проблем](doc:modules-troubleshooting).

## Если ничего не помогло

Соберите сведения для отчёта: текст ошибки из журнала Proxy (кнопка копирования записи), вкладку **Журнал сервера** и, при сбое запуска, `startup-error.log`. Куки и ключи в эти журналы не попадают, их можно пересылать.
