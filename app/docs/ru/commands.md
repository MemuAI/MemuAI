# Команды и упоминания

Команда начинается с ++/++ в начале сообщения. Как только вы нажмёте ++/++, появится список; дальше можно печатать название — список сузится. Выбор — стрелками и ++Enter++, ++Tab++ или щелчком. Команды с аргументом подставляются в поле, остальные выполняются сразу.

Если вы забыли команду, наберите `/help` — список откроется заново.

## Разговор

| Команда | Что делает | Пример |
| --- | --- | --- |
| `/new` | новый чат | |
| `/temp` | временный чат, без сохранения | |
| `/retry` | повторить последний ответ текущей моделью | |
| `/stop` | остановить генерацию | |
| `/export` | скачать текущий чат | |
| `/clear` | удалить текущий чат и открыть пустой | |
| `/system <текст>` | инструкция только для этого чата; без текста — сбросить | `/system отвечай кратко, по пунктам` |

## Модель

| Команда | Что делает | Пример |
| --- | --- | --- |
| `/model <часть имени>` | переключиться на первую модель, в названии которой есть этот текст | `/model sonnet` |
| `/models` | вывести список всех моделей | |
| `/search on` / `/search off` | веб-поиск в этом чате | `/search on` |
| `/think on` / `/think off` | размышления в этом чате | `/think off` |

## Изображения, память, расписание

| Команда | Что делает | Пример |
| --- | --- | --- |
| `/image <описание>` (или `/img`) | нарисовать картинку | `/image маяк в тумане, акварель` |
| `/research [тема]` | включить [глубокое исследование](doc:research); с темой — сразу начать; `off` — выключить | `/research рынок электросамокатов в Европе` |
| `/visual [запрос]` | ответ с графиком, схемой или интерактивной моделью; `off` — выключить | `/visual как менялась ставка ЦБ` |
| `/dfy <задача>` | передать задачу агенту [Do For You](doc:dfy): он сделает её сам в своём браузере | `/dfy забронируй столик на двоих на пятницу` |
| `/tools` | открыть меню ＋ | |
| `/memory <факт>` | добавить факт в [память](doc:memory) | `/memory я пишу на Python и Go` |
| `/schedule Имя \| промпт \| каждые N мин` | создать [задачу по расписанию](doc:schedules) | `/schedule Курс \| Курс доллара и евро \| каждые 60 мин` |

## Режимы и переходы

| Команда | Что открывает |
| --- | --- |
| `/chat` | обычный чат |
| `/work` | [Work](doc:work) — работа с папкой проекта |
| `/code` | [MemuCode](doc:memucode) |
| `/planning` | список задач по расписанию |
| `/agents` | Work и MemuCode: разрешить параллельных агентов в этом чате |
| `/profile` | профиль и память |
| `/settings` | настройки |
| `/lang ru` / `/lang en` | язык интерфейса |
| `/theme dark` / `/theme light` | тёмное или светлое оформление |

## Work и MemuCode

| Команда | Что делает |
| --- | --- |
| `/access ask` / `/access full` | режим доступа: подтверждать каждое изменение или применять сразу |
| `/plan <задача>` | сначала составить план и выполнять его по шагам |
| `/goal <цель>` | работать, пока цель не достигнута; `/goal off` — остановить |

В MemuCode есть ещё свои команды — `/review`, `/test`, `/fix`, `/explain`, `/refactor`, `/commit`, `/diff`, `/undo`, `/mcp`. Они описаны на странице [MemuCode](doc:memucode).

## Упоминания

++@++ открывает второй список — подсказки для модели. Упоминание не запускает инструмент принудительно: оно говорит модели, что вы хотите, а решение и все ограничения безопасности остаются за ней.

| Упоминание | Что подсказывает |
| --- | --- |
| `@Web` | проверить актуальные сведения в интернете |
| `@Browser` | рассмотреть работу в браузере — см. [Browser и Computer Use](doc:browser-computer) |
| `@Computer` | рассмотреть управление компьютером |
| `@Plan` | сначала составить строгий проверяемый план |
| `@Goal` | продолжать работу до достижения цели |

`@Browser`, `@Computer`, `@Plan` и `@Goal` работают в режимах Work и MemuCode; в обычном чате доступен только `@Web`.

### Файлы проекта

В Work и MemuCode в том же списке — файлы и папки проекта. Выберите файл, и в сообщение подставится ссылка на него:

```
Посмотри @index.html и перенеси стили в @src/styles/main.css
```

Имена с пробелами записываются в скобках: `@(docs/Заметки встречи.md)`. Упоминание указывает модели на конкретный файл: она прочитает его, прежде чем что-то в нём менять. Если указано только имя без пути (`@app.js`), модель сама найдёт файл с таким именем в проекте. В тексте сообщения упоминания выделяются, а внутри блоков кода остаются обычным текстом.

См. также: [Поле ввода](doc:composer), [Горячие клавиши](doc:shortcuts).
