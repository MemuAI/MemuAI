# Глоссарий

## А–Я

**Агенты** — помощники, которые в Work и MemuCode параллельно делают части задачи, пока основная модель занимается своей; запускаются только по вашей просьбе. См. [Агенты и мемесы](doc:agents).

**Аккаунт** — одно подключение к сервису моделей в MemuAI Proxy: кука, вход через браузер или ключ. См. [Аккаунты](doc:accounts).

**Акцент** — цвет кнопок, ссылок и активных элементов интерфейса. См. [Внешний вид](doc:appearance).

**Артефакт** — страница, схема или заметка, которую агент MemuCode создаёт отдельно от проекта. См. [MemuCode](doc:memucode).

**Вариант темы** — готовая палитра одного из режимов: Норд, Мокко, Бумага и другие. См. [Внешний вид](doc:appearance).

**Временный чат** — разговор, который MemuAI не сохраняет и в котором модель не видит память. См. [Чаты](doc:chats).

**Галлюцинация** — уверенный, но выдуманный ответ модели. Снижается веб-поиском и просьбой ссылаться на источники.

**Движок (llama.cpp)** — программа, которая запускает локальные модели. См. [Локальные модели](doc:local-models).

**Детектор моделей** — вкладка Proxy, которая оценивает, какая модель на самом деле отвечает. См. [Детектор моделей](doc:model-detector).

**Квантизация** — сжатие весов модели ради меньшего размера: `Q4_K_M`, `Q8_0` и т. п. Чем меньше число, тем легче модель и ниже качество.

**Компаньон** — анимированный персонаж MemuAI Live и «Быстрого доступа», который говорит голосом ответа. См. [Компаньон](doc:companion).

**Кука (cookie)** — строка, по которой сайт узнаёт, что вы вошли. Через неё Proxy работает с веб-версиями сервисов.

**Мемес** — ваш ассистент со своим именем, инструкциями и чатами. См. [Агенты и мемесы](doc:agents).

**Модуль** — своё приложение внутри MemuAI на HTML, CSS и JavaScript. См. [Модули](doc:modules).

**Окно контекста** — сколько текста модель видит за один раз. См. [Контекст](doc:context).

**Откат** — возврат файлов, изменённых сессией MemuCode, к исходному состоянию.

**Песочница** — ограниченная среда, в которой MemuCode выполняет команды проекта.

**Префикс** — начало имени модели, обозначающее сервис: `genspark-`, `kiro-`, `local-`.

**Провайдер** — сервис, через который приходят модели: Genspark, Kiro, Antigravity и другие.

**Проектор (mmproj)** — дополнительный файл, который позволяет локальной модели видеть изображения.

**Профиль** — отдельный набор чатов, памяти и задач. См. [Профили](doc:profiles).

**Размышления (reasoning)** — рассуждение модели перед ответом; показывается свёрнутым блоком.

**Системный промпт** — инструкция, которая задаёт поведение модели на весь разговор.

**Скилл** — готовая инструкция для типовой работы, которую модель подключает сама.

**Сжатие контекста** — замена старых сообщений структурированным резюме, когда разговор приближается к пределу окна.

**Токен** — единица текста для модели, примерно часть слова. По токенам считаются лимиты и стоимость.

**Токен доступа** — секретная строка для входа в сервис. Не путать с токеном текста.

**Упоминание** — `@Web`, `@Browser`, `@файл` в сообщении: подсказка модели. См. [Команды](doc:commands).

## A–Z

**API** — способ, которым программы обращаются друг к другу. Proxy раздаёт API в формате OpenAI. См. [API Proxy](doc:proxy-api).

**Computer Use** — навык, с которым модель управляет мышью и клавиатурой. См. [Browser и Computer Use](doc:browser-computer).

**DFY (Do For You)** — агент, который сам выполняет дела в своём браузере: бронирует, заказывает, заполняет формы, спрашивая подтверждение перед необратимыми шагами. См. [Do For You](doc:dfy).

**GGUF** — формат файлов локальных моделей для llama.cpp.

**Goal** — режим Work, в котором модель работает до достижения цели. См. [Work](doc:work).

**Hugging Face** — крупнейший каталог открытых моделей; оттуда скачиваются локальные модели.

**Live2D** — технология «оживлённых» 2D-рисунков: персонаж нарисован по частям и двигается параметрами. Модель — папка с `*.model3.json`, `.moc3` и текстурами. См. [Свои модели персонажа](doc:live2d-models).

**MCP (Model Context Protocol)** — протокол подключения внешних инструментов к агенту MemuCode.

**MemuAI Live** — голосовой разговор с моделью. См. [Голос](doc:voice).

**Plan** — режим Work, в котором модель сначала составляет проверяемый план.

**SSE** — способ передавать ответ по частям, пока модель его пишет.

**Token (Hugging Face, GitHub)** — ключ доступа к вашему аккаунту в сервисе; хранится только на компьютере.

**VRAM** — память видеокарты. Модель, целиком помещающаяся в VRAM, работает быстрее всего.

**VRM** — формат 3D-персонажей (один файл `.vrm`), например из VRoid Studio. См. [Свои модели персонажа](doc:live2d-models).

**Whisper** — семейство моделей распознавания речи, которое MemuAI запускает локально.

**Work** — режим работы с файлами выбранной папки. См. [Work](doc:work).
