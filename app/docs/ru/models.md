# Модели

В списке моделей MemuAI — все включённые модели всех ваших аккаунтов в MemuAI Proxy. Модель выбирается для каждого чата отдельно, и её можно сменить посреди разговора.

## Выбор модели

Кнопка с названием модели в верхней полосе (++Ctrl+M++) открывает список. Вверху — поле поиска: печатайте часть названия, совпадения подсвечиваются, стрелки ++↑++ ++↓++ и ++Enter++ выбирают.

Каждая модель показана **понятным названием**, а под ним мелким шрифтом — полный идентификатор: «Claude Opus 4.6 Thinking» и `aws9-claude-opus-4.6-thinking`. Название MemuAI составляет сам и для новых моделей: убирает префикс подключения (`aws9-`, `openai/`), приводит версию к виду `4.6`, пишет марки как принято (GPT, GLM, Qwen, DeepSeek), дату снимка показывает отдельно, а `:free` — значком **free**. Своё название (см. «Переименовать») всегда главнее. Одна и та же модель может быть доступна через разные сервисы — это разные строки, сгруппированные по подключениям.

Список один и тот же везде, где выбирается модель — в чате, в настройках, в карточке ошибки генерации: поиск по названию, идентификатору и аккаунту, фильтры **Со зрением**, **Рассуждают**, **Бесплатные**, **Генерация**, разделы «Закреплённые» и «Недавние». Значки справа: глаз — зрение (см. ниже), мозг — рассуждения, ключ — инструменты, «Картинки»/«Видео» — модели генерации. Модели, выключенные в MemuAI Proxy, не показываются нигде.

Список обновляется сам после добавления аккаунта в Proxy и при возвращении в окно MemuAI.

Те же понятные названия (и ваши переименования) видны во всех остальных окнах, а полный идентификатор — рядом, приглушённым моноширинным шрифтом: в [быстром доступе](doc:quick-ask) (++Alt+M++, поиск и по названию, и по идентификатору), в боте и мини-приложении [Telegram](doc:telegram), в `/model` [MemuCode](doc:memucode-cli), в MemuNote, а также в каталоге моделей и карточке модели в [MemuAI Proxy](doc:proxy).

## Меню модели

Правый щелчок по модели в списке:

| Действие | Что делает |
| --- | --- |
| Закрепить / Открепить | закреплённые модели всегда наверху списка |
| Сделать основной | эта модель будет выбираться в новых чатах |
| Переименовать | своё название вместо технического; двойной щелчок по кнопке модели делает то же |
| Зрение: … | указать вручную, видит ли модель изображения, или проверить её (см. ниже) |
| Скрыть из списка | модель пропадает из списка; вернуть её можно в **Настройки → Модели** |

Своё название видно только в MemuAI; в запросах к сервису по-прежнему используется настоящее имя.

**Автоматическое закрепление** (Настройки → Модели) держит наверху по одной основной чат-модели каждого подключённого сервиса. Если открепить такую модель вручную, MemuAI это запомнит и не закрепит её снова.

## Возможности модели

Не все модели умеют одно и то же. Переключатели в верхней полосе появляются, только если текущая модель это поддерживает:

| Возможность | Как видно | Подробнее |
| --- | --- | --- |
| Веб-поиск | переключатель поиска | [Веб-поиск](doc:web-search) |
| Размышления | переключатель размышлений и выбор глубины | ниже |
| Зрение | модель принимает изображения | [Изображения](doc:images) |
| Генерация изображений и видео | модели рисования отмечены в списке | [Картинки и видео в чате](doc:media) |

## Размышления

Модели с рассуждением (Claude, GPT-5 и новее, Gemini 3, DeepSeek, Qwen, GLM, Kimi и другие) могут «подумать» перед ответом. Глубина задаётся уровнем:

| Уровень | Когда подходит |
| --- | --- |
| Авто | модель решает сама — ничего не передаётся, работает умолчание провайдера; так по умолчанию |
| Выкл. | без размышлений — быстрее и дешевле (только если модель это позволяет) |
| Минимальный, Низкий | быстрые короткие ответы |
| Средний | обычные задачи |
| Высокий, Очень высокий, Максимальный | сложные рассуждения, код, математика; ответ дольше |

**У каждой модели — только её настоящие уровни.** Модели принимают разные наборы, и лишний уровень сервис отклоняет с ошибкой. Поэтому чип **Размышления** в поле ввода показывает ровно то, что умеет выбранная модель, а рядом с «Авто» — что модель делает сама («Авто · средний»). Примеры:

| Модель | Уровни в MemuAI |
| --- | --- |
| Gemini 3.7 / 3.8 Flash | Низкий, Средний, Высокий |
| Gemini 3.5 / 3.6 Flash | Минимальный, Низкий, Средний, Высокий |
| GPT-6.1 Sol | Низкий … Максимальный (без «Выкл.» и «Минимального») |
| GPT-5.2 и новее | Выкл., Низкий … Очень высокий |
| Claude Opus / Sonnet 4.6 | Выкл., Низкий, Средний, Высокий, Максимальный; у моделей «…-thinking» нет «Выкл.» |
| DeepSeek V3.1 / V4 | Выкл., Низкий, Высокий, Максимальный |
| GLM-5.x | Низкий, Высокий, Максимальный — выключить размышления нельзя |
| Qwen3, Kimi | Выкл. / Вкл. (или несколько уровней, если модель их поддерживает) |
| GPT-4o и другие модели без рассуждений | чипа нет |

Для незнакомой новой модели набор угадывается по её семейству; если модель прислала размышления, а уровней у неё не было, появляется общий набор «Низкий / Средний / Высокий». Если сервис всё же отклонил уровень, MemuAI повторяет запрос без него, запоминает отказ и больше этот уровень не показывает.

Сохранённый уровень, которого у новой модели нет, не теряется: модель получает **ближайший** из своих (например, «Минимальный» у Gemini 3.7 Flash становится «Низким»). Уровень меняется в чате чипом размышлений. Значения по умолчанию задаются в **Настройки → Модели**: **Глубина размышления** — общая (каждая модель получит ближайший свой уровень) и **Размышление по моделям** — свой уровень для отдельных моделей, у каждой только её варианты. Настройка в чате всегда главнее. Те же уровни видны в [Telegram](doc:telegram) (кнопки уровней на экране модели, чип в Mini App) и [MemuCode](doc:memucode-cli) (`/effort`).

**Ручная настройка.** Если сервис отдаёт модель с другими уровнями, чем ожидается, откройте её карточку в MemuAI Proxy (**Каталог моделей** → кнопка ⓘ) → раздел **Уровни размышлений**: там видно, что показывают клиенты, умолчание провайдера, откуда это известно и как уровень передаётся в API. **Настроить вручную** — отметить уровни, разрешить «Выкл.», выбрать способ передачи; **Вернуть автоматически** — снять ручную настройку; **Забыть отказы API** — снова предлагать уровни, которые сервис когда-то отклонил.

Рассуждения модели показываются свёрнутым блоком над ответом.

## Модель по умолчанию

**Настройки → Модели → Модель по умолчанию** — какая модель выбирается в новом чате. «Первая доступная» берёт первую модель списка.

## Изображения, видео и решения

В **Настройки → Модели → Изображения, видео и решения** выбираются модель для изображений, модель для видео (автоматически, «только по команде» или конкретная) и необязательная быстрая **модель решений**, которая определяет, ответить ли текстом, картинкой или видео. Там же — **Автопромпт**. Модель чата при этом остаётся прежней. Подробно — в разделе [Картинки и видео в чате](doc:media).

## Видит ли модель изображения

У каждой чат-модели один ответ на этот вопрос — он одинаков во всех окнах. Глаз рядом с названием (в списке и в верхней полосе):

| Значок | Значит | Подсказка при наведении говорит, откуда это известно |
| --- | --- | --- |
| Глаз (зелёный) | видит изображения | проверено запросом, указано вами, данные провайдера или семейство модели |
| Перечёркнутый глаз | не видит | например, «этот провайдер не передаёт изображения» |
| Глаз с вопросом | неизвестно | сведений нет — модель можно проверить |

Ответ берётся по порядку: ваша проверка → ваше указание → данные провайдера и каталога → семейство модели. Указать вручную можно в меню модели (**Зрение: …** → «Определять автоматически» / «Видит изображения» / «Не видит изображения») или в карточке модели в MemuAI Proxy — это одна и та же настройка. Кнопка **Проверить сейчас** отправляет модели одну маленькую картинку (тратит один запрос) и запоминает результат.

Если прикрепить картинку к модели, которая её не видит (или про которую это неизвестно), над полем ввода появится заметка с кнопками **Переключиться на …** и **Проверить модель**. А при отправке MemuAI предложит:

| Вариант | Что происходит |
| --- | --- |
| Переключиться на модель со зрением | MemuAI подбирает лучшую модель со зрением (можно выбрать другую); сообщение уходит ей вместе с картинкой, чат продолжается с ней |
| Описать изображение помощником | модель-помощник со зрением скрыто описывает картинку, текущая модель получает описание |
| Проверить модель сейчас | один настоящий запрос; если модель видит — сообщение сразу уходит напрямую |
| Отправить как есть | картинка уходит без изменений — модель может её проигнорировать |

Модель, которая видит изображения, получает картинку сразу, без вопросов. Кнопки «Распознать другой моделью / Убрать изображения» под ошибкой появляются, только если ошибка связана с картинкой — при обычном сбое сервиса там «Повторить».

## Как отправляются изображения

Некоторые сервисы молча игнорируют вложенные картинки. Поэтому в **Настройки → Изображения и видео → Отправка изображений** выбирается, как с ними поступать:

| Вариант | Что происходит |
| --- | --- |
| Спрашивать каждый раз | модели со зрением картинка уходит сразу; остальным — выбор из раздела выше |
| Напрямую | картинка уходит модели как есть |
| Скрытое распознавание | сначала «Модель для распознавания изображений» описывает каждую картинку, а модель чата получает это описание. Работает с любой моделью, но мелкие детали могут потеряться |

## Локальные модели

Модели с префиксом `local-` работают на вашем компьютере через [Локальные модели](doc:local-models) в Proxy. Первый ответ после выбора может занять до минуты: модель загружается в память.

## Модель в чате мемеса

У [мемеса](doc:agents) может быть закреплена своя модель. В его чатах сменить модель нельзя — на месте переключателя видна пометка о блокировке.
