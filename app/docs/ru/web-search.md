# Веб-поиск

Модели знают мир только до даты своего обучения. Веб-поиск даёт им свежие сведения: новости, курсы, документацию новых версий, расписания.

## Включение

Переключатель поиска в верхней полосе включает его для текущего чата. Команды `/search on` и `/search off` делают то же. Правый щелчок по переключателю выбирает источник поиска прямо из чата. Упоминание `@Web` в сообщении подсказывает модели проверить сведения в интернете именно для этого вопроса.

Включать поиск по умолчанию во всех новых чатах — **Настройки → Веб-поиск → Включать по умолчанию**. Переключатель в чате всё равно главнее.

Даже с включённым поиском модель сама решает, нужны ли запросу свежие источники: на «переведи этот абзац» она искать не станет.

## Как быстро ищет MemuAI

Дорого в поиске не сам запрос, а **раунды модели**: «найди» → «открой страницу» → «ответь», и у каждого раунда своя задержка (у подписочных моделей 5–10 секунд). Поэтому поиск устроен так, чтобы ответ приходил за один раунд:

- **Предпоиск.** Если сообщению *явно* нужны свежие данные — погода, курс, новости, цена, результат матча или прямая просьба «поищи» — поиск уходит ещё до первого запроса к модели, и она отвечает сразу, без раунда инструментов. «Привет», просьба переписать текст или вопрос про ваш код в сети не ищутся; при сомнении ничего не происходит, и модель вызывает поиск сама, как раньше. Найденные источники видны в шаге «Веб-поиск».
- **Один вызов — всё нужное.** Результат содержит готовый ответ (`answer`), выдачу и **выдержки** самых подходящих мест первых страниц: страницы читаются одновременно, не дольше пяти секунд, платные стены и закрытые сайты просто пропускаются. Открывать страницу отдельным вызовом нужно, только если выдержек мало.
- **Готовые данные.** На вопросы о **погоде** (в названном городе, а без города — по IP-адресу, с пометкой, что место приблизительное), **местном времени**, **курсах валют** и **ценах биткоина и эфира** ответ берётся из открытых API (Open-Meteo, open.er-api.com, CoinGecko) — это секунда вместо раундов. Источник и пометки модель называет в ответе.
- **Несколько запросов сразу.** `queries` — до двух других формулировок, которые ищутся одновременно с главной; выдачи сливаются без повторов.
- **Бесплатные источники — наперегонки.** Bing и DuckDuckGo спрашиваются одновременно, берётся первый непустой ответ: зависший или заблокированный источник больше не задерживает поиск (источник, давший сбой, 90 секунд не опрашивается). Yahoo — запасной, по одному.
- **Время ответа** в шапке сообщения считается за весь ход, включая раунды инструментов (раньше показывалось время только последнего запроса к модели).

## Два вида поиска

| Вид | Как работает | С какими моделями |
| --- | --- | --- |
| Встроенный | ищет сам сервис модели (например, Genspark, Antigravity) | только с моделями, которые это умеют |
| Внешний | MemuAI ищет сам и передаёт найденное модели | с любой текстовой моделью |

**Настройки → Веб-поиск → Источник поиска**:

- **Автоматически** — встроенный поиск, если модель его умеет, иначе внешний;
- **Только встроенный**;
- **Только кастомный** — всегда внешний.

## Внешние источники

Источник выбирается в **Настройки → Веб-поиск → Внешний источник → Сервис**. Ключ и адрес запоминаются для каждого сервиса отдельно: переключаясь между ними, вы ничего не теряете. Кнопка **Проверить источник** делает пробный запрос и показывает, сколько результатов пришло и за какое время.

### Бесплатно, без ключа

| Сервис | Что это |
| --- | --- |
| Авто: Kiro → Bing и DuckDuckGo | если в Proxy есть аккаунт Kiro и он отвечает почти так же быстро, берётся его встроенный поиск (как в Kiro IDE); иначе Bing и DuckDuckGo спрашиваются одновременно, а Yahoo — запасной. Выбран по умолчанию |
| Kiro | только встроенный поиск Kiro. Нужен аккаунт Kiro в MemuAI Proxy |
| Bing | только Bing, без ключа и аккаунтов; быстрый и терпимый к частым запросам, понимает русский |
| DuckDuckGo | только DuckDuckGo, без аккаунтов. При частых запросах DuckDuckGo на время просит подтвердить, что вы человек, — тогда помогает «Авто» или Bing |
| Yahoo | выдача на индексе Bing; бывает медленным или недоступным в некоторых странах — в «Авто» это запасной источник |
| Википедия | только энциклопедические статьи; язык раздела выбирается по языку запроса |

Раньше «Kiro / DuckDuckGo» был одним пунктом. Теперь это отдельные: «Авто» (Kiro, а без него Bing и DuckDuckGo наперегонки), «Kiro», «Bing» и «DuckDuckGo».

### Свой сервер

| Сервис | Что нужно |
| --- | --- |
| SearXNG | адрес своего или публичного сервера SearXNG (корневой или с `/search`); в нём должен быть включён формат JSON. Ключ — если сервер его требует |

### С ключом API

| Сервис | Особенность | Где взять ключ |
| --- | --- | --- |
| Tavily | поиск для ИИ: чистые выдержки из страниц; есть бесплатный месячный лимит | tavily.com |
| Brave Search API | собственный индекс Brave; есть бесплатный тариф | brave.com/search/api |
| Exa | смысловой поиск: находит страницы по описанию, а не по словам | exa.ai |
| Google · Serper | выдача Google, быстро и недорого | serper.dev |
| Google · SerpApi | выдача Google; есть бесплатный месячный лимит | serpapi.com |
| Google · Programmable Search | официальный API Google; кроме ключа нужен идентификатор поисковой системы (cx); 100 запросов в день бесплатно. **С 20.01.2026 закрыт для новых клиентов, отключается 1.01.2027** — только если он у вас уже был | programmablesearchengine.google.com |
| Jina Search | поиск Jina AI | jina.ai |
| Perplexity Search | ранжированные результаты с выдержками, без ответа модели | perplexity.ai/settings/api |
| Linkup | поиск для ИИ с доступом к части платных изданий | linkup.so |
| Firecrawl | поиск Firecrawl | firecrawl.dev |
| Kagi | платный поиск без рекламы; нужен доступ к Search API | kagi.com |

Источники с ключом проверены на формате ответов их API; сами ключи для них нужно получить у сервиса. Если источник выбран, но ключ не указан, поиск по требованию модели сообщит об этом, а не подменит источник молча.

**Максимум результатов** ограничивает, сколько найденных страниц уходит модели. Больше — полнее ответ, но дольше и дороже по токенам.

Ключи хранятся только на этом компьютере.

## Как модель пользуется результатами

Найденные фрагменты передаются модели как непроверенный справочный материал. Модель должна опираться на прямые и авторитетные источники, указывать только те ссылки, что действительно были в выдаче, и честно говорить, если результатов не хватило. Инструкции внутри найденных страниц модель не выполняет.

> [!TIP]
> Если ответ на вопрос о свежем событии звучит устаревшим, проверьте, что переключатель поиска в чате включён и у модели есть встроенный поиск или настроен внешний источник.

## Поиск в Proxy

У MemuAI Proxy свой поиск — для сторонних программ, которые подключаются к его API: **Proxy → Настройки → Веб-поиск**. Там тот же список источников, свои ключи и кнопка **Проверить**; он работает независимо от настроек MemuAI. Этим же источником ищет [MemuCode CLI](doc:memucode-cli).
