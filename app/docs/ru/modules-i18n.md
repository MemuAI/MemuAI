# Переводы модуля

Модуль узнаёт язык MemuAI при открытии и получает событие, когда язык меняется. Если тексты модуля лежат в словаре, а не прямо в разметке, он переводится целиком и сразу — без перезапуска окна и без единой строки кода для переключения.

Все встроенные модули (Переводчик, Studio, Design) и все шаблоны в мастере создания устроены именно так.

## Из чего состоит перевод

1. Файл `i18n.json` рядом с `manifest.json` — словари по языкам.
2. Атрибуты `data-i18n` в `index.html` — какие элементы переводить.
3. Вызовы `Memu.t("ключ")` в `main.js` — для строк, которые собираются в коде.

```
my-module/
  manifest.json
  index.html
  style.css
  main.js
  i18n.json
```

## Файл i18n.json

Это объект, в котором ключ верхнего уровня — код языка, а внутри — пары «ключ → текст»:

```json
{
  "ru": {
    "title": "Заметки",
    "add": "Добавить",
    "empty": "Пока пусто",
    "saved": "Сохранено {time}"
  },
  "en": {
    "title": "Notes",
    "add": "Add",
    "empty": "Nothing here yet",
    "saved": "Saved at {time}"
  }
}
```

Ключи можно называть как угодно; удобно группировать их точками: `form.name`, `form.email`, `error.network`.

> [!TIP]
> В мастерской модуля есть вкладка **Переводы**. Кнопка «Добавить недостающие» находит ключи, которые встречаются в коде, но отсутствуют в словаре, и добавляет их во все языки — останется только вписать текст.

## Разметка

Атрибут `data-i18n` заменяет текст элемента:

```html
<h1 data-i18n="title"></h1>
<button class="mu-btn primary" id="add" data-i18n="add"></button>
```

Для атрибутов есть отдельные варианты:

| Атрибут в разметке | Что переводит |
| --- | --- |
| `data-i18n` | текст элемента (`textContent`) |
| `data-i18n-html` | содержимое как HTML — только для своих строк, без пользовательских данных |
| `data-i18n-placeholder` | подсказку в поле ввода |
| `data-i18n-title` | всплывающую подсказку |
| `data-i18n-aria-label` | подпись для экранного диктора |
| `data-i18n-alt` | альтернативный текст картинки |
| `data-i18n-value` | значение поля или кнопки |
| `data-i18n-label` | атрибут `label` (например, у `<optgroup>`) |

Одному элементу можно задать несколько атрибутов сразу:

```html
<input id="search" data-i18n-placeholder="search.hint" data-i18n-aria-label="search.label">
```

Мост проходит по документу при запуске и при каждой смене языка. Если элементы добавляются позже, вызовите `Memu.i18n.apply(контейнер)` после вставки — или соберите их сразу с текстом через `Memu.t`.

## Код

```javascript
const t = Memu.t;

status.textContent = t("saved", { time: Memu.i18n.date(Date.now(), { timeStyle: "short" }) });
```

Фигурные скобки в тексте — подстановки: `{time}` заменяется значением из второго аргумента. Если ключа нет ни в одном словаре, `Memu.t` вернёт сам ключ — так пропущенный перевод сразу виден в окне. Можно задать запасной текст: `t("hint", { fallback: "Нажмите Enter" })`.

### Когда язык сменился

Тексты с `data-i18n` обновятся сами. Всё, что код собрал строками, нужно перерисовать:

```javascript
function draw() {
  list.innerHTML = "";
  for (const note of notes) {
    const row = document.createElement("div");
    row.textContent = note.text;
    list.append(row);
  }
  counter.textContent = t("count", { count: notes.length });
}

draw();
Memu.onLanguage(draw);
```

Обработчик получает объект `{ lang, previous }`. Текущий язык всегда доступен как `Memu.lang`.

## Числа: множественное число

Для слов, которые меняются от числа, значение ключа — объект с формами. Мост выбирает форму по правилам языка (стандартный `Intl.PluralRules`), а число передаётся в `count`:

```json
{
  "ru": { "count": { "one": "{count} заметка", "few": "{count} заметки", "many": "{count} заметок", "other": "{count} заметки" } },
  "en": { "count": { "one": "{count} note", "other": "{count} notes" } }
}
```

Допустимые формы: `zero`, `one`, `two`, `few`, `many`, `other`. Форма `other` нужна всегда — она используется, если нужной формы нет.

> [!NOTE]
> В русском языке дробные числа (1,5) относятся к форме `other`, поэтому её стоит заполнить, даже если модуль работает только с целыми.

## Форматирование по языку

| Метод | Пример результата (ru / en) |
| --- | --- |
| `Memu.i18n.number(1234.5)` | `1 234,5` / `1,234.5` |
| `Memu.i18n.number(0.25, { style: "percent" })` | `25 %` / `25%` |
| `Memu.i18n.date(Date.now(), { dateStyle: "long" })` | `23 сентября 2026 г.` / `September 23, 2026` |
| `Memu.i18n.list(["A", "B", "C"])` | `A, B и C` / `A, B, and C` |

Второй аргумент — обычные параметры `Intl.NumberFormat`, `Intl.DateTimeFormat` и `Intl.ListFormat`.

## Полный список методов

| Метод | Что делает |
| --- | --- |
| `Memu.t(key, vars)` | перевод с подстановками и формами числа |
| `Memu.lang` | текущий язык: `ru`, `en` и т. п. |
| `Memu.onLanguage(handler)` | подписка на смену языка |
| `Memu.i18n.apply(root)` | перевести элементы с `data-i18n*` внутри `root` |
| `Memu.i18n.has(key)` | есть ли ключ хотя бы в одном подходящем словаре |
| `Memu.i18n.get(key, lang)` | сырое значение в одном языке, без подстановок и запасных |
| `Memu.i18n.locales()` | языки, для которых есть словари |
| `Memu.i18n.locale()` | код для `Intl`: `ru-RU`, `en-US` |
| `Memu.i18n.add(lang, table)` | добавить или заменить ключи одного языка на ходу |
| `Memu.i18n.extend(tables)` | то же для нескольких языков сразу |
| `Memu.i18n.number / date / list` | форматирование по правилам языка |

## Какой словарь выбирается

Мост ищет ключ по цепочке и останавливается на первом найденном значении:

1. точный язык MemuAI (например, `pt-BR`);
2. его основная часть (`pt`);
3. `default_locale` из `manifest.json`;
4. `en`, затем `ru`;
5. любые другие языки из `i18n.json`.

Так модуль с одним английским словарём всё равно покажет английский текст в русском интерфейсе, а не набор ключей.

```json
{
  "id": "notes",
  "name": "Заметки",
  "default_locale": "ru"
}
```

## Пределы

| Что | Предел |
| --- | --- |
| языков в одном модуле | 24 |
| ключей в одном языке | 3000 |
| длина одного текста | 20 000 символов |
| код языка | `xx`, `xxx` или `xx-YY` |

Ошибка в JSON не ломает модуль: при сохранении мастерская показывает строку и столбец, где сломался файл, а уже установленный модуль с испорченным `i18n.json` откроется с пустыми словарями.

## Проверка

- Переключите язык в предпросмотре мастерской: список языков берётся из `i18n.json`.
- Вкладка **Переводы** показывает, сколько ключей не хватает в каждом языке.
- Ключ, который виден в окне «как есть» (`form.name` вместо текста), значит, что его нет ни в одном словаре.
