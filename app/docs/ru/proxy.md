# MemuAI Proxy

**MemuAI Proxy** — вторая программа комплекта. Она хранит ваши аккаунты провайдеров, собирает из них общий каталог моделей и раздаёт его через API, совместимый с OpenAI. Сам чат MemuAI тоже работает через Proxy: каждое сообщение уходит в него, а он выбирает аккаунт и отправляет запрос провайдеру.

Обычно Proxy настраивают один раз — добавляют аккаунты — и дальше пользуются только MemuAI.

## Где он работает

Proxy живёт в системном трее, рядом с часами. MemuAI запускает его сам, если он ещё не запущен. Окно открывается двойным щелчком по значку в трее; закрытие окна прячет его обратно в трей, а работа продолжается.

Выключить Proxy полностью: трей → **Выключить** или **Настройки → Система → Выключить**. Без Proxy чат MemuAI не сможет отвечать, а запланированные задачи не выполнятся.

Одновременно работает только один экземпляр. Повторный запуск просто показывает уже открытое окно.

## Статистика и стоимость

Карточка **Статистика работы** на главной показывает запросы, успешность, время ответа и токены за выбранный период (сегодня, 24 часа, 7 и 30 дней, всё время — история хранится 35 дней) и **стоимость по API-ценам** — всего и по каждой модели и провайдеру.

- Цена берётся из каталога моделей (OpenRouter / Models.dev, обновляется раз в сутки), иначе из встроенной таблицы типичных цен семейства; своя цена задаётся в `pricing-overrides.json` в папке данных (`memuai`). Подпись к сумме показывает цену за 1 млн токенов и её источник. Кэшированные входные токены считаются по цене кэша.
- Для **подписочных** провайдеров (Genspark, Kiro, Antigravity, Gemini Web, Grok) это **эквивалент по API-ценам** (метка «экв. API»): деньги за токены не списываются, сумма показывает, сколько та же работа стоила бы через официальный API. Для своих API-ключей — оценка счёта; если провайдер сам сообщает стоимость запроса (OpenRouter), показана она (метка «счёт»).
- Если цены модели нет нигде, вместо обманчивого «$0» написано **«цена неизвестна»**, а итог помечен «≥».
- Статистика до раунда 20 хранила токены только за час целиком. Для таких часов токены распределяются между моделями пропорционально числу запросов, и суммы помечены «≈».
- Переключатель графика **Стоимость** показывает расходы по часам или дням.

## Баланс API и свои тарифы

Откройте **Планировщик квот → Баланс API → Добавить аккаунт**. Выберите уже подключённый аккаунт, введите его текущий остаток в USD и нажмите **Сохранить**. Ключ повторно вводить не нужно. Поле **Распределить баланс до** необязательно: оно задаёт дату для расчёта допустимого расхода в день.

В **Настроить** показаны модели этого аккаунта и распознанные названия — например, `api-claude-opus-5.5` соответствует Claude Opus 5.5. Базовые цены берутся из каталога OpenRouter и встроенной таблицы тарифов поставщиков. **Обновить цены** загружает каталог заново и сохраняет ваши настройки.

Раскройте модель и включите **Использовать свой тариф**. Цены задаются в **USD за 1 млн токенов**, отдельно для входа, выхода, чтения и записи кэша. Поиск помогает найти нужную модель; скидка в процентах применяется только к найденным моделям с известной базовой ценой. Выключение **Учитывать отдельную цену кэша** считает кэшированные токены по обычной цене входа; оно не выключает автоматический кэш внешнего сервиса. Пустая своя цена кэша также означает обычную цену входа.

Тариф аккаунта имеет приоритет над общим `pricing-overrides.json` и публичным прайсом. Proxy считает запрос по тарифу **того аккаунта, который действительно ответил**, в том числе при переходе на резервный ключ. Эта же стоимость передаётся в MemuAI, MemuCode и статистику. Прямое подключение CLI `@api:model` тоже использует тариф пула с именем `api`, если цены всех его аккаунтов однозначны. Цены одного ключа не подставляются другому ключу с другим тарифом. Общий файл `pricing-overrides.json` продолжает работать для моделей без тарифов аккаунта.

**Остаток — приблизительный расчёт, а не баланс у провайдера.** Планировщик вычитает успешные запросы через этот Proxy после ввода баланса. Прямые подключения CLI и запросы других приложений в обход Proxy баланс не уменьшают; также могут отсутствовать комиссии, расходы на отдельную генерацию изображений/аудио/видео и оборванные ответы. Запросы без известной цены показаны отдельно: они не считаются бесплатными, а остаток может быть завышен. Темп появляется после трёх запросов и часа наблюдений; сверяйте остаток с кабинетом сервиса.

Редактирование тарифов сохраняет уже учтённый расход. Новый ввод текущего баланса начинает новый период учёта и сохраняет тарифы; оставьте поле пустым, если меняете только цены. **Убрать из планировщика** удаляет учёт баланса и тарифы, сохраняя сам аккаунт Proxy.

## Аккаунты

Аккаунт — это одно подключение к провайдеру: кука, вход через браузер или ключ API. Список провайдеров и что вставлять в каждое поле — в [Аккаунтах](doc:accounts).

**Порядок карточек — это приоритет.** Верхняя карточка используется первой. Порядок меняется перетаскиванием карточки (за ручку ≡ или за свободное место) или стрелками ▲ ▼. Во время перетаскивания список прокручивается колесом мыши и сам — у верхнего и нижнего края окна; синяя черта показывает, куда встанет карточка (до или после той, над которой курсор). ++Esc++ отменяет перемещение. Выделенная группа перетаскивается целиком.

**Выделение.** Щелчок по свободному месту карточки выделяет её, ++Ctrl+++щелчок добавляет или убирает карточку, ++Shift+++щелчок — диапазон, ++Ctrl+A++ — все показанные. Кнопка **Выбрать несколько** включает режим с флажками: там обычный щелчок отмечает карточку. Пока что-то выделено, сверху видна панель «Выбрано: N из M» с массовыми действиями — включить, выключить, проверить, в резерв, обычный приоритет, удалить — и кнопками **Выбрать все** и **Отменить**. Снять выделение и выйти из режима можно кнопкой **Отменить**, клавишей ++Esc++ или щелчком по пустому месту. Правая кнопка мыши открывает меню для выделенных карточек.

У карточки есть состояние:

| Состояние | Что значит | Что делать |
| --- | --- | --- |
| работает | последний запрос или проверка прошли | ничего |
| невалидный | провайдер не принял данные входа | обновить куку или войти заново |
| не проверен | запросов ещё не было | нажать «Проверить» |
| выключен | аккаунт выключен переключателем | включить, если нужен |

Ошибка лимита (429) или временный сбой провайдера **не выключают аккаунт и не отправляют его на «паузу»**: причина остаётся в карточке («Последняя ошибка») и в журнале, а аккаунт продолжает участвовать в очереди. Внутри одного запроса Proxy просто переходит к следующему аккаунту. Единственное исключение — «невалидный»: так помечается аккаунт, у которого провайдер отверг сам вход; пока вы не обновите данные (или фоновая проверка не подтвердит вход), он пропускается.

Рядом с неработающим аккаунтом есть кнопка **Разобрать** — она открывает ИИ-помощника сразу с описанием ошибки.

Ключ копируется там же, где он хранится: **Изменить** (✎) → у поля ключа (и других секретных полей) кнопки **показать** и **копировать**. Копируется то, что сейчас в поле; если поле пустое, появляется «Ключ не задан».

### Готовые подключения

**＋ Добавить аккаунт** → блок **Готовые подключения** — больше 100 сервисов с уже заполненным адресом: сверху плитки самых популярных (OpenRouter, OpenAI, Anthropic, Google AI Studio, DeepSeek, xAI, Mistral, Groq, Qwen, Kimi, Z.ai, Together, YandexGPT, NVIDIA, Cerebras, Ollama, LM Studio, Hugging Face), остальные — по кнопке **Показать все сервисы**: список по алфавиту с поиском (по названию, стране, модели — по-русски и по-английски), фильтром по региону (США, Европа, Китай, Россия, Азия, агрегаторы, этот ПК) и флажком «Есть бесплатный доступ».

В форме сервиса с ключом рядом с **Где взять ключ** и **Документация** есть кнопка **▶ Видео-инструкция**: полминуты о том, как получить ключ на сайте и добавить аккаунт (на примере OpenRouter).

После выбора сервиса остаётся вставить ключ (кнопка **Где взять ключ** открывает нужную страницу). Если адресу нужен ваш идентификатор — ID каталога Yandex Cloud, ID аккаунта Cloudflare, проект и регион Vertex AI, регион AWS Bedrock, имя ресурса Azure, проект MWS GPT, — для него есть отдельное поле, и он сам подставляется в адрес и названия моделей. Для локальных серверов (Ollama, LM Studio, llama.cpp, vLLM, Jan, LocalAI, KoboldCpp и др.) ключ не нужен. Сервисы, которые принимают ключ не в `Authorization: Bearer` (Azure — в `api-key`), Proxy настраивает сам. Каждое готовое подключение — обычный «Собственный API»: всё можно поменять в **Изменить**.

## Настройки

Слева — разделы, справа — один раздел за раз: сверху то, что меняют чаще, редкое спрятано под **Дополнительно**. Всё сохраняется само; справа вверху видно «Сохранение…», «Сохранено» или ошибку. Поле **Найти настройку** (клавиша ++/++ или ++Ctrl+F++) ищет по всем разделам на русском и английском, само раскрывает «Дополнительно» и подсказывает настройки других вкладок — например, публичный доступ или модели каталога по имени. Изменённая настройка отмечена точкой; кнопка ↺ рядом возвращает значение по умолчанию. В разделе **Общие** — язык, тема панели (тёмная, светлая или как в системе) и поведение окна; перезапуск, сброс статистики, очистка журнала и выключение — в **Система**.

## Как выбирается аккаунт

**Настройки → Маршрутизация → Как выбирать аккаунт**:

| Режим | Поведение |
| --- | --- |
| по очереди | запросы распределяются между рабочими аккаунтами по кругу |
| строго по порядку | всегда верхний рабочий аккаунт, следующий — только при ошибке |
| сначала проверенные | сначала аккаунты со статусом «работает», затем остальные — по порядку |
| давно не использованный | аккаунт, который дольше всех не получал запросов |

Если аккаунт ответил ошибкой, Proxy сам пробует следующий. Аккаунты с отметкой «резерв» используются, только когда обычные закончились.

## Каталог моделей

Страница **Каталог моделей** в панели слева (раньше была в настройках) показывает все модели всех аккаунтов. Модель можно выключить — тогда её не будет ни в MemuAI, ни в API. «Обновить с серверов» подтягивает свежие списки у провайдеров. «Выключить по словам» (под «Дополнительно» в каталоге) скрывает сразу все модели, в названии которых есть, например, `preview` или `audio`.

**Выбор моделей при добавлении аккаунта.** Если новый аккаунт принёс 30 моделей или больше, Proxy сразу спрашивает, какие оставить включёнными. Все отмечены; «Выключить все» и поиск помогают быстро оставить только нужные (кнопки действуют на то, что сейчас показано в списке). Выключенные модели не удаляются — их можно включить позже здесь же.

**Выделение в списке** работает как в проводнике Windows: щелчок выделяет строку, повторный щелчок по ней — снимает; ++Ctrl++ добавляет и убирает строки, ++Shift++ — диапазон; рамку можно тянуть мышью, и у края список сам прокручивается, не теряя уже выделенное. ++Ctrl+A++ — все показанные, ++Esc++ — снять, ++Delete++ — удалить выделенные.

Имя модели в API складывается из префикса провайдера и имени модели: `genspark-claude-sonnet-5`, `kiro-claude-sonnet-4-5`, `local-qwen3-8b-q4-k-m`.

## Надёжность

**Настройки → Надёжность** (первые два параметра видны сразу, остальные — под «Дополнительно»):

| Параметр | Смысл |
| --- | --- |
| Ждать начала ответа | сколько ждать начала ответа, прежде чем уйти на другой аккаунт (90 с) |
| Повторных проходов | сколько раз обойти весь список, пока не найдётся рабочий |
| Предел на весь запрос | предел на весь запрос |
| Тишина в потоке | сколько терпеть паузу посреди ответа |
| Пауза между попытками | задержка перед повтором |
| Поддерживать соединение | пинги клиенту (SSE keep-alive), пока модель думает, чтобы долгий ответ не обрывался |

Раз в пять минут Proxy сам закрывает зависшие соединения. Если ответы всё равно перестали приходить — например, после сна ноутбука, — нажмите **Главная → Перезапустить службы**: это пересоздаёт соединения без закрытия программы.

## Логи

Вкладка **Логи** показывает каждый запрос: модель, провайдер, аккаунт, время, токены и стадии обработки. Весь текст выделяется и копируется; запись можно скопировать целиком, выгрузить журнал в JSON или TXT. У неудачного запроса есть кнопка **Разобрать** для ИИ-помощника.

У новых записей есть **Показать промпт** и **Скопировать промпт**: можно посмотреть входные сообщения с ролями и контекстом инструментов. Текст сохраняется полностью, независимо от длины; служебные уведомления просмотра не попадают в скопированный промпт. Вместо изображений, аудио и видео показываются маркеры. Для этой функции включите **Настройки → Логи и статистика → Дополнительно → Сохранять содержимое стадий**. У старых записей промпт может отсутствовать или быть обрезан прежней версией; потерянную часть восстановить из журнала нельзя.

Вторая вкладка — **Журнал сервера**: служебные сообщения самого Proxy с фильтром по уровню. Сюда стоит смотреть, если что-то сломалось не в конкретном запросе, а целиком.

Секретные поля и известные ключи подключения скрываются в журнале. Произвольный секрет, который вы сами написали в сообщении, может остаться частью промпта; для такого разговора отключите сохранение payload.

## Данные

Всё хранится в `%APPDATA%\MemuAI`: `config.json` (настройки), `accounts.json` (аккаунты), `models.json` (каталог), журналы и файлы локальных моделей. Подробнее — в разделе [Где хранятся данные](doc:data).
