# Справочник токенов и селекторов

Токен — это CSS-переменная, через которую окрашивается интерфейс. Поменять токен в теме значит поменять цвет во всех местах, где он используется. Для точечных правок есть селекторы — ниже перечислены те, что не меняются между версиями.

## Основные токены

Эти токены задаёт каждый встроенный вариант. Их же показывает студия тем.

### Поверхности

| Токен | Где используется |
| --- | --- |
| `--bg` | основной фон окна и области чата |
| `--bg-deep` | более глубокий фон: боковая панель, подложки |
| `--panel` | панели, карточки, всплывающие окна, поле ввода |
| `--panel-2` | вторичная поверхность: наведение, пузырь пользователя |
| `--border` | тонкие разделители и рамки |
| `--control-border` | рамки полей и кнопок (заметнее, чем `--border`) |

### Текст

| Токен | Где используется |
| --- | --- |
| `--text` | основной текст |
| `--muted` | второстепенный текст, подписи, иконки |

### Акцент

| Токен | Где используется |
| --- | --- |
| `--accent` | кнопки, ссылки, выделение активного элемента |
| `--on-accent` | текст поверх акцентной заливки |
| `--accent-soft` | полупрозрачная подложка акцента |

В обычном оформлении `--accent` вычисляется из выбранного акцентного цвета. Если тема задаёт `--accent` сама, выбор акцента в настройках на неё не действует.

### Состояния

| Токен | Где используется |
| --- | --- |
| `--danger` | ошибки и разрушительные действия |
| `--ok` | успех и состояние «подключено» |

### Код

| Токен | Где используется |
| --- | --- |
| `--code-bg` | фон блоков кода |
| `--code-text` | обычный текст в коде |
| `--code-header` | шапка блока кода: язык, кнопка копирования |

### Эффекты

| Токен | Где используется |
| --- | --- |
| `--shadow` | тень больших всплывающих панелей |
| `--composer-shadow` | тень поля ввода |

## Дополнительные токены

Их нет во встроенных вариантах: по умолчанию каждый берёт значение из основного токена. Тема может задать любой из них, чтобы поменять одну часть интерфейса, не трогая остальное.

| Токен | По умолчанию | Где используется |
| --- | --- | --- |
| `--side-bg` | `var(--bg-deep)` | фон боковой панели |
| `--topbar-bg` | `var(--bg)` | фон верхней панели |
| `--composer-bg` | `var(--panel)` | фон поля ввода |
| `--user-bubble` | `var(--panel-2)` | фон сообщения пользователя |
| `--user-bubble-text` | `var(--text)` | текст сообщения пользователя |
| `--link` | `var(--accent)` | ссылки в ответах |
| `--selection` | акцент, 42 % непрозрачности | фон выделенного текста |
| `--scroll-thumb` | текст, 22 % | ползунок прокрутки |
| `--scroll-thumb-hover` | смесь акцента и текста | ползунок под курсором |
| `--hover` | серый, 16 % | подсветка строки списка под курсором |
| `--accent-2` | парный оттенок акцента | второй цвет фирменного градиента: знак MemuAI, кнопка отправки, сфера Live, прогресс исследования |
| `--brand-gradient` | градиент `--accent` → `--accent-2` | знак, кнопка отправки, значок нового чата |
| `--chrome-bg` | `var(--bg-deep)` | фон окна вокруг холста беседы и под боковой панелью |
| `--canvas-bg` | `var(--bg)` | холст беседы — приподнятый лист с чатом |
| `--canvas-border` | `--border`, 80 % | тонкая рамка холста, меню и всплывающих окон |
| `--terminal-bg` | `#0f1115` | фон терминала MemuCode |
| `--terminal-text` | `#d7dae0` | текст терминала MemuCode |
| `--mc-add` | зелёный | добавленные строки в изменениях MemuCode |
| `--mc-del` | красный | удалённые строки в изменениях MemuCode |
| `--tooltip-bg` | панель, чуть светлее | фон всплывающих подсказок |
| `--tooltip-text` | `var(--text)` | текст подсказок |

## Форма и шрифты

| Токен | По умолчанию | Смысл |
| --- | --- | --- |
| `--radius` | `12px` | основной радиус скругления |
| `--radius-sm` / `--radius-md` / `--radius-lg` | `8px` / `12px` / `16px` | малые, средние и крупные скругления |
| `--conversation-width` | `780px` (широкая — `1080px`) | ширина колонки диалога |
| `--sans` | Segoe UI Variable | шрифт интерфейса |
| `--serif` | Tiempos Headline, Charter | шрифт заголовков |
| `--font` | Charter | шрифт ответов, если выбран шрифт с засечками |
| `--mono` | Cascadia Code, Consolas | шрифт кода |

## Подсветка кода

Каждый вариант задаёт свою палитру подсветки. Переопределите нужные переменные — остальные останутся от основы:

| Токен | Что подсвечивает |
| --- | --- |
| `--tok-kw` | ключевые слова: `if`, `return`, `class` |
| `--tok-type` | типы и классы |
| `--tok-str` | строки |
| `--tok-com` | комментарии |
| `--tok-num` | числа |
| `--tok-fn` | имена функций |
| `--tok-op` | операторы |
| `--tok-lit` | `true`, `false`, `null` |
| `--tok-tag` | теги HTML и XML |
| `--tok-attr` | атрибуты тегов |
| `--tok-prop` | свойства CSS и ключи объектов |
| `--tok-var` | переменные |
| `--tok-meta` | директивы, декораторы |
| `--tok-punct` | скобки и знаки препинания |

```css
:root {
  --tok-kw: #ff79c6;
  --tok-str: #f1fa8c;
  --tok-com: #6272a4;
}
```

## Атрибуты корневого элемента

MemuAI отмечает текущее состояние атрибутами на `<html>`. По ним тема может вести себя по-разному в разных условиях.

| Атрибут | Значения |
| --- | --- |
| `data-theme` | `dark`, `light` |
| `data-surface` | id встроенного варианта или основы своей темы |
| `data-custom-theme` | slug своей темы, если она активна |
| `data-accent` | `terracotta`, `blue`, `violet`, `teal`, `rose`, `graphite`, `amber`, `forest`, `indigo`, `plum`, `crimson`, `cyan` |
| `data-density` | `compact`, `spacious` (нет атрибута — обычная) |
| `data-chat-width` | `comfortable`, `wide` |

```css
/* Акцент «Лес» в этой теме чуть ярче */
:root[data-accent="forest"] { --accent: #7ee08a; }
```

## Устойчивые селекторы

| Селектор | Что это |
| --- | --- |
| `aside.side` | боковая панель |
| `.side-btn` | кнопки разделов в боковой панели (Чат, Work, MemuCode…) |
| `.chat-item`, `.chat-item.active` | строка чата в списке, текущий чат |
| `header.topbar` | верхняя панель |
| `#model-dd-btn` | кнопка выбора модели |
| `#messages` | лента сообщений |
| `.msg-user .bubble` | сообщение пользователя |
| `.msg-assistant .body` | текст ответа модели |
| `.msg-assistant .who` | строка с именем модели над ответом |
| `.code-block-wrap` | блок кода в ответе |
| `.composer` | поле ввода вместе с кнопками |
| `#input` | само текстовое поле |
| `.pbtn`, `.pbtn.ghost`, `.pbtn.danger` | кнопки в панелях и настройках |
| `#panel` | выдвижная панель настроек |
| `.memu-tooltip` | всплывающая подсказка |
| `#code-dock` | правая панель MemuCode |
| `.module-window` | окно модуля |

> [!WARNING]
> Селекторы, которых нет в этой таблице, — внутренние. Они работают, но могут измениться в следующей версии MemuAI. Если что-то можно сделать токеном, лучше сделать токеном.

## Примеры

### Цветная боковая панель

```css
:root {
  --side-bg: #1b2a22;
}
.side-btn.active-section { background: color-mix(in srgb, var(--accent) 18%, transparent); }
```

### Пузырь пользователя в цвет акцента

```css
:root {
  --user-bubble: var(--accent);
  --user-bubble-text: var(--on-accent);
}
```

### Прямые углы везде

```css
:root {
  --radius: 0px;
  --radius-sm: 0px;
  --radius-md: 0px;
  --radius-lg: 0px;
}
```

### Картинка на фоне ленты

```css
#messages {
  background:
    linear-gradient(color-mix(in srgb, var(--bg) 86%, transparent), color-mix(in srgb, var(--bg) 86%, transparent)),
    url("data:image/svg+xml;utf8,<svg xmlns='http://www.w3.org/2000/svg' width='24' height='24'><circle cx='2' cy='2' r='1' fill='%23888'/></svg>");
}
```
