# Пределы и производительность

Ограничения защищают MemuAI от случайного перегруза. Ниже — все числа, которые стоит знать.

## Код и описание

| Что | Предел |
| --- | --- |
| Идентификатор | 41 символ, латиница/цифры/дефис, начинается с буквы |
| HTML, CSS или JS по отдельности | 400 000 символов |
| `instructions` | 20 000 символов |
| Название, описание | 80 и 400 символов |
| Всего сохраняемых ключей | 32 |
| Длина имени ключа | 40 символов |
| Всего полей за одно сохранение | 200 |
| Значение поля | 2 МБ в JSON |

## Производительность

- Страница модуля собирается один раз, при открытии. Дальше всё работает в памяти.
- Разрешите кэширование: не перерисовывайте весь список на каждый символ.
- Тяжёлые вычисления разбивайте через `requestAnimationFrame` или `setTimeout`, иначе интерфейс замрёт.
- Для длинных списков показывайте первые 100 записей и кнопку «показать ещё».
- Не держите в `persist` изображения: закрытие модуля будет заметно медленнее.

| --- | --- |
| Доступ к странице MemuAI | нет |
