# Telegram-бот

Бот — это ваш MemuAI в Telegram: те же чаты, модели, профили и агенты, что и на компьютере. Всё, что вы напишете боту, появится в MemuAI, и наоборот.

> [!NOTE]
> Бот работает через MemuAI Proxy на вашем компьютере (long polling Bot API): наружу ничего не открывается. Пока Proxy выключен или компьютер спит, бот молчит.

## Подключение за минуту

1. В Telegram откройте **@BotFather**, отправьте `/newbot` и следуйте подсказкам. В конце он выдаст **токен бота**.
2. В MemuAI: **Настройки → Telegram**, вставьте токен в шаг **1**. Под полем появится имя бота — значит, токен верный.
3. Нажмите **Подключить Telegram** (шаг **2**). Появятся QR-код и код вида `K7QM-3XRP`.
4. Отсканируйте QR камерой телефона (или нажмите **Открыть в Telegram**) и нажмите **Start** — бот привяжется сам. Можно и просто отправить боту код.

Кнопка **▶ Видео-инструкция** рядом с шагом **1** показывает то же самое коротким роликом (без звука, с подписями по-русски и по-английски).

Код одноразовый, действует 10 минут и сгорает после 8 неверных попыток. Статус вверху панели показывает, что происходит на самом деле: «Подключено · @бот», «Онлайн · ждёт привязки», «Переподключаюсь…» (с причиной и временем следующей попытки), «Бот запущен в другом месте», «Токен отклонён», «MemuAI Proxy не запущен» (с кнопкой «Запустить Proxy») или «Бот не отвечает». Кнопка **Перезапустить бота** внизу панели за несколько секунд перезапускает опрос Telegram с новым соединением.

> [!IMPORTANT]
> Бот отвечает только привязанному чату (и пользователям из списка «Дополнительные пользователи»). Остальным он один раз вежливо отказывает и больше не отвечает. Токен хранится только на компьютере и не попадает в журналы.

Старый способ тоже работает: отправьте боту `/id` и вставьте число в **Дополнительно → Привязанный Chat ID**.

## Как пользоваться

| Что сделать | Как |
| --- | --- |
| Задать вопрос | просто напишите — ответ печатается вживую |
| Остановить ответ | кнопка ⏹ на черновике, **⏹ Остановить** или `/stop` |
| Голосом | отправьте голосовое, видеосообщение или аудиофайл — его расшифрует локальная модель Whisper на компьютере (или сервис распознавания, выбранный в настройках [голоса](doc:voice)), и MemuAI ответит; с **Показывать расшифровку перед отправкой** сначала придёт текст с кнопкой **Отправить** |
| Фото и файлы | фото идут в vision-модели; PDF, DOCX и текстовые файлы читаются |
| Исправить вопрос | отредактируйте последнее сообщение — MemuAI ответит заново |
| Под ответом | одна строка: **↻ Ещё раз**, **🤖 модель** (сменить), **⋯** — продолжить, озвучить, новый чат, меню |

Внизу экрана всегда три кнопки: **💬 Чаты**, **➕ Новый чат**, **☰ Меню**. Меню — одна карточка, которая меняется на месте: модель, чаты, агенты, временный чат, **⚙️ Настройки** и **⋯ Ещё** (профили, промпт, Work, помощь). На каждом экране есть «‹ Назад». Если подключено мини-приложение MemuAI, оно открывается кнопкой меню слева от поля ввода и кнопкой **📱 Открыть MemuAI** в карточке меню.

### Чаты

**💬 Чаты** — история с компьютера, новые сверху, закреплённые первыми. Есть **🔎 Поиск** по названиям и тексту. Карточка чата: последний ответ, **📜 История**, **✏️ Переименовать**, **📌 Закрепить**, **🗑 Удалить**. Выбранный чат продолжается следующим сообщением.

**🕶 Временный чат** (`/temp`) ничего не сохраняет — ни в Telegram-истории MemuAI, ни в уведомлениях.

### Модели, профили, агенты, промпты

- **🤖 Модель** — избранные (закреплённые в MemuAI), недавние и все модели по провайдерам; **🔎 Найти модель** по части названия. Модели подписаны понятными названиями, как в MemuAI («Claude Opus 4.6 Thinking · aws9-claude-opus-4.6-thinking»), а строка «Сейчас:» показывает и название, и полный идентификатор.
- **🧠 Размышление** — на экране модели, если текущая модель рассуждает, есть ряд кнопок с **её** уровнями (например, у GLM-5.3 — «Авто, Низкий, Высокий, Максимальный», без «Выкл.»); выбранный отмечен ✓. Уровень сохраняется в ту же настройку «Размышление по моделям», что и в MemuAI, и действует на ответы бота и компьютера. Подробно — [Модели → Размышления](doc:models).
- **👤 Профили** — у каждого свои чаты и память. Профиль с PIN спросит PIN; сообщение с PIN сразу удаляется, после 5 ошибок ввод блокируется на 5 минут.
- **🎭 Агенты** — ваши [мемесы](doc:agents) со своим характером и моделью.
- **📝 Промпт** — системный промпт только для Telegram (по умолчанию — как в MemuAI).
- **🗂 Work** — смена активного проекта и список его файлов.

## Команды

| Команда | Что делает |
| --- | --- |
| `/new` | новый чат |
| `/chats [запрос]` | чаты, с запросом — поиск |
| `/models`, `/model имя` | выбор модели |
| `/image …`, `/video …` | создать картинку или видео по описанию — см. [Картинки и видео в чате](doc:media#в-telegram) |
| `/temp` | временный чат вкл/выкл |
| `/stop` | остановить ответ |
| `/retry` | перегенерировать последний ответ |
| `/agents`, `/profiles`, `/prompts`, `/more` | агенты, профили, промпт, «Ещё» |
| `/work` | проекты Work |
| `/web` | одноразовая ссылка для входа в [Mini App](doc:telegram-miniapp#вход-в-обычном-браузере) в обычном браузере |
| `/settings` | настройки бота |
| `/menu` | главное меню |
| `/help` | справка |
| `/id` | показать Chat ID |

В меню команд Telegram показаны основные: `/new /chats /models /menu /temp /image /video /stop /panels /web /settings /help`; остальные команды тоже работают. Меню переведено на русский и английский по языку Telegram.

## Настройки

**Настройки → Telegram** (часть настроек меняется и в самом боте: `/settings` — нажмите пункт и выберите значение). Изменения из бота и из мини-приложения сразу появляются в открытом окне MemuAI — перезапуск не нужен.

| Настройка | Значение |
| --- | --- |
| Как печатать ответ | **Живой черновик** (по умолчанию) — текст появляется по мере генерации; **Правка сообщения** — для старых клиентов; **Целиком в конце** |
| Модель по умолчанию | модель бота; по умолчанию — основная модель MemuAI |
| Язык бота | русский или английский: меню, кнопки и команды |
| Сообщений в контексте ИИ | 20, 40, 60 или 100 |
| Распознавать голосовые | использует распознавание речи из настроек [голоса](doc:voice) |
| Отвечать голосом | нет / на голосовые / всегда — озвучка вашим голосом MemuAI |
| Уведомления | выключены / без звука / со звуком |
| Категории | ответы в MemuAI, задачи по расписанию, Work и MemuCode, модули |
| Тихие часы | в это время уведомления приходят без звука |
| Дополнительные пользователи | Telegram user id, которым тоже можно пользоваться ботом в своём личном чате |

## Уведомления

Когда ответ в MemuAI на компьютере готов, бот присылает начало ответа с кнопками **💬 Открыть чат** и **↩️ Ответить**. Результаты [задач по расписанию](doc:schedules) приходят целиком. Модули со своим переключателем Telegram (например, «Новые модели API») присылают оповещения даже при выключенных уведомлениях — тихо.

## Если что-то не так

| Симптом | Что сделать |
| --- | --- |
| «MemuAI Proxy не запущен» | запустите MemuAI Proxy (кнопка прямо в панели) |
| «Переподключаюсь…» | нет связи с Telegram (сон ПК, VPN, сбой сети) — бот повторяет сам, причина и время следующей попытки видны в панели |
| «Бот не отвечает» | нажмите **Перезапустить бота** |
| «Токен отклонён» | скопируйте токен у @BotFather заново (или `/revoke` и новый токен) |
| «Бот запущен в другом месте» | этот токен уже использует другая программа или компьютер; если панель пишет «на этом компьютере» — закройте вторую копию MemuAI Proxy (на одном компьютере бот всегда запускается один раз) |
| Бот молчит в чате | проверьте, что чат привязан; при необходимости привяжите заново |
| Голосовое не расшифровано | скачайте модель речи в **Настройки → Голос и Live** |

См. также: [Уведомления](doc:notifications), [Профили](doc:profiles), [Агенты](doc:agents).
