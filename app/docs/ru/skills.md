# Скиллы ИИ

Скилл — инструкция для типовой работы: ревью кода, отладка, разбор документа, письмо, панели главного экрана. Модель видит по одной короткой строке о каждом включённом скилле и сама подгружает его полный текст, когда задача подходит, — пока скилл не нужен, он почти не тратит токены.

Окно скиллов открывается кнопкой **Скиллы ИИ** в боковой панели, из меню «+» поля ввода или по ++Ctrl+5++.

## Вкладки окна

| Вкладка | Что там |
| --- | --- |
| Встроенные | скиллы, которые идут с MemuAI: их можно выключить, поправить или удалить — удалённые возвращает пункт меню «Вернуть удалённые встроенные» |
| Мои | ваши скиллы: **Новый скилл**, «Импорт из файла» (`SKILL.md`, `.zip`, `.json`) и «Импорт по ссылке» (GitHub или `.md`) |
| Каталог | скиллы из открытых репозиториев: текст можно прочитать до того, как добавить скилл к себе |

В меню окна есть ещё «Включить все», «Выключить все» и «Экспорт моих скиллов» — ваши скиллы одним архивом `.zip` в формате Agent Skills.

## Одна библиотека для всех приложений

MemuFiles, MemuNote, MemuCode, MemuCode CLI и модули берут скиллы из той же библиотеки, что и чат MemuAI. Выключили скилл в окне — он выключен везде; поправили текст — новая версия сразу работает во всех приложениях. MemuAI Proxy скиллы не использует: он только передаёт запросы моделям.

У агента кода есть и свои скиллы (пункт меню «Скиллы MemuCode») — см. [MemuCode](doc:memucode#скиллы).

## Где работает скилл

На странице скилла есть блок **Где работает** — по переключателю на каждое место. По умолчанию:

| Место | Какие скиллы работают |
| --- | --- |
| Чат MemuAI | все |
| MemuFiles (ИИ-ассистент) и MemuNote | все, кроме «Панелей» и «Справки по MemuAI» |
| MemuCode и MemuCode CLI | те же, кроме четырёх, у которых в MemuCode есть свой вариант: «Ревью кода», «Отладка и корневая причина», «Безопасность», «Коммиты и чейнджлоги» |
| Модули MemuMeet, MemuLearn, MemuAI Studio и MemuAI Design | как в MemuFiles |
| Остальные модули | ни одного: нужный скилл включается для модуля вручную |

«Панели» и «Справка по MemuAI» работают только в чате MemuAI: их инструкции вызывают инструменты, которые есть только там (создание панелей, чтение документации). Вместо переключателей у них замок и причина.

Место, выбранное вручную, отмечено точкой, а кнопка **По умолчанию** возвращает исходный набор. Например, чтобы скилл для кода работал только в MemuCode и MemuCode CLI, выключите у него чат MemuAI, MemuFiles и MemuNote.

## Все скиллы для одного места

Пункт меню **Где работают скиллы** показывает приложения и модули со счётчиком «Скиллов работает здесь» и кнопками **Все** и **Ни одного** — одним нажатием можно, например, убрать все скиллы из MemuCode CLI. В списке модулей — те, что обращаются к моделям; модуль, выключенный в меню модулей, помечен.
