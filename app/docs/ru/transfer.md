# Перенос данных

**Настройки → Данные** собирает всё, что нужно для переезда: с другого ассистента в MemuAI, с одного компьютера на другой или просто для резервной копии.

## Чаты

**Экспортировать все чаты** выгружает всю историю текущего профиля одним файлом JSON в `Загрузки\MemuAI`.

**Импортировать чаты** загружает историю из файла. Поддерживаются:

| Источник | Какой файл |
| --- | --- |
| ChatGPT | `conversations.json` из выгрузки данных (Settings → Data controls → Export data) |
| Claude | `conversations.json` из выгрузки (Settings → Privacy → Export data) |
| Gemini | выгрузка чатов в формате JSON |
| MemuAI | файл, выгруженный кнопкой выше, или экспорт одного чата в JSON |

Перед загрузкой MemuAI показывает, сколько чатов нашлось. По умолчанию они добавляются к уже существующим; отметка **Заменить все текущие чаты** сначала очищает историю. Импортированные чаты появляются в общем списке и работают как обычные.

Отдельный чат выгружается из его меню — см. [Чаты](doc:chats#экспорт).

## Информация о себе

Другой ассистент, которым вы давно пользуетесь, многое о вас знает. **Импортировать информацию о себе** переносит это в [память](doc:memory) MemuAI:

1. Скопируйте готовый промпт из окна импорта.
2. Отправьте его в тот ассистент — ChatGPT, Claude или другой.
3. Вставьте его ответ обратно в MemuAI.
4. Выберите модель-обработчика — она разложит ответ на отдельные факты.
5. Просмотрите факты, уберите лишнее и сохраните.

Если модель недоступна, MemuAI разберёт ответ сам, попроще.

## Мемесы

[Мемесы](doc:agents) передаются файлами `*.memu-agent.json`: **Экспортировать мемесов** и **Импортировать мемесов**. При импорте MemuAI всегда просит выбрать модель: исходной на новом компьютере может не быть.

## Модули и темы

- Модули переносятся файлом `*.memu-module.json` из **Настройки → Модули** — см. [Мастерская](doc:modules-workbench).
- Свои темы — это файлы `.css`: экспорт и импорт в **Настройки → Внешний вид** — см. [Свои темы](doc:themes).

## Переезд целиком

Чтобы перенести всё — аккаунты, настройки, профили, модели Proxy, — скопируйте папку `%APPDATA%\MemuAI` на новый компьютер, пока MemuAI и Proxy там выключены. Подробности — [Где хранятся данные](doc:data).

> [!WARNING]
> В этой папке лежат куки и токены ваших аккаунтов. Передавайте её только на свой компьютер и не выкладывайте в облако общего доступа.

См. также: [Где хранятся данные](doc:data).
