# `manifest.json`

Файл описывает модуль целиком: как он называется, как открывается, что помнит и к каким возможностям просит доступ. Все поля необязательны кроме `id`.

```json
{
  "id": "my-notes",
  "title": "Мои заметки",
  "title_en": "My notes",
  "summary": "Быстрые заметки с сохранением.",
  "summary_en": "Quick notes that stay saved.",
  "version": "1.0",
  "author": "Вы",
  "icon": "text",
  "accent": "#d97757",
  "launcher": { "hidden": false, "slot": "sidebar", "order": 0 },
  "window": {
    "default_width": 720,
    "default_height": 520,
    "min_width": 320,
    "min_height": 240,
    "max_width": 2400,
    "max_height": 1600,
    "fixed": false,
    "resizable": true,
    "size_mode": "user",
    "center": true
  },
  "persist": ["text", "model"],
  "permissions": ["chat", "storage", "models"],
  "bridge": {
    "model": "",
    "instructions": "Ты ведёшь короткие заметки.",
    "keep_in_chat": false,
    "thinking": false,
    "web_search": false
  }
}
```

## Поля верхнего уровня

| Поле | Смысл | Предел |
| --- | --- | --- |
| `id` | Идентификатор. Обязателен при создании, потом не меняется | латиница, цифры, дефис, 41 |
| `title` / `title_en` | Название на русском и английском | 80 символов |
| `summary` / `summary_en` | Описание в разделе настроек | 400 символов |
| `version` | Версия модуля, показывается на карточке | 24 символа |
| `author` | Автор | 80 символов |
| `icon` | Иконка: имя значка, файл пакета (`icon.svg`/`.png`/`.webp`/`.ico`) или встроенный `<svg>`. См. [Иконка модуля](#иконка-модуля) | 48 КБ встроенный SVG |
| `icon_bg` | Фон под значком: `#rrggbb` или список из 2–3 цветов (градиент) | 3 цвета |
| `accent` | Свой цвет модуля в виде `#rrggbb` | 3–8 hex-знаков |
| `default_locale` | Язык словаря, который берётся, если перевода на язык MemuAI нет. См. [Переводы модуля](doc:modules-i18n) | `ru` по умолчанию |

### Значки

`text`, `chat`, `sparkle`, `zap`, `image`, `work`, `bot`, `settings`, `palette`, `search`, `globe`, `list`, `clock`, `bell`, `keyboard`, `user`, `users`, `monitor`, `terminal`, `target`, `mic`, `headphones`, `volume`, `download`, `folder`, `info`, `play`, `undo`, `redo`, `scissors`, `clipboard`, `branch`, `pin`, `edit`, `trash`, `copy`, `retry`, `attach`, `send`, `stop`, `temp`, `focus`, `brain`, `export`, `check`, `unread`, `moon`, `sun`, `menu`, `back`, `forward`, `sidebar`, `plus`, `more`, `close`, `bell`.

Незнакомое имя рисует значок по умолчанию — ошибки не будет.

## Иконка модуля

Иконка видна везде: кнопка в боковой панели, пилюля свёрнутого окна, шапка окна, карточка в «Настройки → Модули»,
карточки модуля в чате и Быстром доступе, окно модуля-приложения, его кнопка на панели задач и ярлыки в «Пуске» и на рабочем столе
(`.ico` MemuAI делает сам).

Три способа задать её в `manifest.json`:

| Значение `icon` | Как выглядит |
| --- | --- |
| `"bell"` — имя значка из списка выше | белый значок на скруглённом квадрате; цвет — `icon_bg`, иначе `accent`, иначе градиент MemuAI, подобранный по `id` |
| `"icon.svg"` — файл пакета (`.svg`, `.png`, `.webp`, `.ico`; можно в папке, `assets/icon.svg`) | ваша картинка как есть |
| `"<svg viewBox=\"0 0 512 512\">…</svg>"` или `data:image/png;base64,…` | то же, без отдельного файла (так модуль сохраняется при экспорте) |

```json
{ "icon": "icon.svg" }
{ "icon": "list", "icon_bg": ["#5f86f7", "#6142d4"] }
```

**Как нарисовать иконку в стиле MemuAI** (так сделаны все встроенные модули):

- холст `viewBox="0 0 512 512"`, скруглённый квадрат `<rect x="28" y="28" width="456" height="456" rx="118">` с диагональным градиентом двух близких цветов;
- сверху — мягкий блик (радиальный градиент белого 35–40% в левом верхнем углу) и тонкий светлый кант по краю;
- светлый крупный глиф (≈ 260–290 px из 512), заливкой, с мягкой тенью; маленькая четырёхлучевая «искра» — фирменная деталь;
- проверьте вид в 16, 20, 32 и 256 px на светлой и тёмной теме: мелкие детали в 16 px пропадают.

**Безопасность.** SVG очищается: остаются только графические элементы и атрибуты; `script`, `foreignObject`, обработчики `on…`,
`DOCTYPE`/`ENTITY` и любые внешние ссылки (`http:`, `url(http…)`, `@import`) удаляются, ссылки допускаются только на `#id` внутри файла
и на растровые `data:image/…`. Картинка показывается тегом `<img>`, поэтому скрипты в ней не выполнятся в любом случае.
Размер: файл до 256 КБ, встроенный SVG до 48 КБ, PNG/WebP/ICO до 768 КБ. «Проверить» в Мастерской подскажет, если с иконкой что-то не так.

**Пользователь может заменить иконку любого модуля** — в меню кнопки модуля, в «⋯» карточки или щелчком по иконке на карточке:
набор MemuAI, значок на градиенте, эмодзи на градиенте, свой файл (SVG/PNG/ICO/WebP) или «Вернуть иконку модуля».
Замена хранится в данных MemuAI (`modules/icons/`), не в пакете, и не теряется при обновлении модуля.

## `launcher`

- `hidden` — скрыть кнопку, оставив модуль включённым (`true` полезен для модулей-помощников, которые открываются из другого места).
- `slot` — где стоит кнопка: `sidebar` (под пунктами «Планирование» и «Скиллы»), `chat-list` (над списком чатов), `topbar` (на верхней полосе), `composer` (у поля ввода).
- `order` — порядок внутри места, `0`–`9999`. Меньше — выше.

Порядок и место меняются пользователем и хранятся отдельно от пакета: правка `manifest.json` их не перезаписывает.

## `persist`

Список полей, которые разрешено помнить. Имя — до 40 символов, всего до 32 штук. `Memu.save` игнорирует всё, чего нет в списке.

> Не добавляйте сюда изображения и большие тексты «на всякий случай»: каждое сохранение пишет файл. Одна картинка в data-URL весит больше, чем весь остальной модуль.

## `permissions`

Что модуль просит у MemuAI. Если список не указан, модуль получает все права, кроме `net-import` и `music`, — так работают пакеты, созданные до появления прав. Доступные значения: `chat`, `media`, `storage`, `models`, `files`, `download`, `notify`, `external`, `web`, `clipboard`, `background`, `net-import`, `music`. Подробности — в разделе «Права модуля».

## `net_import`

Только вместе с правом `net-import`: `{"sources": [...], "hosts": [...]}` — какими источниками импорта пользуется модуль (`chub`, `chub-lorebook`, `janitor`, `pygmalion`, `aicc`, `risu`, `perchance`, `generic`; без поля — всеми) и сайты для прямых ссылок на PNG/JSON по умолчанию. Человек может заменить список сайтов в Настройках → Модули → ⋯ → Источники импорта. См. `Memu.fetchImport`.

## `bridge`

Значения по умолчанию для моста. Код модуля может заменить любое из них при вызове.

- `model` — идентификатор модели MemuAI. Пустая строка означает «пользователь выберет».
- `instructions` — системный текст. До 20 000 символов. Заменяется целиком, а не дополняется.
- `keep_in_chat` — дописывать ход в чат `module-<id>`, чтобы он появился в списке чатов.
- `thinking` — просить размышления, если модель умеет.
- `web_search` — просить веб-поиск, если модель умеет.
