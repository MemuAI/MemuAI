# Агенты и мемесы

В MemuAI два разных механизма, и их легко спутать:

- **агенты** — помощники, которые параллельно делают части одной задачи в Work и MemuCode;
- **мемесы** — ваши собственные ассистенты с именем, инструкциями и своей историей чатов.

## Агенты в Work и MemuCode

Агент — отдельный исполнитель с собственным заданием. Он работает в фоне, пока основная модель занимается своей частью: один агент изучает, как устроена авторизация, другой ищет все места, где вызывается старая функция, третий читает тесты — а основная модель в это время пишет код и забирает их отчёты, когда они готовы.

**В обычном чате агентов нет.** Раньше чат мог сам разделить запрос между «агентами-специалистами»; это делало ответы медленнее и дороже там, где агенты не нужны, и убрано. Для большой темы с десятками источников в чате есть [Глубокое исследование](doc:research).

### Когда агенты запускаются

Только когда вы об этом попросили:

- словами в сообщении — «используй агентов», «сделай это параллельно», «запусти фоновую задачу»;
- переключателем **Агенты** в меню «+» (он есть только в Work и MemuCode) или командой `/agents` — тогда модель может запускать агентов в этом чате, когда сочтёт нужным.

Без такой просьбы запрос на запуск агента отклоняется, и модель делает работу сама.

### Как это выглядит

В ответе появляется карточка агентов: у каждого — задание, состояние и то, чем он занят сейчас. Основная модель не ждёт их: она продолжает работу и получает отчёты по мере готовности, а когда все закончили — сводит результаты. Кнопка **Стоп** останавливает и ответ, и всех агентов.

### Что агентам можно

| | |
| --- | --- |
| Читать файлы проекта, искать по коду, смотреть структуру | всегда |
| Искать в интернете | если в чате включён веб-поиск |
| Менять файлы и запускать команды | только при режиме доступа «Полный доступ» |

Одновременно работают до четырёх агентов, за один разговор — не больше 24; каждый делает не больше 16 шагов. Агент не может запускать своих агентов.

### Настройки

**Настройки → Work и агенты → Агенты**:

| Настройка | Что делает |
| --- | --- |
| Модель агентов | одна модель для всех агентов; по умолчанию — модель чата. Для поиска по коду и чтения файлов хватает быстрой недорогой модели |
| Агентов одновременно | от 1 до 4. Больше — быстрее, но больше запросов к модели |

В [MemuCode CLI](doc:memucode-cli) то же правило задаёт настройка `subagents`: `ask` — только по просьбе (по умолчанию), `auto` — модель решает сама, `off` — никогда.

## Мемесы

Мемес — ассистент со своей ролью: «Редактор текстов», «Юрист-консультант», «Учитель английского». У каждого мемеса свои инструкции и свои чаты в разделе **Мемесы** боковой панели.

### Создание

Кнопка ＋ у заголовка «Мемесы» открывает мастер из четырёх шагов:

1. **Имя и инструкции** — как зовут, описание, что и как делать.
2. **Модель и режимы** — модель мемеса (или текущая модель чата), веб-поиск сразу включён, режим размышлений, «Строго держаться темы агента».
3. **Доступные возможности** — что мемесу разрешено.
4. **Проверка и подтверждение** — сводка перед сохранением.

Кнопка **Создать с помощью ИИ** заполняет мастер по короткому описанию: «помощник для подготовки к собеседованиям на позицию аналитика».

### Возможности

| Возможность | Что даёт |
| --- | --- |
| Планирование и расписания | создавать задачи по расписанию |
| Сообщения о работе в Telegram | присылать уведомления через бота |
| Локальные инструменты (Tools) | пользоваться встроенными инструментами MemuAI |
| Интеграции | GitHub, Google Drive, Google Календарь |
| Файлы и изображения | принимать вложения |
| Долгая память | видеть и пополнять вашу память |
| Скиллы ИИ | подключать готовые приёмы работы |

Выключенная возможность недоступна мемесу даже по прямой просьбе.

### Чаты мемеса

Новый чат с мемесом начинается из его строки в боковой панели. Инструкции мемеса имеют наивысший приоритет. Если у мемеса закреплена модель или режим поиска, в его чатах их нельзя сменить — на месте переключателя видна пометка.

Порядок разделов «Папки», «Мемесы», «Чаты» меняется перетаскиванием заголовков или кнопкой ⇅. Аватар мемеса выбирается случайно из двенадцати рисунков и палитр — его можно перегенерировать.

### Перенос

Мемесов можно экспортировать в файл `*.memu-agent.json` и импортировать на другом компьютере: **Настройки → Данные → Мемесы**. При импорте MemuAI всегда просит выбрать модель заново — на другом компьютере может не быть исходной.

### В Telegram

Если настроен [Telegram-бот](doc:notifications), команда `/agents` в нём открывает список мемесов, и с ними можно общаться прямо из Telegram.
