# Интеграции

**Настройки → Интеграции**. Подключите сервис один раз — дальше ассистент сам найдёт письмо, посмотрит расписание, прочитает документ на Диске или страницу Notion, откроет репозиторий — в чате, в Work и в быстром доступе (Alt+Space).

## Telegram Use — личный аккаунт

Telegram Use подключает **ваш личный аккаунт**, отдельно от Telegram-бота MemuAI. После подключения можно попросить в обычном чате: «Найди Ивана Ивановича и кратко перескажи последние 50 сообщений». Те же инструменты доступны в MemuCode CLI; окно MemuAI должно оставаться запущенным. При совпадении имён уточните контакт: ассистенту нужен однозначный чат.

1. Откройте **Telegram Use**, включите его. В [my.telegram.org/apps](https://my.telegram.org/apps) получите **API ID и API hash**, вставьте оба значения. Настройки сохраняются автоматически; дождитесь сообщения **Все изменения сохранены**. Оба значения нужны и для входа по QR; API ID сам по себе недостаточен.
2. Нажмите **Показать QR**. На телефоне: Telegram → **Настройки → Устройства → Подключить устройство**, отсканируйте код. Либо раскройте **Войти по номеру телефона вместо QR**, введите номер с кодом страны и код Telegram. Если включён облачный пароль 2FA, введите его в появившемся поле. Перед началом входа MemuAI сохраняет заполненные настройки.
3. Дождитесь статуса подключённого аккаунта. API hash и сессия защищены хранилищем Windows; коды входа и пароль 2FA не сохраняются. При обычной правке настроек пустое поле API hash сохраняет уже записанное значение.

Ассистент умеет находить чаты, искать и читать сообщения, отвечать, пересылать, редактировать **свои** сообщения, удалять, ставить реакции и отправлять файлы. В настройках отдельно разрешаются изменения. В обычном чате изменения проходят политику подтверждений; разрешение файловых правок `acceptEdits` в CLI не разрешает автоматически отправку в Telegram.

Перед отправкой или редактированием показан предпросмотр с форматированием Telegram: переносами строк, выделением, цитатами, кодом и ссылками. Для длинного сообщения видны все части, для подписи файла — фактически отправляемый сокращённый текст. Проверьте получателя и содержимое, затем подтвердите действие. Подготовка предпросмотра сама ничего не отправляет.

История передаёт модели явные сведения об авторе: ваши сообщения, собеседник, участник группы или автор канала. Это помогает пересказу правильно различать участников.

Для справки по инструментам: `telegram_use_dialogs` находит чат, `telegram_use_history` читает историю, `telegram_use_search` ищет сообщения, `telegram_use_media` распознаёт вложение, `telegram_use_send` отправляет сообщение.

### Если my.telegram.org не создаёт приложение

«Too many attempts. Please try again later.» возникает на стороне сайта Telegram, до подключения MemuAI. Прекратите повторные отправки формы; проверьте, нет ли у этого номера уже созданного приложения (на номер допускается один API ID). Его API ID/hash можно использовать повторно. Иначе повторите позже или обратитесь в [поддержку Telegram](https://telegram.org/support). Точный срок ожидания сайт не сообщает. QR-вход также требует API ID и hash; публичные чужие ключи не заменяют ваше приложение. Прокси MemuAI влияет на соединение Telegram Use, а не на сайт my.telegram.org в браузере.

Если для сайта включён VPN, попробуйте выключить его при входе или создании приложения: общий адрес VPN иногда вызывает ограничения. Это не снимает серверный лимит Telegram. Для **генерации QR**, наоборот, нужен доступ к самому Telegram: если прямое соединение из России заблокировано, включите работающий VPN или настройте Telegram-прокси в MemuAI. Сайт и подключение Telegram могут требовать разных настроек сети.

### Команды в сообщениях Telegram

Отдельно включите **Обрабатывать команды в Telegram автоматически**. Команды используют общего ассистента MemuAI, его основные инструкции и характер. Дополнительная инструкция Telegram Use задаётся отдельно. При включённом веб-доступе ассистент может искать актуальные сведения и читать веб-страницы; инструменты изменения компьютера автоматическим командам не выдаются.

| Команда | Действие |
| --- | --- |
| `!//question <вопрос>` | Ответить на вопрос с контекстом переписки и доступным веб-поиском |
| `!//summary <count> [chat]` | Пересказать указанное число последних сообщений; число обязательно, от 1 до 1000 |
| `!//voice` | Распознать голосовое сообщение, **на которое вы ответили** командой |

`!//summary 50` читает текущую переписку. `!//summary 50 AI Telegram News` читает другой доступный вам чат или канал, а результат размещается в переписке, где отправлена команда, либо в MemuAI согласно настройке доставки. Название можно написать с пробелами без кавычек. Декоративные символы и небольшие опечатки учитываются: например, обычное название может найти `AI T@l@gram News`. При неоднозначном совпадении уточните числовой ID — случайный чат не выбирается. Если контекст слишком велик, ассистент получает пометку об обрезанном фрагменте. Другим разрешённым пользователям доступен пересказ только текущей переписки.

У каждой команды выбираются инструкция, текстовая модель, контекст и доставка: заменить свою команду, ответить в Telegram или сохранить новый чат MemuAI. Базовое форматирование, ссылки, цитаты и код работают без Premium; Premium-only custom emoji не отправляются. При неправильных аргументах своей команды MemuAI отвечает подсказкой, сохраняя исходное сообщение.

В редакторе можно добавлять свои команды и **аргументы по порядку**: текст, название чата, целое число, число, да/нет или один из вариантов. Имена аргументов задаются латиницей, цифрами и `_`. Задавайте обязательность, значение по умолчанию, диапазон и подсказку; используйте в инструкции `{argument_name}`. `{question}` содержит исходный текст после команды. Последний текстовый аргумент или название чата может занимать остаток строки с пробелами. Для действия «Пересказ переписки» нужен обязательный целочисленный `count` и, при необходимости, `chat` с типом «Название чата».

Разрешённые пользователи и чаты задаются числовыми ID; также настраиваются пауза и лимиты запросов в час/сутки. Пустой список других пользователей разрешает команды только вам. В группе другому пользователю нужны **оба** разрешения: его ID и ID группы. Чужое сообщение ИИ не редактирует — отвечает на него.

### Распознавание речи и очистка диктовки

Для `!//voice` **не нужна текстовая модель**, если очистка выключена. В Telegram Use откройте **Распознавание речи и очистка диктовки**. Выберите модель из **Голос и Live**, настройки **быстрого доступа**, отдельную локальную модель или Audio API из настроек голоса. Можно выбрать локальную модель и язык, включая автоматическое определение. Локальные модели скачиваются в «Голос и Live»; адрес и ключ Audio API переиспользуются оттуда же.

**Очищать диктовку после распознавания** — отдельный переключатель. Для очистки выбираются текстовая модель и инструкция: пустая инструкция исправляет пунктуацию, оговорки и абзацы, сохраняя смысл. Если очистка не удалась, сохраняется исходная расшифровка. Все изменения, включая команды и настройки речи, сохраняются автоматически; неполные поля остаются в форме с объяснением. **Сохранить сейчас** позволяет повторить сохранение после ошибки.

### Прокси и ограничения Telegram Use

В разделе **Настроить прокси** вставьте ссылку, например `tg://proxy?server=HOST&port=PORT&secret=SECRET` или `socks5://USER:PASS@HOST:PORT`, и дождитесь автосохранения. Поддержаны также `https://t.me/proxy`, `tg://socks`, `socks4://` и `http://`. Обычный MTProxy secret и secret с префиксом `dd` поддержаны; **`ee` / Fake-TLS не поддерживается**. Пустое поле сохраняет существующий прокси; для удаления есть отдельная галочка.

Доступны облачные чаты, к которым имеет доступ ваш аккаунт; **секретные чаты Telegram недоступны**. Изображения описывает vision-модель, видео — по выборке до шести кадров, а не по каждому моменту ролика. После входа проверьте чтение нужного чата; доступ зависит от вашего аккаунта, сети и прокси.

## Chrome · MemuAI — расширение браузера

1. В **Настройки → Интеграции → Chrome · MemuAI** нажмите **Скачать расширение** и распакуйте ZIP в постоянную папку.
2. В Chrome откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение**, выберите распакованную папку. Установка через магазин не требуется.
3. Откройте параметры расширения и нажмите **Подключить через MemuAI**. Ссылка `memuai://` откроет установленное приложение; подтвердите подключение в MemuAI. Адрес и одноразовый код передадутся автоматически. Если ссылка недоступна, раскройте **Подключить по коду или изменить адрес**: получите код в настройках Chrome-интеграции MemuAI, скопируйте показанный локальный адрес и код, нажмите **Подключить по коду**. Оставьте MemuAI запущенным.
4. В параметрах расширения нажмите **Разрешить доступ к сайтам**, если нужен контекст страниц. Кнопка расширения открывает боковую панель: выберите модель и чат либо создайте новый. Контекст страницы добавляется по вашему выбору; обычные вопросы работают без страницы.

Настройки чтения страниц, действий на вкладках (**Спрашивать / Разрешить / Запретить**), **DFY в моём Chrome**, расписания и истории доступны **прямо в параметрах расширения** и синхронизируются с MemuAI. Браузерное разрешение доступа к сайтам управляется отдельно — его выдаёт сам Chrome. Ассистент читает страницу и её элементы, открывает/закрывает вкладки, вводит текст и делает снимки в пределах этих разрешений. Обычный снимок требует активной вкладки. Внутренние страницы Chrome, магазин расширений и некоторые защищённые страницы ограничены самим браузером.

[Быстрый доступ](doc:quick-ask) предпочитает подключённое расширение для Chrome; без него или в другом браузере остаётся прежний способ чтения. [DFY](doc:dfy) подключается только отдельной галочкой, создаёт свои фоновые вкладки с вашими входами на сайты и не переключает вашу вкладку. Chrome показывает штатное уведомление отладки. Отключение расширения останавливает его задачи. Полностью отозвать сопряжение можно кнопкой **Отозвать доступ расширения** в MemuAI.

Инструменты браузера: `chrome_tabs` — список вкладок, `chrome_read` — текст и элементы страницы, `chrome_screenshot` — снимок, `chrome_open` / `chrome_navigate` / `chrome_close` — вкладки, `chrome_close_tabs` — закрытие выбранной группы вкладок, `chrome_action` — действие на странице. Например, «Закрой все вкладки с GitHub» можно выполнить групповым действием: в режиме «Спрашивать» показывается одно подтверждение со списком названий и адресов вкладок. Выполняются только вкладки, включённые в подтверждённый список.

Кнопка загрузки сохраняет ZIP в **Загрузки / MemuAI** и показывает путь; есть **Сохранить как…** и **Показать в папке**. Название модели открывает поиск; основная модель и закрепления общие с активным профилем MemuAI. Изменения закреплений и основной модели синхронизируются в обе стороны. Модель уже открытого разговора меняется в панели.

**Новые чаты по умолчанию сохраняются в отдельной истории браузера** и не появляются в основном списке MemuAI. Это локально сохранённые разговоры, а не режим без сохранения. В истории есть вкладки **В браузере / MemuAI / Все**. Переключатель **Показывать новые чаты в MemuAI** меняет место сохранения последующих разговоров; уже созданные чаты остаются на своих местах. Чаты проектов доступны для чтения с переходом в приложение.

Кнопка **Инструменты страницы** запускает краткий пересказ, объяснение простыми словами, перевод на русский или выделение фактов и действий. Чтение страницы и вызовы инструментов показываются отдельными этапами с состоянием выполнения и результатом. Доступны остановка генерации и копирование ответа/кода. Для вложений используйте скрепку, перетаскивание или вставку: до 5 МБ на файл, 8 файлов/4 изображения на запрос. Поддерживаются изображения, PDF с текстовым слоем, DOCX, текст и код; длинные документы сокращаются с отметкой.

**Панель справа:** в параметрах расширения откройте настройки внешнего вида браузера и выберите **Боковая панель → Справа**. Сторону панели задаёт Chrome; расширение не может изменить эту общую настройку самостоятельно. После обновления распакуйте ZIP в ту же папку и нажмите **Обновить** в chrome://extensions — так сохраняется ID и подключение.

## Telegram Use и Chrome в планировании

В [Планировании](doc:schedules) можно сохранить задание, использующее `telegram_use_*` или `chrome_*`: например, регулярно читать сообщения или работать с вкладками. Для изменений заранее включите разрешение изменений задачами Telegram Use либо **Действия по расписанию без запросов** у Chrome; для браузерного DFY также нужен **DFY в моём Chrome**. Сохранённые задания не ждут диалогов подтверждения. Запрет управления, выключенная интеграция и ограничения доступа продолжают действовать. MemuAI должен работать, а для Chrome нужен запущенный сопряжённый браузер. Telegram-прокси относится к Telegram Use; сеть Chrome настраивается в самом Chrome/системе.

## Как ассистент ими пользуется

Модель знает только, что может подключиться к сервису, если задача этого требует. «Что мне писала Анна на этой неделе?» превращается в вызовы `gmail_search` и `gmail_read`, «зайди в мой репозиторий memuai и прочитай README» — в `github_list_repos` и `github_read_file`.

**Запись** — отправка письма, черновик, метки и корзина, событие календаря, файл на Диске, страница Notion, коммит, pull request или новый репозиторий на GitHub — сначала показывается вам карточкой «Отправить письмо?», «Удалить файл навсегда?» с адресатом, темой, путём, временем и текстом и выполняется только после вашей кнопки. У разрушительных действий кнопка красная, а по Enter срабатывает «Отмена». **Всегда, даже при «Полном доступе»**, подтверждаются действия, которые нельзя отменить: отправка, ответ и пересылка письма, удаление писем и файлов Диска навсегда (мимо корзины), удаление репозитория и календаря. В быстром доступе ассистент только читает; записать что-то он предложит в основном чате.

Ключи и токены хранятся только на этом компьютере, токены Google и Notion — в защищённом хранилище Windows; в интерфейсе их не видно.

## Видео-инструкции

У каждой инструкции подключения есть кнопка **▶ Видео-инструкция** — ролик на полминуты без звука, с подписями по-русски и по-английски (кнопка **CC** их выключает; шаги под видео кликабельны). Шаги на сайтах Google, GitHub и Notion требуют входа, поэтому в роликах они показаны карточками с точными названиями кнопок сайта, а действия в MemuAI — настоящим интерфейсом:

- **Google** — мастер «свой OAuth-клиент» (проект, API, Google Auth Platform, тестовые пользователи, клиент Desktop app); тот же ролик — в **Синхронизации** рядом с «Как получить Client ID».
- **GitHub** — в справке «Как получить токен и какие права нужны».
- **Notion** — под шагами «Токен интеграции».

## Google: Gmail, Календарь, Диск, Документы, Таблицы, Задачи, Контакты

Один аккаунт Google на всё: тот же вход используют [резервные копии](doc:sync) и «Файлы с Google Диска» в чате.

1. Откройте **Google** в списке сервисов.
2. Отметьте галочками, к чему у MemuAI будет доступ: **Gmail**, **Google Calendar**, **Google Drive**, **Google Docs**, **Google Sheets**, **Google Tasks**, **Google Contacts**.
3. Нажмите **Войти через Google**. Откроется ваш браузер со страницей Google — войдите, **отметьте все галочки** и нажмите **Разрешить**. Вернитесь в MemuAI: вход подхватится сам, и MemuAI сразу проверит, включены ли API в вашем проекте Google Cloud.

Google спрашивает разрешение **только на отмеченные сервисы**. Сервис, включённый позже, — одна галочка: Google спросит о нём одном, уже выданное сохранится. Выключенная галочка просто убирает инструменты сервиса у ассистента.

| Сервис | Что разрешается | Что умеет ассистент |
| --- | --- | --- |
| Gmail | полный доступ к почте и фильтрам | поиск (`from:`, `subject:`, `newer_than:7d`, `is:unread`, `has:attachment`), чтение писем и цепочек, ответ (и «ответить всем»), пересылка с вложениями, вложения с компьютера и сохранение вложений, черновики, метки, архив, прочитано/непрочитано, звёздочка, корзина и возврат, удаление навсегда, массовые действия по запросу, фильтры, автоответ |
| Календарь | календари и события | расписание за любой период, события с гостями, ссылкой Google Meet, повтором и напоминаниями, перенос и правка, ответ на приглашение, занятость, свои календари |
| Диск | все файлы Диска | поиск по имени и тексту, чтение (Документы и Таблицы — текстом), загрузка с компьютера, папки, переименование, перенос, копия, корзина и возврат, удаление навсегда, доступ по почте и по ссылке, скачивание и экспорт в PDF, DOCX, XLSX и другие форматы |
| Документы | Google Docs | чтение, новые документы, дописывание и замена текста |
| Таблицы | Google Sheets | чтение и запись ячеек (формулы работают), добавление строк, новые таблицы и листы, очистка |
| Задачи | Google Tasks | списки, новые задачи со сроком, правка, отметка «выполнено», удаление |
| Контакты | Google Contacts | поиск, новые и изменённые контакты, удаление |

**Выйти** отзывает доступ у Google и забывает токен — вместе с ним отключаются копии и выбор файлов с Диска.

### «Базовый доступ» и «Расширить доступ»

Если вы входили в Google в прошлых версиях MemuAI, у Gmail и Диска будет пометка **базовый доступ**: читать и отправлять можно, а удаление, метки, переименование и т. п. требуют более широкого разрешения. Нажмите **Расширить доступ** — Google спросит ещё раз, уже выданное сохранится. Пока доступ не расширен, ассистент сам скажет, что нужно нажать, и ничего не отправит в Google зря.

### «Проверить API» и ошибка «нет доступа»

Чтобы Google отвечал, каждый сервис нужно **включить (Enable) в вашем проекте Google Cloud** — это отдельный шаг, вход в аккаунт его не заменяет. Если API выключен, ассистент и строка сервиса покажут, какой именно, и дадут прямую ссылку **Включить** — на странице Google нажмите **Enable** и через минуту **Проверить API**. Кнопка **Включить все одной кнопкой** открывает включение всех выключенных API сразу.

### Если нужен свой OAuth-клиент

Google пускает приложения только через зарегистрированный «OAuth-клиент». Если в вашу сборку MemuAI он встроен, вход — в одну кнопку. Если нет, раздел Google покажет пошаговый мастер с прямыми ссылками (около 5 минут, один раз):

1. **Новый проект** в [Google Cloud Console](https://console.cloud.google.com/projectcreate) — любое имя.
2. **Включите все семь API** — кнопка «Включить все API» или по одному: [Gmail API](https://console.cloud.google.com/apis/library/gmail.googleapis.com), [Google Calendar API](https://console.cloud.google.com/apis/library/calendar-json.googleapis.com), [Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com), [Google Docs API](https://console.cloud.google.com/apis/library/docs.googleapis.com), [Google Sheets API](https://console.cloud.google.com/apis/library/sheets.googleapis.com), [Google Tasks API](https://console.cloud.google.com/apis/library/tasks.googleapis.com), [People API](https://console.cloud.google.com/apis/library/people.googleapis.com) (контакты). Проверьте, что сверху выбран ваш проект.
3. **Экран согласия** ([Google Auth Platform → Branding](https://console.cloud.google.com/auth/branding)): **Get started** → имя приложения и ваша почта → Audience: **External** → контактная почта → **Create**. Области доступа (Data Access) добавлять не нужно — MemuAI запросит их сам.
4. **Тестовые пользователи** ([Audience](https://console.cloud.google.com/auth/audience)): **Test users → Add users** → ваш Gmail. В режиме Testing Google просит входить заново раз в 7 дней; чтобы не просил — **Publish app**. Для личного клиента Google покажет «Приложение не проверено» — это нормально: **Дополнительные настройки → Перейти на страницу…**.
5. **Создать клиент** ([Clients → Create client](https://console.cloud.google.com/auth/clients/create)): Application type **Desktop app** → Create. Скопируйте **Client ID** и **Client secret** или нажмите **Download JSON** — секрет Google показывает только один раз.
6. Вставьте их в мастер (или **Загрузить JSON**), **Сохранить**, затем **Войти через Google**.

Мастер подставляет в ссылки номер вашего проекта (он есть в начале Client ID), поэтому после сохранения клиента ссылки открывают именно ваш проект.

**Галочка «Use this client for an AI-powered agent»** при создании клиента — необязательна, её можно оставить в любом положении. По [справке Google](https://support.google.com/cloud/answer/15549257) это только самодекларация «клиентом пользуется ИИ-агент»: дополнительных прав она не даёт, а нужна MCP-серверам Google. MemuAI обращается к обычным API Google, поэтому с галочкой и без неё всё работает одинаково.

Вход идёт по стандарту для настольных программ: MemuAI ждёт ответа Google на `127.0.0.1` (случайный порт) с защитой PKCE, пароль вводится только на странице Google.

## Notion

Два способа:

- **Токен интеграции** — самый простой. В портале разработчика Notion (**[app.notion.com/developers](https://app.notion.com/developers)**, или в Notion **Settings → Connections → Go to developer portal**) откройте **Internal connections → Create a new connection**, задайте имя и рабочее пространство. На вкладке **Configuration** скопируйте **API token** (начинается с `ntn_`, у старых интеграций — `secret_`) и вставьте его в поле. Затем дайте доступ к страницам: вкладка **Content access → Edit access** или на самой странице **«•••» → Connections → + Add connection →** ваше подключение. Доступ к родительской странице открывает и все вложенные.
- **Войти через Notion** — кнопка появляется, если в сборку встроен OAuth-клиент Notion или вы указали свой (публичная интеграция, раздел «Свой OAuth-клиент Notion»; в её настройках Redirect URI — `http://127.0.0.1:47652/notion/callback`). Откроется браузер, где вы выберете страницы для MemuAI.

| Инструмент | Что делает |
| --- | --- |
| `notion_search` | поиск страниц и баз |
| `notion_read_page` | текст страницы (заголовки, списки, задачи, код) и свойства |
| `notion_query_database` | строки базы данных |
| `notion_create_page` | новая страница из Markdown — с подтверждением |
| `notion_append` | дописать на страницу — с подтверждением |
| `notion_get_database` | свойства базы и варианты значений — чтобы правильно заполнить строку |
| `notion_update_page` | заголовок, свойства (простыми значениями: `"Статус": "Готово"`, `"Срок": "2026-10-16"`), иконка |
| `notion_delete_page`, `notion_restore_page` | в корзину Notion и обратно |
| `notion_replace_content`, `notion_delete_block` | заменить содержимое страницы, удалить блок |
| `notion_comment` | комментарий к странице |

Если ассистент пишет, что страница «не найдена», — к ней не дан доступ: добавьте подключение в **Connections** страницы (или в **Content access** в портале разработчика).

## GitHub

Репозитории, файлы, ветки, pull request, issues, релизы, gists и Actions — по персональному токену. Подходит любой из двух видов.

**Classic — проще всего:** github.com → **Settings** → **Developer settings** → **Personal access tokens** → **Tokens (classic)** → **Generate new token (classic)**. Отметьте scopes `repo`, `workflow`, `gist`, `delete_repo` (для репозиториев организаций — ещё `read:org`), скопируйте токен (`ghp_…`).

**Fine-grained — точнее:** там же → **Fine-grained tokens** → **Generate new token**. Repository access — **All repositories** (иначе ассистент не сможет создавать новые репозитории) или выбранные. Repository permissions — **Read and write**: Administration (создание, удаление, переименование, видимость, участники), Contents, Issues, Pull requests, Actions, Workflows; Metadata — Read. Account permissions: **Gists** — Read and write. Скопируйте токен (`github_pat_…`).

Вставьте токен в поле **Personal Access Token** и нажмите **Сохранить** — MemuAI проверит его и покажет вид токена и каких scopes не хватает. Если GitHub отказывает в действии, ассистент назовёт нужное право (GitHub сам сообщает его в ответе).

**Репозиторий по умолчанию** (необязательно) — например, `me/notes`: тогда в просьбах его можно не называть. Удаление репозитория и добавление/удаление участников всегда требуют явно названного репозитория.

| Инструменты | Что делают |
| --- | --- |
| `github_status`, `github_list_repos`, `github_repo_info`, `github_search_repos` | токен, репозитории, поиск |
| `github_create_repo`, `github_update_repo`, `github_fork_repo`, `github_delete_repo` | создать (в т. ч. из шаблона и в организации), переименовать, видимость и настройки, форк, удалить (всегда с подтверждением) |
| `github_list_files`, `github_read_file`, `github_search_code` | файлы и поиск по коду |
| `github_write_file`, `github_commit_files`, `github_move_file`, `github_delete_file` | записать файл, коммит из многих файлов, переместить/переименовать файл или папку, удалить файл или папку |
| `github_list_branches`, `github_create_branch`, `github_delete_branch`, `github_list_commits`, `github_get_commit`, `github_compare`, `github_list_tags` | ветки, коммиты, сравнение, теги |

## Для сборщиков: встроенный вход в один клик

Владелец сборки может встроить свой OAuth-клиент: переменные окружения `MEMUAI_GOOGLE_CLIENT_ID`, `MEMUAI_GOOGLE_CLIENT_SECRET` (клиент типа Desktop app), `MEMUAI_NOTION_CLIENT_ID`, `MEMUAI_NOTION_CLIENT_SECRET` (публичная интеграция) перед `build.py` — или файл `oauth_clients.local.json` рядом с `build.py`. Тогда пользователям мастер не нужен. Свой клиент пользователя всегда главнее встроенного.

## Отключение

**Выйти** у Google и **Отключить** у Notion отзывают доступ и удаляют токены с компьютера. У GitHub **Отключить** удаляет токен; сам токен стоит отозвать на сайте GitHub, если он больше не нужен.
