# Визуализации в ответах

MemuAI может вставлять на любое место ответа схемы с ветвлениями, сортируемые рейтинги, сравнения, диаграммы, таблицы, временные шкалы, карточки, вкладки, раскрывающиеся пояснения и небольшие калькуляторы. Блоки используют тему приложения и работают с клавиатуры. У диаграммы можно раскрыть таблицу исходных чисел.

Название понятия с подчёркиванием открывает панель справа: краткое описание, иллюстрации, факты и ссылки из этого сообщения. Панель не проверяет сведения самостоятельно: модель должна приложить надёжные источники. Изображения из интернета загружаются через защищённый медиапрокси; ссылки на локальную сеть блокируются.

В **Настройки → Чат → Что может быть в ответах** можно отключить все визуализации, только кастомные HTML-блоки или только изображения. При отключении визуализации остаётся её текстовое содержание. Команда `/visual` явно запрашивает визуальный ответ в текущем чате.

При копировании и экспорте сообщения сохраняются названия, значения, шаги и пояснения, а не JSON или код интерфейса. Для кастомного блока используется приложенное моделью текстовое резюме.

## Инструменты для модели и авторов промптов

`visual_schema` возвращает формат и поддерживаемые компоненты, `visual_validate` проверяет структуру перед выводом. Эти локальные инструменты не вызывают провайдера и не изменяют файлы. В обычном чате и Команде используется один рендерер.

Нативный блок — JSON в ограждении `memuai-visual`:

```json
{"type":"text","title":"Варианты","blocks":[{"type":"ranking","max":10,"items":[{"name":"Первый","value":9,"detail":"Обоснование оценки"}]}]}
```

Набор компонентов включает `flow`, `branch`, `ranking`, `comparison`, `entity`, `chart`, `table`, `timeline`, `metrics`, `cards`, `columns`, `tabs`, `accordion`, `calculator`, `progress`, `callout`, `list`, `code`, `quote` и обычный текст. Формулы калькулятора допускают арифметику и ограниченный набор математических функций, без исполнения JavaScript.

Для кликабельного термина модель прикладывает JSON в `memuai-entity` с `id`, `name`, `summary`, необязательными `image`, `facts`, `sources` и `inline_only:true`, затем пишет `[[entity:id|Название]]` вне кода. Панель использует только приложенные данные.

Кастомный вариант: `{"type":"custom","summary":"Понятное текстовое резюме","html":"<div>…</div>"}`. Он исполняется в отдельном iframe: без доступа к данным MemuAI, cookies, хранилищам, внешним скриптам и сети. Старые HTML-визуализации совместимы. Большие научные графики и материалы для публикации лучше создавать отдельным файлом.
