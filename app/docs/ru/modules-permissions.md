# Права модуля

Права перечисляются в `permissions`. Если список не указан, модуль получает все, кроме `net-import`, `music` и `learn`, — так работают пакеты, созданные до появления прав.

| Право | Что открывает | Методы |
| --- | --- | --- |
| `chat` | запросы к моделям | `request`, `stream`, `history` |
| `media` | генерацию медиа | `image`, `video`, `speak`, `transcribe`, `record`, `music` |
| `storage` | память между запусками | `save` |
| `models` | список моделей | `models` |
| `files` | разбор документов | `extract` |
| `download` | запись в загрузки | `download`, `handoff` |
| `notify` | уведомления | `notify` |
| `external` | открытие в системе | `open` |
| `web` | сеть через MemuAI | `search`, `fetch` |
| `background` | фоновые задания в Proxy | `monitor` |
| `clipboard` | буфер обмена | `copy` |
| `chat` | полный массив сообщений | `complete` |
| `storage` | большое файловое хранилище | `store.*` |
| `net-import` | загрузку карточки персонажа или лорбука по ссылке через MemuAI (объявляется явно) | `fetchImport` |
| `music` | музыкальную библиотеку MemuMusic: треки, плейлисты, скачивание по ссылке, тексты, плеер (объявляется явно) | `music.call` |
| `learn` | курсы, карточки и повторение MemuLearn (объявляется явно) | `learn.call` |

Права не требуются для `routes`, `env`, `resize`, `log`, `close` и `host` — это среда.

## Импорт по ссылке (`net-import`)

Единственный способ для модуля получить что-то из интернета по адресу. В неявные «все права» оно не входит: модуль должен сам указать `net-import`. Скачать можно немногое — карточку персонажа или лорбук из источников блока манифеста `net_import` (chub, лорбук chub, JanitorAI, Pygmalion, AICharacterCards, RisuRealm, Perchance и прямые ссылки на разрешённые сайты), см. [Импорт по ссылке](doc:modules-bridge-app).

- Скачивает MemuAI, а не модуль: только публичные адреса HTTPS на порту 443, проверяется каждый ответ DNS и адрес, к которому реально подключились (никаких localhost, локальной сети, link-local), каждое перенаправление проверяется заново, есть пределы размера и времени.
- Перед первой загрузкой с сайта MemuAI спрашивает человека: **Один раз**, **Всегда для этого сайта** или **Не разрешать**. «Всегда» запоминается для этого модуля.
- Настройки → Модули → ⋯ → **Источники импорта** показывают, какие сайты больше не спрашивают, и список сайтов для прямых ссылок (как `whitelistImportDomains` в SillyTavern). Меняет его только человек, модуль — не может.

## Музыкальная библиотека (`music`)

Round 37. `Memu.music.call(op, args)` → Promise с результатом; операции те же, что у встроенного модуля MemuMusic
(`library.list`, `library.get`, `library.like`, `playlists.list`, `playlist.create`, `download.start`, `download.jobs`, `search.online`,
`lyrics.get`, `player.state`, `player.command` и другие).
`Memu.music(body)` по-прежнему означает генерацию музыки (право `media`).

- В неявные «все права» не входит: модуль указывает `music` сам.
- У каждого трека есть адреса `stream` и `cover` с токеном: их можно прямо подставить в `<audio src>` и `<img src>` — для модуля с этим
  правом политика безопасности документа разрешает только эти два адреса MemuAI (`/api/pg/music/`), остальная сеть закрыта по-прежнему.
- Аудио отдаётся с поддержкой перемотки (HTTP Range). Скачивает и ищет MemuAI (yt-dlp), модуль сам в сеть не ходит.

## Курсы и карточки (`learn`)

Round 40. `Memu.learn.call(op, args)` → Promise с результатом; операции те же, что у встроенного модуля MemuLearn
(`overview`, `course.create`, `course.get`, `node.get`, `card.list`, `card.add`, `review.queue`, `review.answer`, `review.undo`, `stats`,
`exam.list`, `ai.prompt`, `ai.apply`, `source.ingest`, `import.apkg`, `export.apkg`, `import.csv`, `export.csv`, `panel` и другие).

- В неявные «все права» не входит: модуль указывает `learn` сам.
- Расписание FSRS считает MemuAI на этом компьютере; данные курсов общие для модуля MemuLearn, панели «Повторить сегодня» и вкладки «Тренажёр» в Mini App.
- Запросы к моделям (конспекты, карточки, экзамены) модуль делает сам через `Memu.request` — для этого нужно право `chat`.

## Что происходит без права

Вызов отклоняется с понятной ошибкой: «Модулю не разрешено…». Ошибка видна в интерфейсе модуля, так что автор сразу понимает причину.

## Минимум прав

Просите только нужное. Модуль-калькулятору хватает `storage`; модулю, который показывает список моделей, — `models`; переводчику нужны `chat`, `storage`, `models`, `files`, `download`.

## Зачем песочница

Модуль запускается в отдельном документе с флагом `allow-scripts` и без доступа к странице MemuAI:

- он не видит чаты, память, профиль и настройки MemuAI;
- он не может читать чужой DOM или подслушивать события;
- он не ходит в сеть напрямую;
- он не может закрыть или изменить MemuAI.

Единственный канал — сообщения с проверкой источника. Обратно уходят только данные, которые хост сам сформировал.

> Права ограничивают не доверие к автору, а масштаб случайного вреда: чужой модуль не должен уметь читать вашу переписку или стирать файлы.
