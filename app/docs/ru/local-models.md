# Локальные модели

Вкладка **Локальные модели** в MemuAI Proxy запускает открытые модели прямо на вашем компьютере. Для ответа не нужны ни интернет, ни аккаунт: интернет понадобится только один раз, чтобы скачать движок и саму модель.

Локальные модели работают как любые другие: они появляются в списке моделей MemuAI и в API Proxy с префиксом `local-`, например `local-qwen3-8b-q4-k-m`. В разделе «Аккаунты» для них автоматически создаётся аккаунт «Локальные модели».

## Что понадобится

| Что | Зачем |
| --- | --- |
| Движок llama.cpp | программа `llama-server`, которая загружает модель и отвечает на запросы |
| Файл модели `.gguf` | сами веса модели |
| Оперативная память или видеопамять | модель целиком загружается в память |

Справа на вкладке показано, сколько у компьютера памяти, какая видеокарта и сколько потоков у процессора. По этим данным MemuAI оценивает, какие модели здесь пойдут.

## Мастер подбора модели

Не знаете, какую модель выбрать? Нажмите **Подобрать модель** в карточке сверху вкладки. Мастер проходит четыре шага:

1. **Компьютер** — что найдено: видеокарта и её видеопамять (точно, через DXGI и `nvidia-smi`), процессор (ядра, потоки, AVX2/AVX-512), объём и тип оперативной памяти, свободное место на диске, установлен ли движок. **Другой компьютер…** позволяет указать видеопамять и ОЗУ вручную — например, чтобы подобрать модель для другого ПК.
2. **Задачи** — общение, программирование, агенты и инструменты (MemuCode), картинки и скриншоты, сложные рассуждения, длинные документы; язык общения (русский, английский, оба).
3. **Приоритеты** — качество или скорость, длина контекста (авто или 8K–128K), сколько памяти оставить другим программам, условие на лицензию (любая, можно в коммерции, только Apache 2.0/MIT), по желанию MTP-ускоритель.
4. **Рекомендации** — модели по местам. У каждой: квантизация (можно выбрать другую), примерная скорость в токенах в секунду, где она будет работать (целиком на видеокарте, видеокарта + ОЗУ, процессор), размер загрузки, контекст, лицензия, языки и возможности, объяснение «почему» и предупреждения. Ниже — модели, которые не подошли, с причиной.

**Установить и настроить** делает всё за один раз: ставит движок, если его нет, скачивает нужный файл (и проектор изображений, если нужны картинки), а после загрузки сразу настраивает модель — название, контекст, рекомендованные параметры генерации, потоки процессора. Затем **Запустить и проверить** загружает модель и показывает первый ответ и скорость, **Открыть в чате** переносит её во вкладку «Чат».

Скорость — оценка по пропускной способности памяти (±25 %): реальная зависит от драйвера, длины разговора и нагрузки. Оценки качества сравнительные, по опубликованным тестам моделей. Список моделей мастер берёт из встроенного каталога; ссылка **обновить данные** внизу мастера перечитывает с Hugging Face файлы, размеры и параметры моделей.

## Шаг 1. Движок

Нажмите **Установить движок**. MemuAI скачает последнюю сборку llama.cpp с официальной страницы релизов на GitHub и положит её в папку данных. Размер — от 30 до 400 МБ в зависимости от сборки.

| Сборка | Для чего |
| --- | --- |
| Автовыбор | NVIDIA → CUDA, остальные видеокарты → Vulkan, без видеокарты → процессор |
| CUDA | видеокарты NVIDIA; нужен свежий драйвер. Вместе с ней ставятся библиотеки CUDA |
| Vulkan | почти любая видеокарта: AMD, Intel, NVIDIA |
| Только процессор | без видеокарты или если остальные сборки не запускаются |

Кнопка **Обновить** позже скачает свежую сборку. Если у вас уже есть свой `llama-server` (например, собранный под ROCm), укажите путь к нему в **Настройках** вкладки — встроенный движок тогда не нужен.

> [!NOTE]
> Автоматическая установка работает в Windows. В других системах укажите путь к своему `llama-server`.

## Шаг 2. Модель

### Поиск на Hugging Face

Введите название — например, `qwen3 8b` или `gemma 3` — и нажмите **Найти**. В выдаче только репозитории с файлами GGUF. Сортировка: популярные, в тренде, по лайкам, свежие.

Щелчок по репозиторию раскрывает список файлов. У каждого файла — квантизация, размер и оценка «пойдёт ли здесь»:

| Оценка | Что значит |
| --- | --- |
| Влезет в видеопамять | модель целиком помещается в видеокарту — самый быстрый вариант |
| Видеокарта + ОЗУ | часть слоёв на видеокарте, остальное в оперативной памяти — llama.cpp делит модель сам |
| Пойдёт в ОЗУ | модель работает из оперативной памяти — медленнее, но работает |
| Впритык | памяти почти не хватает, компьютер может тормозить |
| Слишком большая | скорее всего не запустится |

Оценка учитывает сами веса и контекст около 8 тысяч токенов. Один файл в списке отмечен как **рекомендую** — самый крупный из тех, что хорошо помещаются, с предпочтением распространённых квантизаций.

Модели из нескольких частей (`…-00001-of-00003.gguf`) показаны одной строкой и скачиваются целиком. Если в репозитории есть **проектор изображений** (`mmproj`), над таблицей появляется выбор — с ним модель сможет смотреть на картинки.

Загрузка идёт в фоне, с прогрессом, скоростью и оставшимся временем. Её можно отменить; при обрыве связи она продолжится с того же места. После загрузки модель сразу появляется в списке.

> [!TIP]
> **Какую квантизацию брать.** `Q4_K_M` — лучший баланс качества и размера. `Q5_K_M` и `Q6_K` — чуть лучше и тяжелее. `Q8_0` — почти без потерь. `Q3`, `Q2`, `IQ` — для слабых компьютеров с заметной потерей качества. Для ориентира: модель на 7–8 миллиардов параметров в `Q4_K_M` весит около 5 ГБ.

### Закрытые репозитории

Некоторые модели (Llama, Gemma) закрыты лицензией. Примите её на сайте Hugging Face, создайте токен доступа и вставьте его в **Proxy → Локальные модели → Настройки → Токен Hugging Face**. Токен хранится только на этом компьютере и отправляется только на huggingface.co.

### Файл с диска

**＋ Файл с диска** открывает выбор файла. Модель можно оставить на месте — тогда Proxy работает с ней там, где она лежит, и никогда её не удаляет, — или скопировать в папку MemuAI. Для модели из нескольких частей выберите первую.

## Шаг 3. Работа с моделью

| Кнопка | Что делает |
| --- | --- |
| Загрузить | загружает модель в память заранее, чтобы первый ответ не ждал |
| Выгрузить | освобождает память |
| Проверить | отправляет короткий вопрос и показывает ответ и скорость |
| Настроить | параметры модели |
| ⋯ | журнал сервера, включить/выключить, путь к файлу, страница на Hugging Face, проверка в детекторе, удаление |

Локальные модели поддерживают вызов инструментов (function calling) через API Proxy — их можно использовать в MemuCode и агентах, если сама модель это умеет. Размышления модели (`<think>`) показываются отдельно от ответа.

Загружать вручную не обязательно: модель загрузится сама при первом запросе. Первый ответ после этого будет дольше — от нескольких секунд до минуты.

### Настройки модели

| Параметр | Смысл |
| --- | --- |
| Название | как модель подписана в списках |
| Доступна в API | выключенная модель пропадает из каталога |
| Длина контекста | сколько токенов модель держит в памяти; больше — больше расход памяти |
| Слоёв на видеокарте | `-1` — авто: столько, сколько поместится в видеопамять (свежий llama.cpp подбирает сам), `0` — только процессор |
| Потоков процессора, размер пакета | `0` — решает llama.cpp |
| Выгружать после простоя | через сколько минут без запросов освободить память; `0` — держать всегда |
| Лимит ответа | предел длины ответа, если клиент не задал свой |
| Параметры генерации | температура, top P, top K, min P, штраф за повторы — применяются, если клиент не прислал свои |
| Системный промпт | добавляется, если в запросе нет своего системного сообщения |
| Проектор изображений | файл `mmproj` для моделей со зрением |
| Дополнительные аргументы | любые ключи `llama-server`, например `--flash-attn on` |

Название, параметры генерации и системный промпт применяются сразу. Контекст, слои, потоки и аргументы — при следующей загрузке: если модель уже в памяти, она выгрузится, чтобы запуститься с новыми значениями.

### Общие настройки

**Настройки** над списком моделей:

- **Моделей в памяти одновременно** — по умолчанию одна. Запрос к другой модели выгрузит ту, что использовалась давнее всех.
- **Потоков процессора по умолчанию**.
- **Свой llama-server** — путь к собственной сборке.
- **Токен Hugging Face**.

## Другие локальные серверы

Если у вас уже работают Ollama, LM Studio, llamafile, Jan, KoboldCpp, text-generation-webui или vLLM, нажмите **Найти на этом компьютере**. Proxy проверит их стандартные порты (11434, 1234, 8080, 1337, 5001, 5000, 8000) и предложит **Подключить** найденное как «Собственный API». Модели появятся с префиксом по имени сервера, например `ollama-llama3.2`.

## Ошибки

| Сообщение | Что делать |
| --- | --- |
| llama-server завершился с кодом … | откройте ⋯ → **Журнал сервера**. `failed to allocate` или `out of memory` — уменьшите контекст или слои на видеокарте, возьмите квантизацию поменьше. `unknown argument` — уберите лишний аргумент или обновите движок |
| Модель не успела загрузиться | очень большая модель на медленном диске — повторите запрос |
| Модель не видит изображения | добавьте проектор `mmproj` в настройках или не прикладывайте картинку |
| llama-server аварийно завершился: нарушение доступа к памяти (код 0xC0000005) | чаще всего выбран draft-файл (MTP-голова) вместо модели: у него метаданные целой модели, но всего несколько тензоров. MemuAI распознаёт такие файлы и предупреждает заранее — скачайте основной файл из того же репозитория, а draft-файл укажите в поле «Draft-модель для ускорения» |
| Hugging Face ответил HTTP 401/403 | репозиторий закрыт: примите лицензию и укажите токен |
| Разговор не помещается в контекст локальной модели | увеличьте «Длину контекста» в настройках модели, начните новый чат или отправьте меньше текста |
| Шаблон чата этой локальной модели не поддерживает инструменты | модель не умеет вызывать функции — для агентов и MemuCode выберите модель с отметкой «инструменты» в мастере |
| Не удалось скачать движок | GitHub недоступен или ограничил частоту запросов — повторите позже или укажите свой `llama-server` |

Любую из этих ошибок можно отдать [ИИ-помощнику](doc:proxy-companion) — он знает эту вкладку.

## Где лежат файлы

```
%APPDATA%\MemuAI\local-models\
  catalog.json   список моделей и их настройки
  models\        скачанные и скопированные модели
  runtime\       движок llama.cpp
```

Удаление модели, скачанной через MemuAI, может удалить и её файл. Файлы, добавленные «на месте», Proxy не удаляет никогда.
