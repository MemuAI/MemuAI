# Рецепты

## Модуль, который открывается только из другого модуля

```json
"launcher": { "hidden": true, "slot": "sidebar" }
```

Модуль включён, но своей кнопки не показывает. Пользователь открывает его из настроек.

## Окно, которое не таскается

```json
"window": { "default_width": 520, "default_height": 620, "fixed": true, "draggable": false }
```

Подходит панелям с фиксированной сеткой: не нужно тратить время на подгонку.

## Модуль, который всегда открывается размером автора

```json
"window": { "size_mode": "authored" }
```

Пользователь по-прежнему может менять размер, но при следующем открытии окно вернётся к авторскому — полезно, когда важна предсказуемая раскладка.

## Чат внутри модуля

Поставьте `"keep_in_chat": true` в описании и передавайте `keep_in_chat: true` в запросе. Пары сообщений начнут копиться в чате `module-<id>`, который виден в обычном списке чатов.

## Отмена долгой генерации

```javascript
let job = null;
document.querySelector("#go").onclick = () => {
  job = Memu.stream(body, handlers);
};
document.querySelector("#stop").onclick = () => job && job.cancel();
```

Для изображений и видео мост поддерживает закрытие окна: незавершённый запрос прекращается.

## Показать ошибку по-человечески

```javascript
function showError(error) {
  status.textContent = error.message || "Неизвестная ошибка";
  status.classList.add("mu-note", "warn");
}
```

Мост уже подставляет текст на языке интерфейса, добавлять ничего не нужно.

## Экономия: не сохранять тяжёлое

Храните ссылки и небольшие настройки, а не содержимое. Огромные data-URL в `persist` замедлят закрытие модуля.

## Проверка, что модуль запущен в MemuAI

```javascript
if (!window.Memu) {
  document.body.textContent = "Этот экран работает только внутри MemuAI.";
}
```

Так пакет можно открыть в браузере для отладки вёрстки и получить понятное сообщение вместо белого экрана.

## Поддержка двух языков

```javascript
const t = (ru, en) => (Memu.env.lang === "en" ? en : ru);
document.querySelector("#title").textContent = t("Заметки", "Notes");
```
