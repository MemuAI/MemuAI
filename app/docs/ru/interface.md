# Интерфейс

Окно MemuAI — обычное окно Windows: его можно растягивать, разворачивать, прикреплять к краю экрана через Snap Layouts. Интерфейс подстраивается под размер вплоть до 420×360 пикселей.

![Окно чата MemuAI](docs-img/ru/interface.webp "Слева — боковая панель с разделами и чатами, сверху — выбор модели, в центре — лента, внизу — поле ввода")

## Боковая панель

Слева — навигация. Её ширина меняется перетаскиванием правого края, а сама панель прячется по ++Ctrl+B++.

| Элемент | Что это |
| --- | --- |
| Новый чат, временный чат | начать разговор; временный не сохраняется — см. [Чаты](doc:chats) |
| Чат, Work, MemuCode | три режима работы: обычный разговор, [работа с файлами](doc:work), [агент для кода](doc:memucode) |
| Планирование | [задачи по расписанию](doc:schedules) |
| Скиллы ИИ | готовые приёмы работы, которые модель подключает сама |
| Закреплённые | чаты, закреплённые через их меню |
| Папки | ваши папки с чатами; чат переносится в папку перетаскиванием |
| Мемесы | ваши [ассистенты](doc:agents) со своими инструкциями и чатами |
| Чаты | история разговоров, новые сверху |
| Состояние Proxy | точка и подпись внизу: работает ли MemuAI Proxy |
| Карточка профиля | имя и аватар; щелчок открывает [профиль](doc:profiles) |

Порядок разделов Папки, Мемесы и Чаты меняется перетаскиванием заголовка или кнопкой ⇅.

У каждого чата есть меню (⋯ или правый щелчок): закрепить, переименовать, отметить непрочитанным, экспортировать, скопировать, удалить.

## Верхняя полоса

| Элемент | Что делает |
| --- | --- |
| Меню MemuAI | команды приложения: файл, правка, вид, справка |
| Назад, вперёд | переходы между недавно открытыми чатами и экранами (++Alt+←++, ++Alt+→++) |
| Панель | скрыть или показать боковую панель |
| Поиск | фильтр списка чатов; ++Enter++ или ++Ctrl+K++ — [поиск везде](doc:search): чаты, память, файлы, настройки |
| Выбор модели | модель текущего чата — см. [Модели](doc:models) |
| Счётчик контекста | сколько места в окне контекста модели занимает разговор — см. [Контекст](doc:context) |
| Фокус | режим без отвлекающих элементов (++Ctrl+Shift+F++) |
| Тема | переключение светлого и тёмного режима |

В режимах Work и MemuCode под верхней полосой появляется своя полоса: проект, режим доступа, план, цель.

## Лента сообщений

Ответы модели оформлены Markdown: заголовки, списки, списки задач (`- [ ]` и `- [x]` показываются как ☐ и ☑), таблицы, формулы, код с подсветкой и кнопкой копирования. Пока ответ печатается, незакрытый блок кода уже показывается как код, а не сырыми символами ```. Под ответом — имя модели и действия: скопировать, повторить, озвучить, изменить. Весь текст можно выделять.

Изображения — ваши и созданные моделью — открываются в просмотрщике: колесо мыши масштабирует, есть «вписать», скачивание и открытие во внешней программе.

Длинное сообщение пользователя сворачивается; кнопка под ним раскрывает текст целиком.

## Поле ввода

Беседа живёт на приподнятом «холсте» со скруглёнными углами, а боковая панель сливается с фоном окна. Внизу — поле сообщения: слева кнопка ＋ с вложениями и инструментами ответа (включённые видны чипами рядом с ней), справа микрофон, MemuAI Live и отправка. Подробно — [Поле ввода](doc:composer). Символ ++/++ в начале открывает [команды](doc:commands), ++@++ — упоминания.

## Панель настроек

++Ctrl+,++ или пункт в меню. Слева — поиск и 19 разделов в пяти группах, справа — содержимое раздела. Сначала видны только частые настройки; редкие спрятаны в свёрнутые блоки **Дополнительно**, а длинные списки (голоса, модели, интеграции) открываются отдельными подстраницами со строкой «Настройки › Раздел › Подраздел» наверху.

| Группа | Раздел | Что там |
| --- | --- | --- |
| Основное | Общие | язык, отправка сообщения, проверка орфографии, названия чатов, запуск вместе с Windows |
| | Внешний вид | тема и её вариант, акцентный цвет, дизайн, шрифт, анимации — см. [Внешний вид](doc:appearance) |
| | Уведомления | оповещения Windows и звук |
| Искусственный интеллект | Модели | модель по умолчанию, размышление, видимые модели, кэширование промптов |
| | Чат и ответы | характер ответов, ваши инструкции, визуализации и карточки товаров, длинные чаты и окно контекста |
| | Веб-поиск | поиск в интернете, внешний источник, глубокое исследование |
| | Изображения и видео | как отправлять картинки и видео моделям без зрения, модель распознавания |
| | Голос и Live | диктовка, озвучивание ответов, MemuAI Live, Live-модели реального времени, компаньон |
| | Work и агенты | доступ к файлам, навыки ИИ (Browser, Computer Use), модель и число агентов |
| Везде под рукой | Быстрый доступ | окно по Alt+Space — см. [Быстрый доступ](doc:quick-ask) |
| | Панели | карточки на главном экране и сбоку |
| | Telegram | бот и Mini App |
| | Интеграции | GitHub, Google Drive, Google Календарь, почта для задач по расписанию |
| Вы и данные | Профиль и память | имя, о себе, аватар, PIN, память |
| | Системные промпты | библиотека промптов для опытных пользователей |
| | Данные | импорт и экспорт чатов, мемесов и сведений о себе; опасная зона (удаление истории) |
| MemuAI | Модули | [свои приложения](doc:modules) внутри MemuAI |
| | Документация | эта справка |
| | О программе | версия, обновления и [горячие клавиши](doc:shortcuts) |

**Поиск** (++Ctrl+F++ или ++/++ в настройках) находит любую настройку по-русски и по-английски, прощает опечатки и неверную раскладку («ntvf» найдёт «тема»): ++↑++/++↓++ выбирают результат, ++Enter++ открывает раздел, подстраницу или блок «Дополнительно» и подсвечивает нужную строку. ++Esc++ сначала очищает поиск, потом закрывает подстраницу, потом окно; ++Alt+←++ — назад. У изменённой настройки при наведении появляется ↺ — вернуть значение по умолчанию; у некоторых разделов есть «Сбросить раздел». В узком окне список разделов прячется за кнопку ☰.

Все изменения сохраняются сразу — в шапке на мгновение появляется «Сохранено ✓».

## Контекстные меню

Правый щелчок работает почти везде: по сообщению, чату, модели, полю ввода, файлу в MemuCode, тексту документации. В поле ввода меню содержит правку текста, преобразования (регистр, очистка), счётчики и исправление орфографии.

## Подсказки

Наведите курсор на любую кнопку-значок — через полсекунды появится подсказка с названием и сочетанием клавиш, если оно есть. С клавиатуры подсказка показывается при переходе клавишей ++Tab++.
