# Discord и WhatsApp

Кроме Telegram, MemuAI отвечает в **Discord** и **WhatsApp**. Все три мессенджера собраны на одной странице: **Настройки → Мессенджеры**, вкладки **Telegram · Discord · WhatsApp**. Точка на вкладке показывает состояние: зелёная — подключено, жёлтая — ждёт привязки или запускается, красная — ошибка.

Боты работают внутри MemuAI Proxy на вашем компьютере. Ответы создаются теми же серверными задачами, что и в Telegram Mini App, и сохраняются в обычные чаты MemuAI — их видно в окне на компьютере.

> [!IMPORTANT]
> Пока бот не привязан, он никому не отвечает. После привязки он отвечает только вам (и людям из списка «Дополнительные пользователи»). Токены хранятся только на компьютере, не попадают в журналы и не копируются при синхронизации.

## Что умеет бот

| Команда | Что делает |
|---|---|
| `/menu` | Главное меню с кнопками |
| `/new` | Новый чат |
| `/chats` | Ваши чаты MemuAI (с поиском: `/chats отчёт`) |
| `/model` | Выбор модели (с поиском: `/model gpt`) |
| `/settings` | Веб-поиск, размышление, личность, язык бота |
| `/temp` | Временный чат: не попадает в чаты MemuAI |
| `/regen` | Ответить ещё раз |
| `/stop` | Остановить ответ |
| `/status` | Что выбрано сейчас: чат, модель, переключатели |
| `/help` | Подсказка |

Под ответами есть кнопки **Ещё раз**, **Новый чат** и **Меню**. Списки чатов, моделей и личностей листаются кнопками. Команды понимаются и по-русски: `/меню`, `/новый`, `/чаты`, `/модель`, `/настройки`, `/стоп`, `/статус`.

## Discord

1. Откройте [Discord Developer Portal](https://discord.com/developers/applications) → **New Application** → раздел **Bot** → **Reset Token** и скопируйте токен.
2. В MemuAI: **Настройки → Мессенджеры → Discord**, вставьте токен и нажмите **Проверить подключение**. Появятся ссылки **Добавить в мой аккаунт** и **Добавить на сервер**.
3. Добавьте бота к себе. Для «Добавить в мой аккаунт» в портале включите **Installation → User Install**. Можно и просто добавить бота на свой сервер — после этого ему можно писать в личные сообщения.
4. Включите **Бот Discord**, нажмите **Получить код привязки** и отправьте боту в личные сообщения `/pair КОД`.

Бот работает только в личных сообщениях; на серверах он вежливо отказывает. Особые разрешения и Message Content Intent не нужны. Ответ печатается по мере генерации — сообщение обновляется каждые 1–2 секунды.

## WhatsApp

Есть два способа подключения — выберите его переключателем вверху вкладки.

### WAHA на этом компьютере

[WAHA](https://waha.devlike.pro/) — WhatsApp HTTP API, который работает у вас локально. Наружу ничего не открывается.

1. Запустите WAHA: `docker run -it -p 3000:3000 devlikeapro/waha`.
2. Откройте `http://localhost:3000/dashboard`, запустите сессию и отсканируйте QR в WhatsApp → **Связанные устройства**.
3. В MemuAI выберите **WAHA**, проверьте адрес, API-ключ (если задан) и имя сессии.
4. Укажите **номер чата для MemuAI**: ваш собственный номер (переписка с самим собой) или ваш личный номер, если WAHA подключён к отдельному номеру-боту.
5. Включите **Бот WhatsApp** и нажмите **Проверить подключение**.

MemuAI читает только указанный чат, привязка кодом не нужна. В WhatsApp нет кнопок для обычных аккаунтов, поэтому варианты приходят нумерованным списком — отвечайте цифрой.

### WhatsApp Cloud API

Официальный способ Meta для бизнес-номеров. Сообщения приходят на webhook MemuAI Proxy, поэтому его нужно открыть в интернет по HTTPS.

1. В [Meta for Developers](https://developers.facebook.com/apps) создайте приложение типа **Business** → **WhatsApp** → **API Setup**.
2. Скопируйте постоянный токен (System User), **Phone number ID** и **App secret** (App settings → Basic) в MemuAI.
3. Откройте MemuAI Proxy по HTTPS, например `cloudflared tunnel --url http://127.0.0.1:ПОРТ`.
4. В WhatsApp → **Configuration** укажите Callback URL `https://ваш-адрес/messengers/whatsapp/webhook` и **Verify token** — его создаёт кнопка **Создать** в MemuAI. Подпишитесь на поле `messages`.
5. Включите **Бот WhatsApp**, нажмите **Получить код привязки** и отправьте код на номер бота со своего WhatsApp.

Каждый запрос к webhook проверяется подписью App secret (`X-Hub-Signature-256`): запросы без верной подписи отклоняются. Списки до 10 пунктов приходят интерактивным меню, действия — кнопками.

## Если что-то не работает

- **MemuAI Proxy не запущен** — боты работают внутри Proxy; запустите его, бот подключится сам.
- **Токен отклонён** — сбросьте токен в Developer Portal и вставьте новый; перезапуск не нужен.
- **Ждёт сообщений от Meta** — проверьте туннель HTTPS и подписку webhook на `messages`.
- **WAHA не отвечает** — проверьте, что контейнер запущен и сессия в статусе `WORKING`.
- Отвязать бота можно кнопкой **Отвязать** в карточке владельца; после этого нужен новый код.
