# Уведомления и удалённый доступ

## Оповещения о завершении

**Настройки → Уведомления**. Пока модель отвечает, можно переключиться в другое окно — MemuAI сообщит, когда ответ готов.

| Настройка | Что делает |
| --- | --- |
| Оповещение Windows | уведомление в углу экрана после завершения ответа |
| Звуковой сигнал | короткий сигнал после ответа |
| Вариант сигнала | Мягкий, Кристалл, Pop, Тёплый аккорд; кнопка ▶ проигрывает образец |
| Громкость | от 0 до 100 % |

Сигналы не накладываются друг на друга, если несколько ответов закончились одновременно.

## Telegram-бот

**Настройки → Telegram**. Бот — это MemuAI в телефоне: те же чаты, модели, профили и агенты, живые ответы, голосовые сообщения, фото и файлы. Подключается за минуту по QR-коду или одноразовому коду, без поиска Chat ID. Уведомления о готовых ответах, задачах, Work и модулях настраиваются по категориям, есть тихие часы.

Подробно — на странице [Telegram-бот](doc:telegram).

## Почта для задач по расписанию

В том же разделе настраивается отправка результатов [задач по расписанию](doc:schedules) на почту через ваш собственный SMTP-сервер. Письмо уходит только для задач, где отмечена «Почта».

| Поле | Пример |
| --- | --- |
| Получатель | `me@example.com`; несколько — через запятую |
| SMTP | `smtp.gmail.com` |
| Порт | 587 |
| Имя пользователя | ваш адрес |
| Пароль | пароль приложения — у Gmail, Яндекса и Mail.ru обычный пароль не подойдёт |
| Отправитель | необязательно, если совпадает с логином |
| Защита соединения | STARTTLS (порт 587), SSL/TLS (порт 465) или нет |

Пароль хранится только на этом компьютере.

Если режим защиты не совпадает с портом (STARTTLS на 465 или SSL/TLS на 587), MemuAI выбирает режим по порту, а не ждёт ответа, которого сервер не пришлёт. Недоступный сервер даёт понятную ошибку по тайм-ауту (20 секунд на шаг соединения).
