# Первый модуль за пять минут

## 1. Создайте его

Откройте **Настройки → Модули** и нажмите «Создать модуль». Мастер спросит идентификатор, название и шаблон. Возьмите шаблон «Пустой» — в нём уже есть поле, кнопка и вызов модели.

Идентификатор — это внутреннее имя: латиница в нижнем регистре, цифры и дефис, до 41 символа, например `my-notes`. Он не меняется и попадает в адрес страницы модуля.

## 2. Включите и откройте

У каждого модуля есть переключатель. Пока он выключен, модуль не занимает места в интерфейсе и его нельзя открыть. Включите — в боковой панели появится кнопка с названием модуля. Кнопку можно убрать («Скрыть кнопку») или перенести в другое место.

## 3. Поправьте код

Нажмите «Код» на карточке модуля — откроется мастерская: HTML, CSS и JS рядом, живой предпросмотр справа. Сохранение перезагружает открытое окно модуля, так что результат виден сразу.

## 4. Проверьте связь с моделью

В `main.js` шаблона уже есть:

```javascript
const answer = await Memu.request({
  model: Memu.manifest.bridge.model,
  instructions: Memu.manifest.bridge.instructions,
  text: document.querySelector("#input").value,
});
document.querySelector("#out").textContent = answer.text;
```

`Memu.request` возвращает `{ text, model, chat }` — то, что ответила модель. Если модель не выбрана, мост вернёт понятную ошибку, а не пустой текст.

## 5. Сохраните состояние

```javascript
await Memu.save({ input: input.value, draft: true });
```

Сохранение работает только для ключей из списка `persist` в описании модуля. Всё остальное молча отбрасывается — так исключены случайные гигантские записи. При следующем открытии те же данные лежат в `Memu.saved`.

## 6. Выключите или удалите

Выключенный модуль ничего не делает и не помнит о себе ни одной живой ссылки. Свой модуль можно удалить совсем (вместе с сохранёнными полями), встроенный — только выключить, а его изменённую копию — сбросить к заводской.
