# Интеграция с MemuAI: панели, команды, виджеты

Модуль может выйти за пределы своего окна. Блок `contributes` в `manifest.json` добавляет:

- **панели** — карточки модуля в списке «Новая панель» (раздел «Панели модулей»);
- **команды** — действия, которые ИИ выполняет в чате и в Быстром доступе («Включи трек Believer»);
- **скилл** — текст для ИИ: что умеет модуль и когда звать его команды;
- **виджеты** — мини-плеер над полем ввода, карточка и кольцо-эквалайзер в Быстром доступе.

Всё это работает только для **включённых** модулей и только с правами самого модуля. В безопасном режиме модули ничего не добавляют.

## Пример

```json
"contributes": {
  "panels": [{
    "id": "now-playing", "title": "Сейчас играет", "title_en": "Now playing",
    "summary": "Обложка и управление", "icon": "music", "size": "m", "height": 200,
    "entry": "integration/panel.html", "scripts": ["integration/panels.js"], "styles": ["integration/panels.css"],
    "settings": [{"key": "compact", "type": "bool", "label": "Компактно", "label_en": "Compact", "default": false}]
  }],
  "commands": [{
    "id": "open-note", "title": "Открыть заметку", "title_en": "Open a note",
    "description": "Открыть заметку по названию", "description_en": "Open a note by its title",
    "args": {"type": "object", "properties": {"title": {"type": "string"}}, "required": ["title"]},
    "phrases": ["открой заметку {title}"], "phrases_en": ["open the note {title}"],
    "danger": false, "run": {"open": true}
  }],
  "skill": "integration/skill.md",
  "widgets": [{
    "id": "eq-ring", "slot": "quick.ring", "kind": "equalizer", "source": "music.player",
    "title": "Эквалайзер", "settings": [{"key": "enabled", "type": "bool", "label": "Показывать", "default": true}]
  }]
}
```

Все файлы лежат в пакете модуля, обычно в папке `integration/`.

## Панели

Панель — отдельная страница модуля в той же песочнице, что и окно: без сети, с мостом `Memu.*` и правами модуля.

- `entry` — HTML-фрагмент панели, `scripts` и `styles` — файлы пакета (до 6 и 4).
- `size` — размер по умолчанию: `s`, `m`, `l` или `w`; `height` — высота карточки, 96–640 px.
- `settings` — настройки панели (`bool`, `choice`, `text`, `color`); их значения — в `Memu.panel.settings`. Человек меняет их в настройках панели на главном экране.
- `data` — имя серверного источника данных. Доступен только встроенным модулям (Персонажи, API модели, Бенчмарки); у стороннего модуля поле отбрасывается с ошибкой проверки.

Панель создаётся лениво: страница грузится, только когда карточка появилась на экране, и живёт, пока панель на месте.

### Объект Memu.panel

| Поле | Что это |
| --- | --- |
| `id` | id панели из манифеста — один скрипт может рисовать несколько панелей |
| `settings` | значения настроек панели |
| `params` | размер и место карточки, например `{"size": "m"}` |
| `visible` | видна ли карточка сейчас |
| `open(detail)` | открыть окно модуля; `detail` придёт в событии `navigate` |
| `data(args)` | `Promise` с серверными данными панели (только при `data` в манифесте) |
| `height(px)` | сообщить нужную высоту карточки |

Пока карточка не видна или окно MemuAI свёрнуто, приходит событие `memu-panel-visible` с `visible: false` — остановите опрос и анимации. Атрибут `html[data-size]` повторяет размер карточки, удобно для стилей.

```js
const P = Memu.panel;
document.addEventListener("memu-panel-visible", (e) => { if (e.detail.visible) refresh(); });
async function refresh() {
  const data = P.data ? await P.data({ limit: 5 }) : null;   // встроенный модуль с "data"
  render(P.id, data);
}
```

### Что доступно в панели

`Memu.music.call` (право `music`), `Memu.store` (`get`, `get_many`, `set`, `list`, право `storage`), `Memu.monitor` (только `status` и `events`, право `background`), `Memu.env`, `Memu.log`, `Memu.panel.open`. Остальное — в окне модуля: панель ответит ошибкой «откройте модуль».

## Общий вид панелей

Каждая панель получает набор стилей MemuAI **до** своих стилей — так панели разных модулей выглядят одинаково спокойно и сами следуют светлой и тёмной теме. Цвет акцента задаёт переменная `--c` (по умолчанию `--accent`).

| Класс | Что это |
| --- | --- |
| `.mk` | корень панели: отступы, колонка, `--c` |
| `.mk-glow` | мягкое свечение акцента в углу |
| `.mk-head`, `.mk-ico`, `.mk-link` | заголовок, иконка и ссылка справа («Все…») |
| `.mk-list`, `.mk-row`, `.mk-main`, `.mk-side` | список строк: кнопка-строка, текст и значение справа |
| `.mk-mono` (`.round`) | аватар-монограмма или картинка 32 px; оттенок — `--h` |
| `.mk-pill` (`.dim`) | метка-пилюля |
| `.mk-chips`, `.mk-chip` | прокручиваемые фильтры; выбранный — `aria-pressed="true"` |
| `.mk-cta` | главная кнопка |
| `.mk-empty` | пустое состояние |
| `.mk-skel` | скелет загрузки |

```html
<main class="mk" id="mk" aria-live="polite">
  <div class="mk-skel" aria-hidden="true"><i></i><b></b><b></b></div>
</main>
```

Свои стили панели пишите поверх и через токены темы (см. [оформление](doc:modules-design)).

## Команды

Команда — действие, которое ИИ может вызвать инструментом `module_command {module, command, args}`.

- `args` — JSON-схема объекта: `string`, `number`, `integer`, `boolean`, `enum`, `required` (до 8 аргументов).
- `phrases` / `phrases_en` — точные фразы с подстановками `{имя}`.
- `danger: true` — MemuAI спросит пользователя, прежде чем выполнить команду.
- `run.open: true` — MemuAI открывает окно модуля и передаёт команду событием `navigate`: `Memu.on("navigate", (d) => d.command, d.args)`.
- `run.handler` — обработчик на сервере MemuAI. Доступен только встроенным модулям.

```js
Memu.on("navigate", (d) => {
  if (d.command === "open-note") openNote(d.args.title);
});
```

### Фразы в Быстром доступе

Запрос, который **точно** совпадает с фразой, Быстрый доступ выполняет сразу, без модели: «включи трек Believer» при фразе `включи трек {query}`. Регистр и лишние пробелы не важны, допускаются `.`, `!` или `?` в конце, кавычки вокруг аргумента снимаются. Всё остальное — «поставь, пожалуйста, что-нибудь от Queen» — уходит к ИИ, который сам выбирает команду. Команды с `danger: true` по фразе не выполняются: их всегда ведёт ИИ с подтверждением.

### Карточка результата

После команды человек видит карточку: в чате — под ответом (сохраняется вместе с перепиской), в Быстром доступе — внизу окна. На ней обложка, название и кнопки. Модель читает только текст результата и отвечает одной фразой. Карточку с обложкой и кнопками готовит обработчик встроенного модуля; у команды `run.open` её нет — Быстрый доступ покажет короткое «Открываю…».

## Скилл

`skill` — путь к `.md`-файлу пакета или `{"text": "…", "text_en": "…"}`, до 6000 символов. Текст попадает в системную подсказку чата и Быстрого доступа рядом со списком команд, пока модуль включён. Пишите коротко: когда звать какую команду и чего модуль не умеет.

```markdown
Заметки — локальные заметки пользователя.
- «открой заметку X» → notes.open-note {title}
- Если заметки нет, предложите её создать — команды для этого нет, откройте модуль.
```

## Виджеты

Виджет рисует сам MemuAI, а модуль выбирает вид, место и настройки. Код модуля в окне чата не запускается.

| `slot` | Где | `kind` |
|---|---|---|
| `chat.composer` | над полем ввода чата | `miniplayer` |
| `quick.card` | карточка в Быстром доступе | `nowplaying` |
| `quick.ring` | кольцо по краю Быстрого доступа | `equalizer` |

Источник данных сейчас один — `music.player` (плеер MemuMusic). Виджеты живут, только пока играет музыка и окно видно; без звука в окне кольцо анимируется по данным трека.

## Настройки в самом модуле

Модуль показывает и меняет настройки **своих** виджетов и панелей мостом `Memu.integration` — так их можно собрать на одной вкладке настроек модуля (в MemuMusic — «Виджеты и интеграция»).

```js
const { widgets, panels } = await Memu.integration.list();
// widgets: [{id, slot, kind, title, settings, values}], panels: [{id, title, settings}]
await Memu.integration.set("widget", "eq-ring", { style: "glow" });
```

Настройки других модулей недоступны. Значения хранит MemuAI; снаружи модуля они доступны через `GET` и `POST /api/pg/modint/settings` с `{module, kind: "widget"|"panel", id, values}`.

## Экспорт и импорт

При экспорте модуля в файл попадают все файлы, названные в `contributes`: страницы, скрипты и стили панелей и файл скилла. При импорте MemuAI записывает только эти файлы — текстовые, без `..` в пути, до 400 КБ каждый и до 2 МБ вместе. Файл, которого нет в `contributes`, при импорте пропускается.

## Проверка

Мастерская модулей и `modules_validate` проверяют `contributes`: id, файлы панелей и скилла, схему аргументов, места виджетов, `data` и `run.handler`. Ошибочный элемент отбрасывается, остальное работает.

Ограничения: до 8 панелей, 24 команд, 6 виджетов, 12 настроек у элемента и 8 фраз у команды.
