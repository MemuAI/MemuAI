# Экспорт чата

Экспорт сохраняет чат так, как вы видите его в MemuAI: формулы, таблицы, подсветка кода, картинки и диаграммы остаются на месте.

![Окно «Экспорт чата»](docs-img/ru/chat-export.webp "Слева — формат, сообщения и что включить, справа — живой предпросмотр документа")

## Как открыть

- ++Ctrl+Shift+S++ — экспорт текущего чата (сочетание меняется в [горячих клавишах](doc:shortcuts));
- правый клик по чату в списке → **Экспортировать чат**;
- меню **Файл → Экспортировать чат** в заголовке окна.

Откроется окно с выбором формата, настройками и живым предпросмотром.

## Форматы

| Формат | Что получится |
|---|---|
| **PDF** | Для чтения и печати. Печатает Microsoft Edge в фоне; если Edge нет — откроется окно печати («Сохранить как PDF») |
| **Word** (DOCX) | Редактируемый документ: настоящие таблицы, списки, цветной код, картинки и редактируемые формулы Office |
| **HTML** | Одна веб-страница, всё внутри: шрифты формул, картинки, интерактивные графики |
| **Markdown** | Текст с разметкой — для заметок и Git |
| **JSON** | Данные сообщений — для программ и архива |
| **Текст** | Только текст |

## Какие сообщения

- **Все** — весь чат;
- **Диапазон** — с одного сообщения по другое;
- **Выбрать** — отметьте нужные вручную; есть быстрые кнопки «Все», «Ничего», «Только мои», «Только ответы».

## Что включить

Заголовок и сведения (название, дата, число сообщений, модели), время сообщений, изображения и графики, формулы, подсветка кода, ход мыслей, шаги инструментов, статистика токенов и содержание — список ваших вопросов со ссылками.

## Оформление

- **Тема** — светлая, тёмная, сепия, для печати или текущее оформление MemuAI;
- **Шрифт** текста и кода, **размер**;
- **Бумага** A4 или Letter, **ориентация**, **поля**;
- **Колонтитулы** — свой текст сверху и снизу (например, «Конфиденциально») и номера страниц.

Последние выбранные параметры запоминаются и предлагаются в следующий раз.

## Куда сохраняется

По умолчанию файл попадает в папку **Загрузки/MemuAI**, после сохранения его можно сразу открыть или показать в папке. Вариант **Спросить, куда** открывает обычное окно сохранения Windows. Текстовые форматы можно также скопировать в буфер кнопкой **Копировать**.

> [!TIP]
> Экспорт целиком выполняется на вашем компьютере: чат никуда не отправляется.
