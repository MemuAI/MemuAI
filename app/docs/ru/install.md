# Установка и обновление

## Требования

| Что | Требование |
| --- | --- |
| Система | Windows 10 или 11, 64 бита |
| Компонент | Microsoft Edge WebView2 (в Windows 11 уже есть, в Windows 10 ставится вместе с Edge) |
| Место на диске | несколько сотен мегабайт для программы; локальные модели — отдельно, обычно от 1 до 10 ГБ каждая |
| Интернет | нужен для облачных моделей; локальные модели работают без него |

## Установщик

Запустите **MemuAI-Setup-<версия>.exe** (например, `MemuAI-Setup-3.0.exe`). Установщик на русском и английском, язык переключается кнопками RU/EN в его окне. Права администратора не нужны: всё ставится для вашей учётной записи в `%LOCALAPPDATA%\Programs\MemuAI`.

Кнопка **Установить** на первом экране проводит по шагам. На каждом шаге уже выбрано рекомендуемое, поэтому достаточно нажимать **Далее**; **Назад** (или Esc) возвращает на шаг назад:

| Шаг | Что выбрать |
| --- | --- |
| Состав | полный комплект (MemuAI, Proxy и MemuCode CLI) или только Proxy — если нужен только API для других программ; MemuCode CLI можно отключить |
| Папка | куда поставить программу; установщик показывает, сколько места нужно и сколько свободно |
| Параметры | автозапуск Proxy вместе с Windows (включён по умолчанию), чтобы API и расписания работали сразу после входа; отдельно — запуск MemuAI после входа; ярлыки MemuAI и Proxy на рабочем столе (по желанию). В меню «Пуск» ярлыки появляются всегда |
| Проверка | сводка выбранного; любой пункт можно изменить кнопкой **Изменить**. Файлы начинают записываться только после нажатия **Установить** здесь |

**Быстрая установка** на первом экране сразу открывает сводку с рекомендуемыми параметрами — без подтверждения ничего не ставится. При обновлении, переустановке или возврате к старой версии установщик сразу показывает, что произойдёт (какая версия на какую, где лежит программа, что сохранится), и параметры можно поменять там же. На последнем экране — **Открыть MemuAI**, «Что нового» и «Открыть папку».

Установщик проверяет каждый файл по контрольной сумме: повреждённая загрузка не установится, а прежняя версия останется на месте. Если окну установщика не хватает компонента WebView2, он предложит скачать его у Microsoft или установить программу с настройками по умолчанию без окна.

Для администраторов есть тихая установка: `MemuAI-Setup-3.0.exe /VERYSILENT` (или `/S`); работают и `/DIR="путь"`, `/COMPONENTS=memuai,memucode`, `/TASKS=autostart,desktopicon`, `/LANG=ru`, `/LOG`.

## Первый запуск

1. Откройте **MemuAI**. Если Proxy ещё не работает, MemuAI запустит его сам — значок появится в трее у часов.
2. При первом запуске MemuAI предложит познакомиться: имя, пара слов о себе. Этот шаг можно пропустить.
3. Добавьте аккаунт — см. [Аккаунты](doc:accounts). Без аккаунтов и без локальных моделей отвечать некому.

## Обновление

Новая версия ставится поверх старой тем же установщиком — в том числе поверх версий, установленных прежним установщиком на Inno Setup. Закрывать программы вручную не нужно: установщик сам просит их завершиться, а если какая-то не закрылась, предложит закрыть её за вас. Папки программ заменяются целиком, поэтому от старой версии не остаётся лишних файлов. Чаты, настройки, аккаунты и модели сохраняются: они лежат не в папке программы, а в `%APPDATA%\MemuAI`. После обновления установщик просит Windows перечитать значки ярлыков, чтобы на панели задач и в меню «Пуск» сразу появились новые значки MemuAI и MemuAI Proxy.

С включёнными **автоматическими обновлениями** (Настройки → Общие) MemuAI проверяет новую версию при запуске и каждые 15 минут, скачивает её в фоне и показывает синюю кнопку установки внизу боковой панели, рядом с состоянием Proxy.

## Удаление

Удаление — через «Параметры Windows → Приложения» или ярлык удаления в меню «Пуск». Личные данные в `%APPDATA%\MemuAI` по умолчанию **не удаляются**: при повторной установке всё вернётся. Чтобы стереть и их, выключите в окне удаления переключатель «Сохранить чаты, настройки и аккаунты» — или удалите эту папку вручную.

> [!WARNING]
> В папке данных лежат ваши аккаунты и чаты. Перед её удалением сохраните нужное: **Настройки → Данные** выгружает все чаты одним файлом.

## Если программа не запускается

- Сообщение с путём к `startup-error.log` означает, что запуск упал на раннем этапе. Файл лежит в `%APPDATA%\MemuAI\memuai\` и содержит причину — её можно отправить разработчику или ИИ-помощнику.
- Белое или пустое окно — обычно не установлен или повреждён WebView2. Установите «Microsoft Edge WebView2 Runtime» с сайта Microsoft.
- Если порт 8317 занят другой программой, смените порт Proxy в **Proxy → Настройки → Дополнительно → Сервер и API**.
