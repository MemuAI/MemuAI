# Мастерская: создание и правка

Раздел **Настройки → Модули** — это не список галочек, а рабочее место.

## Создание

Кнопка «Создать модуль» открывает мастер:

1. **Идентификатор и название.** Идентификатор проверяется сразу: занятый или неверный не пропустят.
2. **Шаблон.** Пустой, Мини-чат, Инструмент или Медиа. Шаблоны дают рабочий код, а не заглушку.
3. **Окно.** Размер, границы, фиксированный или изменяемый, чей размер важнее.
4. **Права и сохранение.** Отметьте, что модулю разрешено, и какие поля он помнит.

После создания мастер открывает код нового модуля — можно сразу продолжить.

## Правка кода

Кнопка «Код» на карточке открывает мастерскую из трёх панелей:

- **HTML**, **CSS**, **JS** — с проверкой синтаксиса;
- **Переводы** — словари `i18n.json` по языкам, кнопка «Добавить недостающие» и счётчик пропущенных ключей;
- **Предпросмотр** — живая страница модуля, обновляется при сохранении; язык предпросмотра выбирается отдельно, чтобы проверить каждый перевод;
- **Описание, окно, права, сохраняемые поля** — рядом с кодом, а не в отдельном окне;
- **Импорт и экспорт пакета** — файлом `.memu-module.json`.

Мастерская показывает замечания до сохранения: забытые ключи в `persist`, неработающие внешние ссылки, закрывающие теги `</body>` в разметке.

## Встроенные модули

Код встроенного модуля правится как обычный: изменения ложатся в `overrides/<id>` и не трогают файлы установки. Поэтому обновление MemuAI не потеряет вашу версию, а «Сбросить к заводской» вернёт исходник.

## Проверка кода

Мастерская ловит типичные ошибки, которые иначе проявились бы только в рантайме:

| Проверка | Что сообщает |
| --- | --- |
| `</body>` и `</html>` в разметке | разметка попадает внутрь страницы, закрывающие теги не нужны |
| `script` и `link` с внешним адресом | такие теги не загрузятся, у модуля нет сети |
| `http://` и `https://` в коде | нужен `Memu.fetch`, `Memu.download` или `Memu.open` |
| ключ в `Memu.save`, которого нет в `persist` | поле не сохранится |
| пустой `main.js` | окно покажет только разметку |
| модуль без обращений к моделям | мост Memu доступен, если он нужен |

## Импорт и экспорт

Пакет модуля — один JSON-файл:

```
my-notes.memu-module.json
```

Экспорт сохраняет описание и весь код. Импорт умеет:

- создать модуль из пакета;
- дать новое имя, если идентификатор уже занят;
- взять пакет, созданный кем-то другим.

Перенос работает и между компьютерами, и между профилями MemuAI.

## Полезные действия на карточке

- **Включить** — модуль получает кнопку и открывается.
- **Скрыть кнопку** — модуль включён, но не мешает.
- **Где кнопка** — перенос между четырьмя местами.
- **Открыть** — окно модуля прямо из настроек.
- **Код** — мастерская.
- **Дублировать** — своя копия для экспериментов.
- **Очистить сохранённое** — сбросить память модуля.
- **Сбросить к заводской** — вернуть исходный код встроенного модуля.
- **Удалить** — у своего модуля; встроенный только выключается.

## Подсветка и размер предпросмотра

Редактор подсвечивает HTML, CSS, JavaScript и JSON переводов, сохраняя выделение, прокрутку и отмену ввода. Tab добавляет отступ, Shift+Tab уменьшает его. Предпросмотр можно открыть отдельно; на узком экране код и предпросмотр располагаются друг под другом, чтобы интерфейс модуля не обрезался до узкой полосы.
