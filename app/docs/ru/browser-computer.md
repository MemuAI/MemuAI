# Browser и Computer Use

В режиме Work у модели есть два навыка для задач, которые нельзя решить одними файлами:

| Навык | Что умеет |
| --- | --- |
| **Browser** | открывает сайты в отдельном скрытом Edge, читает, нажимает, листает, заполняет поля |
| **Computer Use** | видит экраны и управляет мышью и клавиатурой в вашей сессии Windows |

## Кто решает, запускать ли

Навыки — не ручные режимы. Основная модель сама решает, нужен ли браузер или управление компьютером для текущей задачи. Упоминания `@Browser` и `@Computer` только просят её рассмотреть такой вариант. Кнопок принудительного запуска нет.

Выключить навыки можно в **Настройки → Work и агенты → Навыки ИИ**. Выключенный навык модели недоступен вовсе.

## Какая модель действует

Навыку нужна модель со зрением: она смотрит на снимки страницы или экрана и решает, куда нажать. Для каждого навыка можно выбрать отдельную модель; если не выбрано ничего, используется модель Vision из настроек распознавания изображений. Без подходящей модели MemuAI сообщит, что сначала её нужно добавить в Proxy.

Лимит шагов не даёт навыку работать бесконечно: по умолчанию 16 действий для Browser и 12 для Computer Use.

## Browser

- Работает в **отдельном профиле Edge**, не в вашем обычном браузере: у него нет ваших паролей, закладок и входов на сайты.
- Страница, ход действий и журнал видны справа, в панели внутри MemuAI. Панель можно скрыть.
- Разрешены только адреса `http` и `https`. Локальная сеть закрыта; исключение — `localhost` проекта, над которым вы работаете, чтобы модель могла проверить свой сайт.
- Загрузки файлов, ввод паролей и платёжных данных блокируются.
- Текст страниц — непроверенные данные: инструкции, найденные на сайте, модель не выполняет.

## Расширение для вашего Chrome

Для чтения страниц, вкладок и работы с вашими входами в Chrome доступно [расширение Chrome · MemuAI](doc:integrations): **Настройки → Интеграции → Chrome · MemuAI**, загрузка ZIP, **Загрузить распакованное расширение** в `chrome://extensions`, затем сопряжение одноразовым кодом. Расширение добавляет инструменты `chrome_*` и боковую панель чатов. Контекст страницы, управление, [DFY в вашем Chrome](doc:dfy) и задания без подтверждений включаются отдельно. Быстрый доступ предпочитает расширение, когда оно подключено; в других браузерах сохраняется прежнее чтение. Навык **Browser**, описанный выше, продолжает работать в отдельном профиле Edge.

## Computer Use

- Перед передачей управления MemuAI показывает, что модель собирается сделать, и **ждёт вашего подтверждения**.
- Пока модель управляет компьютером, вокруг всех мониторов видна рамка.
- **++Esc++ немедленно останавливает** работу.
- Действия с секретами, покупки, публикации и удаление данных запрещены всегда, независимо от настроек и просьб.

> [!WARNING]
> Computer Use действует в вашей настоящей сессии Windows. Закройте окна с личными данными перед запуском и не оставляйте компьютер без присмотра, пока модель работает.

## Результат

Отчёт навыка — что сделано, что увидено, ошибка или отмена — возвращается основной модели, и она продолжает задачу. Отчёт тоже считается непроверенными данными.
