# MemuCode

**MemuCode** — режим для программистов. В отличие от [Work](doc:work), он рассчитан на репозиторий: модель запускает тесты и сборку, смотрит git, показывает изменения построчно, а каждую правку можно откатить.

Открывается кнопкой **MemuCode** в боковой панели или командой `/code`.

## Экран

| Часть | Что там |
| --- | --- |
| Полоса сверху | проект, разрешения, план, запуск и остановка процессов, состояние песочницы |
| Слева над чатами | дерево файлов проекта с фильтром и веткой git |
| В центре | чат с агентом |
| Справа | панель с разделами: файл, изменения, артефакты, терминал, задачи, откат, скиллы |

Обе боковые панели скрываются кнопками на верхней полосе и возвращаются ими же. Правую панель можно растянуть на всю ширину кнопкой «Развернуть панель» в её шапке.

### Клавиши

| Клавиши | Действие |
| --- | --- |
| ++Ctrl+P++ | найти файл, команду или скилл |
| ++Ctrl+Shift+E++ | дерево проекта |
| ++Ctrl+Shift+D++ | правая панель |
| ++Ctrl+Ё++ (клавиша обратного апострофа) | терминал |
| ++Alt+1++ … ++Alt+7++ | разделы правой панели |

## Файлы

Щелчок по файлу в дереве открывает его справа с подсветкой синтаксиса. Кнопки в шапке файла: скопировать путь или текст, упомянуть в запросе (`@путь`), показать в проводнике, **Изменить**.

### Правка вручную

**Изменить** (клавиша ++E++ или ++Alt++ + двойной щелчок по строке) превращает просмотр в редактор:

| Клавиши | Действие |
| --- | --- |
| ++Ctrl+S++ | сохранить |
| ++Ctrl+Z++ / ++Ctrl+Y++ | отменить / повторить |
| ++Ctrl+F++ / ++Ctrl+H++ | найти / найти и заменить |
| ++Ctrl+G++ | перейти к строке |
| ++Ctrl+/++ | закомментировать строки |
| ++Ctrl+D++ | дублировать строку |
| ++Alt+↑++ / ++Alt+↓++ | переместить строку |
| ++Tab++ / ++Shift+Tab++ | сдвинуть вправо / влево |

У редактора своё контекстное меню со всеми этими действиями. Кодировка и концы строк файла сохраняются. Если в файл в кодировке Windows-1251 добавлен символ, которого в ней нет, файл сохраняется в UTF-8, чтобы ничего не потерять.

Если, пока вы правили, файл изменил агент или другая программа, редактор покажет конфликт: **Сохранить мою версию** или **Взять версию с диска**. Ручная правка тоже попадает в [откат](#изменения-и-откат) с пометкой «ваша правка».

## Разрешения

Кнопка разрешений на верхней полосе (или команда `/access`) выбирает, что агент делает без вашего подтверждения:

| Уровень | Правки файлов | Команды |
| --- | --- | --- |
| **С подтверждением** (по умолчанию) | ждут вашего решения | ждут вашего решения |
| **Правки без вопросов** | применяются сразу, отменяются в разделе «Откат» | ждут вашего решения |
| **Полный доступ** | применяются сразу | выполняются сразу |

Команды чтения — `git status`, `git diff`, `ls` и подобные — выполняются на любом уровне. `/access ask`, `/access edits` и `/access full` переключают уровень сразу, без окна выбора.

### Подтверждение в чате

Когда агенту нужно разрешение, ход останавливается, а в чате появляется карточка: для правки — дифф, для команды — сама команда и где она выполнится. Варианты ответа:

- **Применить** (для удаления — **Удалить**) или **Выполнить** — один раз;
- **Разрешить правки в этой сессии** / **Разрешить команды в этой сессии** — до конца текущей сессии такие действия идут без вопросов, а на кнопке разрешений появляется «+»;
- **Отклонить** — агент получает отказ и продолжает без этого действия;
- можно просто написать в чат, что сделать иначе: сообщение отклонит действие и уйдёт агенту как указание.

Кнопка остановки ответа отменяет и ожидающее действие. Если перезагрузить окно, пока карточка ждёт, она получает отметку «Не дождалось решения» — ничего не выполняется.

## Настройки MemuCode

**Настройки → MemuCode** собирают всё, что относится к окну MemuCode:

- **Разрешения** — те же три уровня, что и на полосе;
- **Агент** — модель для MemuCode (по умолчанию — как в чатах), план перед правками для новых сессий, автоматическая проверка (агент сам запускает тесты и линтеры после правок; если выключить, он только назовёт команду проверки), правила проекта и лимит шагов — сколько раундов инструментов агент делает за один ответ (от 6 до 50, по умолчанию 20);
- **Редактор и изменения** — размер шрифта кода, перенос длинных строк, вид диффа (общий или рядом), открывать ли изменённый агентом файл в правой панели; живой пример сразу показывает результат;
- **Терминал** — очистка истории команд;
- **Инструменты** — скиллы, серверы MCP, агенты и горячие клавиши.

### Правила проекта

MemuCode читает те же файлы инструкций, что и MemuCode CLI: `MEMUCODE.md`, `AGENTS.md` или `CLAUDE.md` в проекте (также в `.memucode/` и `.claude/`), в папках выше проекта, личный `MEMUCODE.md`, файлы `*.local.md` и подключённые в них через `@файл`. Агент получает их в начале каждого ответа: команды сборки и тестов, стиль кода, соглашения. Команда `/memory` показывает, какие файлы действуют, `/init` изучает проект и пишет `MEMUCODE.md`. Если правила расходятся с вашей просьбой, главнее просьба. Отключается переключателем **Правила проекта** в настройках.

## Терминал и песочница

Команды проекта — `npm test`, `python -m pytest`, `git status` — выполняются в папке проекта, в **песочнице**: отдельном объекте заданий Windows с ограничением памяти (2 ГБ) и времени. В окружение не попадают секреты. Кнопка **Стоп** завершает все процессы песочницы разом.

Опасные команды — форматирование дисков, выключение компьютера и подобное — не запускаются ни в каком режиме.

Раздел **Терминал** — ваша консоль в той же песочнице: ++↑++ / ++↓++ листают историю команд. Долгие процессы — сервер разработки, сборку — агент запускает в разделе **Задачи**, не блокируя разговор.

## Изменения и откат

- **Изменения** — незакоммиченные изменения рабочего дерева git: общий вид или «рядом», копирование диффа.
- **Откат** — всё, что изменила текущая сессия. Перед первой правкой каждого файла MemuCode сохраняет его копию, поэтому откат работает даже без git и без коммитов. Можно откатить выбранные файлы или всё сразу.

Команды `/diff` и `/undo` открывают эти же разделы.

## Артефакты

Страницы, схемы SVG, заметки и данные, которые агент создаёт в сессии, хранятся отдельно от проекта — в разделе **Артефакты**, с версиями. Их можно открыть, скачать или записать в проект файлом — запись считается правкой и подчиняется [разрешениям](#разрешения).

## Команды MemuCode

| Команда | Что делает |
| --- | --- |
| `/review` | ревью текущих изменений по степени важности |
| `/test` | найти и запустить тесты проекта, разобрать падения |
| `/fix <описание>` | воспроизвести дефект, найти причину и минимально исправить |
| `/explain <файл или функция>` | разобрать код |
| `/refactor <что>` | переписать, сохранив поведение |
| `/plan <задача>` | спланировать работу до правок |
| `/init` | изучить проект и записать `MEMUCODE.md` для агентов |
| `/security-review` | проверить изменения на уязвимости, без правок |
| `/commit` | составить сообщение коммита по реальному диффу и сделать коммит |
| `/pr` | подготовить и открыть pull request |
| `/diff` | что изменила сессия, откат |
| `/undo` | вернуть файлы к состоянию до правок |
| `/compact [тема]` | сжать историю: суть остаётся, контекст освобождается; тема — на чём сосредоточиться |
| `/context` | чем занято окно модели |
| `/clear` | начать новую сессию — прежняя останется в `/resume` |
| `/resume` | открыть прежнюю сессию этого проекта |
| `/rename <название>` | назвать текущую сессию |
| `/copy [N]` | скопировать последний ответ (`/copy 2` — второй блок кода) |
| `/agents` | агенты MemuCode, их модели и разрешение для чата |
| `/skills` | скиллы: свои и из библиотеки |
| `/memory` | файлы инструкций агента: `MEMUCODE.md`, `AGENTS.md` и другие |
| `/mcp` | подключить внешние серверы инструментов |
| `/access` | выбрать уровень разрешений |
| `/status` | модель, доступ, проект, инструкции, MCP |
| `/stats` | статистика сессий, токенов и активности |

**Свои команды MemuCode CLI** — Markdown-файлы в `<проект>/.memucode/commands` и в личной папке `memucode\commands` (а также в папках Claude Code) — работают и в окне: `/имя аргументы` разворачивается так же, как в терминале (`$ARGUMENTS`, `$1`…). Если команды с таким именем нет, запускается скилл с этим именем. Переопределение модели в своей команде (`model:`) окно пока не учитывает — ответ пишет модель сессии.

## Агенты

В MemuCode те же агенты, что в MemuCode CLI: встроенные (`general-purpose`, `explore`, `plan`, `reviewer`, `tester`), личные (`memucode\agents` в папке данных MemuAI) и проектные (`<проект>/.memucode/agents`). Агенты в формате Claude Code (`~/.claude/agents`, `<проект>/.claude/agents`) тоже видны, но только для чтения. Агент — Markdown-файл: в заголовке имя, описание, инструменты, модель и цвет, в теле — роль. Личный или проектный агент с именем встроенного заменяет его — в окне и в CLI одинаково.

Вкладка **Агенты** правой панели (или `/agents`) показывает все типы агентов, позволяет создать, изменить и удалить свои, выбрать модели для агентов и их число. Переключатель **Агенты в этом чате без просьбы** разрешает ИИ запускать агентов сам; иначе агенты запускаются, только когда вы просите о них в сообщении («запусти агентов», «параллельно», «в фоне»). Главная модель выбирает подходящий тип агента для каждой подзадачи; запущенные агенты и их ход видны на той же вкладке.

В [агентной рабочей области](doc:spaces#агентная-область) компаньон в режиме MemuCode использует именно этих агентов MemuCode.

## Скиллы

Скилл — готовая инструкция для типовой работы: ревью, тесты, отладка, рефакторинг, коммиты, аудит безопасности, производительность и другие. Агент подключает нужный скилл сам. В палитре ++Ctrl+P++ префикс ++#++ ищет только скиллы, ++/++ — только команды.

Свои скиллы:

- для проекта — `<проект>/.memuai/skills/<имя>/SKILL.md`, они главнее встроенных;
- личные — в папке данных MemuAI, раздел **Скиллы** правой панели.

## MCP

Кнопка MCP на полосе (или `/mcp`) подключает внешние серверы инструментов по протоколу Model Context Protocol: базы данных, трекеры задач, документацию. Их инструменты становятся доступны агенту.

## Статистика

На главной странице MemuCode есть карточка **Статистика MemuCode**; команда `/stats` открывает её в отдельной панели. Учитываются только сессии MemuCode: число сессий и сообщений, токены на входе и выходе, активные дни, самый активный час, любимая модель и тепловая карта по дням. Объём токенов сравнивается с книгами и другими мерами (страницы, время чтения вслух) — случайное сравнение меняется кнопкой. Данные хранятся локально в `memucode-stats.json` профиля; если провайдер не сообщил токены, они оцениваются по длине текста.

## Экономия контекста

Агент получает дерево файлов и запрашивает точные диапазоны строк. Повторные чтения неизменённых фрагментов заменяются короткими ссылками — счётчик на полосе показывает, сколько символов не ушло в контекст повторно.

Начало запроса не меняется от хода к ходу: системная инструкция, контекст проекта и правила стоят на месте, поэтому провайдер берёт их из кэша и не считает заново. Старые раунды инструментов в длинной сессии сворачиваются в короткие отчёты, последние остаются целиком; `/compact` сжимает всю историю той же сводкой, что в MemuCode CLI, а `/context` показывает, что занимает окно модели.
