# Каталог модулей

Откройте **Настройки → Модули → Каталог**. Здесь можно найти дополнение по
названию, автору или тегам, выбрать категорию и показать только установленные
модули. Выберите карточку, чтобы посмотреть описание, автора, лицензию, размер,
версию и полный список доступов до установки.

Официальный источник — `module-catalog/index.json` в репозитории
[MemuAI/MemuAI](https://github.com/MemuAI/MemuAI). Сопровождающие проверяют код
вручную перед объединением pull request. Список доступов сверяется с манифестом,
а размер и SHA-256 пакета — с записью каталога. Контрольная сумма подтверждает
целостность загрузки и не заменяет проверку исходников.

## Исходники до установки

В сведениях модуля откройте **Исходный код**. MemuAI загружает пакет, проверяет
размер, SHA-256 и формат, затем показывает манифест, HTML, CSS, JavaScript,
переводы и объявленные дополнительные файлы. Код показывается как текст:
модуль не устанавливается и не запускается. Можно переключаться между файлами,
копировать выбранный текст или скачать файл и весь проверенный пакет.

Просмотр доступен и для пакетов, которым нужна более новая версия приложения.
Это позволяет изучить исходники, пока установка недоступна. Исходники загружаются
из текущей версии каталога; локальные изменения установленного модуля здесь не показаны.

## Установка и обновления

Нажмите **Установить** в сведениях о модуле. Установленный модуль остаётся
выключенным: вернитесь в **Мои модули** и включите его. При обновлении модуль
тоже выключается; сохранённые данные и настройки окна остаются на месте.

Если версия пакета изменилась, каталог показывает **Есть обновление**. Перед
заменой создаётся копия текущего кода. Если вы меняли код самостоятельно,
потребуется явно отметить замену этих правок. Старую версию можно вернуть
кнопкой **Вернуть предыдущую версию**. Сохраняются две последние резервные
копии кода; данные самого модуля при откате не меняются. Если новый код изменил
формат своих данных, совместимость старой версии зависит от автора модуля.

Каталог не заменит одноимённый встроенный модуль или модуль, установленный
из другого источника. Кнопка установки недоступна при несовместимой минимальной
версии MemuAI или неизвестных доступах.

Модули и источник каталога относятся ко всему приложению. Смена профиля во время
установки отменяет устаревшее действие, но не создаёт отдельный набор модулей.

## Работа без сети

Загруженный индекс сохраняется локально. Если официальный источник недоступен
при первом запуске, используется копия из комплекта приложения. Над списком
появляется явное сообщение об этом. Пакеты встроенной копии можно установить
без сети; сохранённый индекс сам по себе не содержит удалённых пакетов.

## Предложить свой модуль

Нажмите **Предложить модуль**, выберите свой модуль и заполните автора, лицензию,
категорию и теги. **Подготовить файлы** создаёт переносимый JSON-пакет и запись
каталога с размером и SHA-256; личные сохранённые данные в экспорт не входят.

Положите пакет в `module-catalog/packages/`, добавьте запись в массив `modules`
файла `module-catalog/index.json` и выполните
`python tools/check_module_catalog.py --write`. Вместе с этим обновится встроенная
копия. Создайте pull request и следуйте
[инструкции для авторов](https://github.com/MemuAI/MemuAI/blob/main/module-catalog/CONTRIBUTING.md).
Добавление в официальный каталог требует ручной проверки сопровождающими.

## Другой источник

Внизу списка откройте **Источник каталога**. Укажите публичный HTTPS-адрес
совместимого JSON-каталога и сохраните. Ссылку GitHub на файл можно вставить
в обычном виде: MemuAI преобразует её в raw. Пакеты должны находиться на том же
сайте. Локальные адреса, пароли в URL и нестандартные порты не поддерживаются.

Эта возможность позволяет использовать поддерживаемый сообществом каталог,
если официальный проект перестанет развиваться. За код стороннего источника
отвечает его владелец: команда MemuAI его не проверяет. Кнопка **Официальный**
возвращает исходный адрес. Ранее установленные модули остаются на месте.
