# Где хранятся данные

Всё, что MemuAI знает о вас, лежит на вашем компьютере в одной папке:

```
%APPDATA%\MemuAI
```

Её удобно открыть так: ++Win+R++ → вставить `%APPDATA%\MemuAI` → ++Enter++.

## Что где лежит

### MemuAI Proxy

| Файл или папка | Содержимое |
| --- | --- |
| `config.json` | настройки Proxy, ключи клиентов API |
| `accounts.json` | аккаунты провайдеров — куки и токены |
| `models.json` | каталог моделей |
| `logs\` | журнал запросов, если включено хранение между запусками |
| `metrics.json` | статистика запросов |
| `backups\` | автоматические резервные копии важных файлов |
| `local-models\` | [локальные модели](doc:local-models) и движок llama.cpp |
| `detector-history.json` | история [детектора моделей](doc:model-detector) |

### MemuAI

Папка `memuai\` внутри:

| Файл или папка | Содержимое |
| --- | --- |
| `preferences.json` | настройки, общие для всех профилей |
| `profiles.json` | профили; PIN хранится хэшем |
| `chats.json` | чаты профиля по умолчанию |
| `memory.json` | память |
| `schedules.json`, `schedule_results.json` | задачи по расписанию и их результаты |
| `workspaces.json` | проекты Work и MemuCode |
| `prompts.json` | библиотека промптов |
| `profiles\<id>\` | чаты, память, задачи и проекты остальных профилей |
| `themes\` | [свои темы](doc:themes) |
| `modules\` | свои модули и правки встроенных |
| `integrations.json` | ключи [интеграций](doc:integrations) |
| `voice-models\` | скачанные модели распознавания и голоса |
| `browser-profile\` | отдельный профиль Edge для навыка Browser |
| `checkpoints\`, `code_artifacts\` | точки отката и артефакты MemuCode |
| `startup-error.log` | причина сбоя запуска, если он был |

Скачанные файлы и экспорт чатов сохраняются отдельно — в `Загрузки\MemuAI`.

## Надёжность записи

Файлы записываются атомарно: сначала во временный файл, потом заменой. Сбой питания посреди записи не оставит полупустой файл. Для важных файлов хранятся кольцевые резервные копии, и при повреждении MemuAI восстанавливает последнюю исправную версию сам.

MemuAI и Proxy могут писать одни и те же файлы одновременно — например, чат из Telegram и из окна. Изменения сливаются, история не теряется.

## Приватность

- Сообщения уходят только тому сервису, чья модель выбрана. [Локальные модели](doc:local-models) не отправляют ничего.
- Куки, токены и ключи не показываются в интерфейсе, не пишутся в журналы и не передаются ИИ-помощнику.
- Статистика профиля считается на компьютере и никуда не отправляется.
- Своего сервера у MemuAI нет: окно программы — локальная страница, которую отдаёт сам MemuAI.

> [!NOTE]
> [Временный чат](doc:chats) не сохраняется в MemuAI, но сообщения всё равно попадают к сервису модели по его правилам.

## Удаление и сброс

- Удаление программы папку данных **не трогает**.
- Чтобы начать с чистого листа, закройте MemuAI и Proxy (трей → Выключить) и переименуйте папку `MemuAI` — например, в `MemuAI.old`. При следующем запуске создастся новая. Если что-то понадобится, старую можно вернуть.
- Удалить только чаты — **Настройки → Данные → Опасная зона → Удалить историю всех чатов**.

## Перенос на другой компьютер

Скопируйте папку `%APPDATA%\MemuAI` целиком, пока программы выключены. Подробнее — [Перенос данных](doc:transfer).
