# API Proxy

Proxy отдаёт все модели ваших аккаунтов через API в формате OpenAI. Поэтому к нему подключается почти любая программа, которая умеет работать с OpenAI: редакторы кода, чат-клиенты, скрипты.

## Адрес

```
http://127.0.0.1:8317/v1
```

Хост и порт меняются в **Proxy → Настройки → Сеть**. Новый порт начинает работать после перезапуска Proxy. Текущий адрес всегда виден на вкладке «Главная».

## Ключи

Пока в **Настройки → Доступ и безопасность → API-ключи клиентов** нет ни одного ключа, API открыт для программ этого компьютера и закрыт для сайтов в браузере. В поле «API key» клиента можно вписать любой текст.

Как только создан хотя бы один ключ, каждый запрос должен его передавать — иначе ответ `401`:

```
Authorization: Bearer <ключ>
```

Заголовок `x-api-key: <ключ>` тоже принимается.

> [!WARNING]
> Если хост изменён на `0.0.0.0`, Proxy виден в локальной сети. Без ключей API в этом режиме отказывает всем запросам, даже с этого же компьютера: создайте ключ и смените пароль панели.

## Эндпоинты

| Метод | Путь | Назначение |
| --- | --- | --- |
| `GET` | `/v1/models` | список включённых моделей |
| `GET` | `/v1/models/{id}` | одна модель |
| `POST` | `/v1/chat/completions` | ответ модели, обычный или потоком |
| `POST` | `/v1/messages` | Anthropic Messages для Claude Code |
| `POST` | `/v1/responses` | OpenAI Responses для Codex CLI |
| `GET` | `/health` | Proxy жив и отвечает |
| любой | `/p/<имя>/<путь>` | прямой проход к «Собственному API» с обходом CORS |

### Запрос к модели

Поддерживаются обычные поля OpenAI: `model`, `messages`, `stream`, `temperature`, `top_p`, `max_tokens`. Изображения передаются частями `image_url` с адресом `data:`.

Два поля добавлены MemuAI:

| Поле | Значения | Смысл |
| --- | --- | --- |
| `web_search` | `true` / `false` | включить поиск в интернете у модели, которая его умеет |
| `effort` | `auto`, `minimal`, `low`, `medium`, `high`, `max` | глубина размышлений у моделей с рассуждением |

## Примеры

### curl

```bash
curl http://127.0.0.1:8317/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{"model": "genspark-claude-sonnet-5", "messages": [{"role": "user", "content": "Привет"}]}'
```

### Python

```python
from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8317/v1", api_key="ваш-ключ")
reply = client.chat.completions.create(
    model="kiro-claude-sonnet-4-5",
    messages=[{"role": "user", "content": "Коротко: что такое SSE?"}],
)
print(reply.choices[0].message.content)
```

### JavaScript, потоком

```javascript
const response = await fetch("http://127.0.0.1:8317/v1/chat/completions", {
  method: "POST",
  headers: { "Content-Type": "application/json", Authorization: "Bearer ваш-ключ" },
  body: JSON.stringify({ model: "local-qwen3-8b-q4-k-m", stream: true,
    messages: [{ role: "user", content: "Три идеи для названия блога" }] }),
});
// Ответ приходит строками "data: {...}" и заканчивается "data: [DONE]".
```

## Готовые программы

Во всех программах выбирайте тип подключения **OpenAI compatible** (или «OpenAI API» со своим адресом):

| Поле клиента | Значение |
| --- | --- |
| Base URL / API base | `http://127.0.0.1:8317/v1` |
| API key | ваш ключ или любой текст, если ключей нет |
| Model | id из `/v1/models`, например `genspark-claude-sonnet-5` |

Так подключаются Cursor, Continue, Cline, Roo Code, Open WebUI, SillyTavern, Chatbox и другие. Пока модель думает, Proxy шлёт клиенту служебные пинги, поэтому долгие ответы в Cline и Continue не обрываются по таймауту.

## Claude Code и Codex CLI

В **Proxy → Настройки → Интеграции** выберите модели и примените настройки, затем перезапустите CLI. MemuAI сохранит прежние файлы конфигурации и сможет вернуть их состояние. Если у Proxy есть API-ключ клиента, он записывается в локальный файл настроек CLI (`~/.claude/settings.json` или `~/.codex/config.toml`).

Для агентных действий (чтение и правка файлов, запуск команд) выберите модель подключения **«Собственный API»**, чей сервер поддерживает OpenAI-совместимые `tools` / `tool_calls`. Proxy передаёт вызовы между моделью и CLI; сами действия выполняет CLI. Если выбрать веб-провайдера без native function calling, запрос с инструментами получит явную ошибку `400`, а обычный чат продолжит работать.

Если у вас уже есть отдельный API, выберите в этой же панели **«Свой API напрямую»** и укажите его Base URL, ключ и ID модели. В этом режиме CLI обращается к API без участия Proxy. Для Claude Code адрес должен поддерживать Anthropic Messages (`/v1/messages`), для Codex CLI — OpenAI Responses (`/v1/responses`) с вызовами инструментов. Ключ при повторном применении настроек вводится заново.

## Проход к своему API (`/p/`)

Для подключений типа «Собственный API» есть прямой адрес:

```
http://127.0.0.1:8317/p/<имя>/<путь>
```

Proxy подставляет ключ и дополнительные заголовки подключения и добавляет заголовки CORS. Это позволяет браузерному приложению обращаться к вашему API без собственного сервера. Запрос должен нести заголовок `x-hub-key` с ключом клиента Proxy.

## Ошибки

Ошибки приходят в формате OpenAI и дополнительно содержат подсказку:

```json
{
  "error": {
    "message": "Все аккаунты «kiro» недоступны (Work): HTTP 429",
    "message_en": "Every “kiro” account failed (Work): HTTP 429",
    "type": "rate_limit_error",
    "code": 429,
    "hint": "Провайдер временно ограничил частоту запросов. Обычно помогает второй аккаунт."
  }
}
```

| Код | Частая причина |
| --- | --- |
| 401 | неверный или отсутствующий ключ клиента |
| 404 | модель не найдена или выключена в каталоге |
| 400 | запросил инструменты у провайдера, который не поддерживает function calling |
| 429 | у всех подходящих аккаунтов лимит |
| 502 | провайдер ответил ошибкой, изменил протокол или не ответил вовремя |
| 503 | нет ни одного рабочего аккаунта этого провайдера или Proxy выключен кнопкой |

Каждый запрос виден во вкладке **Логи** с причиной ошибки, а кнопка **Разобрать** объяснит её простыми словами.

## Генерация музыки

Музыкальные модели из аккаунтов Proxy возвращаются `/v1/models` с `capabilities.music: true`. Для генерации используйте **POST `/v1/audio/music`** с тем же ключом клиента:

```json
{
  "model": "elevenlabs-music-music_v2_5",
  "request_id": "my-track-1",
  "prompt": "Мягкое вечернее фортепиано",
  "style": "ambient piano",
  "duration": 60,
  "tempo": 90,
  "instrumental": true,
  "lyrics": ""
}
```

Используйте точный ID из `/v1/models`. Ответ JSON содержит `audio` (data URL), `mime`, `model` и `provider`. Передайте `action: "cancel"` с тем же `request_id`, чтобы прекратить ожидание; отмена принадлежит тому же ключу клиента. Это расширение MemuAI Proxy, отдельное от стандартного TTS endpoint. Параметры и доступность зависят от настроенного музыкального сервиса.
