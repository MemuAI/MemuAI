# Что модуль помнит

Модуль не пишет файлы сам. Он просит хост запомнить значения, а хост решает, какие ключи разрешены.

## Три источника состояния

```javascript
Memu.saved          // поля с прошлого запуска (только разрешённые ключи)
Memu.manifest       // публичная часть описания модуля
Memu.env            // язык, тема, акцент, масштаб шрифта, платформа
```

`Memu.saved` доступен сразу при загрузке страницы: мост вставляет его в документ, не дожидаясь сети. Поэтому экран рисуется сразу с прошлыми данными, без мигания.

## Запись

```javascript
await Memu.save({ text: "привет", model: "genspark-claude-opus-5" });
```

- Ключ длиннее 40 символов обрезается.
- Ключ, которого нет в `persist`, игнорируется.
- Значение больше 2 МБ в JSON не записывается.
- За одно сохранение обрабатывается не больше 200 полей.
- Возвращается объект с полным актуальным состоянием.

Запись атомарная: файл `persist/<id>.json` заменяется целиком, повреждённый файл автоматически восстанавливается из кольцевого бэкапа MemuAI.

```javascript
const state = await Memu.save({ draft: text });
console.log(state.draft);   // то же значение, уже прочитанное обратно
```

## Что сохранять

- Пользовательские настройки: модель, язык, размеры панелей.
- Введённый текст или черновик.
- Небольшую историю (последние 20–50 записей).

Что не стоит: сгенерированные изображения целиком, гигабайтные логи, всё, что легко получить заново.

## Очистка

На карточке модуля есть «Очистить сохранённое». Удаление своего модуля удаляет и его поля. Сброс встроенного модуля возвращает код к заводскому, но сохранённые поля остаются — человек не теряет свои данные из-за сброса кода.


## Файловое хранилище

Поля `persist` подходят для настроек. Для больших данных — чатов, карточек с аватарами, библиотек — есть `Memu.store` (Round 29, право `storage`): каждый ключ — отдельный JSON-файл в `modules/store/<id>/`.

```js
await Memu.store.set("chats/alice/chat-1", { messages: [] });
const chat = await Memu.store.get("chats/alice/chat-1", null);   // второй аргумент — значение по умолчанию
const many = await Memu.store.getMany(["settings", "index"]);
const keys = await Memu.store.list("chats/alice/");               // [{ key, bytes, modified }]
await Memu.store.remove("chats/alice/chat-1");
const usage = await Memu.store.usage();                           // { bytes, keys, limit, value_limit }
```

- Ключ — до трёх частей через `/` из латиницы, цифр, `.`, `_`, `-`; `..`, абсолютные пути и имена устройств Windows отклоняются.
- Одно значение — до 40 МБ, всё хранилище модуля — до 2 ГБ.
- Модуль видит только своё хранилище; оно не попадает в экспорт пакета модуля.
