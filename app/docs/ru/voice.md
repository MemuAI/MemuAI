# Голос и MemuAI Live

Всё, что связано с голосом, настраивается в **Настройки → Голос и Live**.

## Диктовка

Кнопка микрофона рядом с отправкой записывает речь. После остановки запись распознаётся, и текст появляется в поле ввода — его можно поправить перед отправкой. Кнопка неактивна, пока выбранный распознаватель не готов.

### Распознаватель

| Источник | Как работает |
| --- | --- |
| Локальный | модель Whisper скачивается один раз и дальше работает без интернета; речь не покидает компьютер |
| Облачный сервис или свой API | распознавание через API выбранного сервиса; нужны его адрес, ключ и модель, если сервис её требует |

Выберите источник, затем **Сервис**: **OpenAI, Groq, Google Gemini AI Studio, ElevenLabs Scribe, Deepgram, Mistral Voxtral, Microsoft Azure Speech** или **свой OpenAI-совместимый API**. MemuAI использует нативный формат выбранного сервиса. Адрес и предложенные модели подставляются автоматически; вариант **Другое** позволяет ввести собственный ID. Для Azure укажите адрес своего Speech-ресурса и ключ; отдельный ID модели не нужен. Доступность модели и цена зависят от сервиса и вашего аккаунта.

Настройки каждого сервиса — адрес, ключ и модель — сохраняются отдельно. При переключении ключ другого провайдера не переносится. Ключ Gemini или ElevenLabs из озвучивания можно переиспользовать отдельной кнопкой. **Проверить аудиофайлом** сохраняет настройки и распознаёт выбранную вами запись; результат или понятная ошибка показываются рядом. Язык можно задать явно или определять автоматически, если это поддерживает модель.

Локальные модели:

| Модель | Размер | Особенности |
| --- | --- | --- |
| Whisper Tiny | 75 МБ | самая быстрая, для слабых компьютеров |
| Whisper Base | 142 МБ | быстрая, для коротких заметок |
| Whisper Small | 466 МБ | лучший баланс точности, скорости и размера |
| Whisper Medium | 1,5 ГБ | точнее на длинной речи и сложных акцентах |
| Whisper Large v3 Turbo | 1,6 ГБ | точность большой модели с ускоренным разбором |
| Distil-Whisper Large v3 | 1,5 ГБ | быстрая для длинных записей на английском; Distil Large v2 также только для английского |
| Whisper Large v3 | 3,1 ГБ | лучшая точность, самая медленная |

Скачивается только выбранная модель. Показываются реально полученные байты и процент, если известен общий размер; загрузку можно отменить. Модель становится доступна после проверки и установки, временные файлы отменённой загрузки очищаются. Папку моделей можно сменить, когда нет активной загрузки/установки; свою модель можно добавить. Завершение загрузки само не переключает уже выбранный распознаватель.

### Запись

| Настройка | Смысл |
| --- | --- |
| Язык речи | «Автоматически» лучше подходит для смешанной речи |
| Устройство ввода | системный микрофон надёжнее при переподключении гарнитуры |
| Шумоподавление, подавление эха, автогромкость | обработка звука браузерным движком |
| Максимальная запись | предел длины одной записи в секундах |

### Очистка диктовки

**Постобработка** — необязательный шаг: выбранная текстовая модель исправляет пунктуацию и регистр, записывает произнесённые числа цифрами, убирает оговорки и слова-паразиты, разбивает на абзацы. Она не отвечает на текст, не пересказывает и не меняет смысл. Инструкцию обработки можно изменить и сохранить как пресет.

## Озвучка ответов

Меню любого ответа в обычном чате → **Озвучить**. Перед чтением Markdown, таблицы, формулы и код превращаются в естественную речь.

Чем озвучивать, выбирается одним списком в **Настройки → Голос и Live → Озвучивание ответов → Чем озвучивать**:

| Вариант | Что нужно |
| --- | --- |
| Голоса Windows | ничего: используются голоса, установленные в системе; без интернета |
| Скачанный голос Piper | нейросетевые голоса, скачиваются один раз и дальше работают без интернета; язык сообщения определяется сам |
| OpenAI | API-ключ OpenAI; модели `gpt-4o-mini-tts`, `tts-1`, `tts-1-hd`, голоса alloy, nova, coral и другие |
| Google Gemini (AI Studio) | ключ Google AI Studio; 30 голосов Gemini (Kore, Puck, Zephyr…), понимают русский |
| ElevenLabs | ключ ElevenLabs; голос — `voice_id` из вашей библиотеки ElevenLabs |
| Microsoft Azure Speech | ключ ресурса Speech и его регион в адресе (вместо `westeurope`); сотни нейроголосов |
| Другой OpenAI-совместимый API | адрес (корень API — к нему добавляется `/audio/speech`), ключ, модель и голос |
| Свой локальный сервер | OpenAI-совместимый сервер речи на этом компьютере (Kokoro-FastAPI, XTTS…) |

У облачных сервисов MemuAI сам подставляет адрес, предлагает модели и голоса и даёт ссылку **Где взять ключ →**. Каждый сервис получает запрос в своём собственном формате, а длинный ответ делится на части по лимиту сервиса. Если что-то не так — неверный ключ, нет такой модели, кончилась квота, — вместо страницы ошибки сервиса вы увидите короткое понятное сообщение. Если голос или ключ принадлежит другому сервису (например, голос OpenAI «alloy» выбран для Gemini), под полем появится предупреждение — при смене сервиса модель и голос сбрасываются на его значения по умолчанию. Кнопка **▶ Проверить** сохраняет настройки и проигрывает пробную фразу тем же путём, что и настоящая озвучка. Повторное **Озвучить** того же ответа берётся из кэша и не оплачивается заново.

Старые настройки «TTS API» продолжают работать: сервис определяется по адресу.

Скорость (если сервис её поддерживает; у Gemini и ElevenLabs её нет) и громкость настраиваются. Озвучка работает в отдельном процессе: если голосовой движок упадёт, MemuAI покажет ошибку, но сам продолжит работать.

## MemuAI Live

Кнопка Live рядом с отправкой открывает голосовой разговор: говорите — модель слушает, отвечает и, если включено **Автоматически озвучивать ответы**, читает ответ вслух. Разговор сохраняется в текущем обычном чате обеими сторонами.

Остановить — закрыть Live или нажать на сферу. Закрытие во время записи отменяет её.

У Live своя короткая разговорная инструкция — **Личность Live и пресеты**: можно сделать собеседника строже, короче или, наоборот, разговорчивее.

## Live-модели реального времени

Обычный Live работает цепочкой: распознавание речи → модель чата → озвучка. **Live-модели** (GPT-Live-1, Gemini Live, Grok Voice и совместимые) слушают и говорят сами: без пауз на распознавание, со своим естественным голосом, и их можно перебивать. Переключатель **Использовать Live-модель в MemuAI Live** в **Настройки → Голос и Live → Live-модели реального времени** выбирает режим; выключенный переключатель возвращает обычную цепочку.

### Провайдеры

| Провайдер | Модели по умолчанию | Ключ |
| --- | --- | --- |
| OpenAI GPT-Live | `gpt-live-1` | platform.openai.com → API keys |
| OpenAI Realtime | `gpt-realtime`, `gpt-realtime-mini` | тот же ключ OpenAI |
| Google Gemini Live | `gemini-3.8-live`, `gemini-3.8-live-extended-thinking` | aistudio.google.com → Get API key |
| xAI Grok Voice | `grok-voice-latest` | console.x.ai → API Keys |
| Свой · OpenAI Realtime | любой ID | по требованию сервера |
| Свой · Gemini Live | любой ID | по требованию сервера |

«Свой» подходит для любого API, совместимого с протоколом OpenAI Realtime или Gemini Live: укажите адрес `wss://…` (для сервера на этом компьютере допускается `ws://127.0.0.1`). У встроенных провайдеров адрес можно заменить, например на прокси или регион.

### Настройка

1. Включите переключатель и выберите провайдера.
2. Вставьте ключ — он хранится в папке данных MemuAI и не передаётся в окно: соединение с провайдером открывает сам MemuAI.
3. При желании укажите модель и голос — подсказки есть в выпадающих списках, но можно вписать любой ID.
4. Нажмите **Проверить подключение**: MemuAI откроет сессию, дождётся подтверждения и сразу закроет её.

В разделе **Дополнительно** — определение очереди (семантическое ждёт законченной мысли, серверный VAD реагирует на паузу) и, для своего API, диалект протокола: GA или старый beta.

### Как идёт разговор

Нажмите Live и **Начать разговор** — MemuAI попросит доступ к микрофону и начнёт слушать. Сфера дышит в такт голосу: вашему, пока вы говорите, и модели, пока звучит ответ. Под сферой — субтитры обеих сторон; каждая реплика сохраняется в текущем чате обычным сообщением.

- Заговорите во время ответа или нажмите на сферу — модель остановится и выслушает.
- Кнопка микрофона приглушает вас, не завершая разговор.
- Кнопка клавиатуры (если модель её поддерживает) позволяет написать реплику текстом.
- **Завершить** закрывает сессию у провайдера.

Модель получает выбранную личность Live с приоритетом над обычным тоном чата, инструкции мемеса, ваши общие инструкции, инструкции чата, профиль и последние сообщения разговора как контекст.

### Камера и показ экрана

Во время разговора рядом с кнопкой **Завершить** появляются две кнопки: **камера** и **экран**. Включённый источник виден в маленьком окне под сферой; одновременно работает один — второй его заменяет. Повторное нажатие выключает показ.

| Провайдер | Как модель видит |
| --- | --- |
| Gemini Live | смотрит видео, пока вы говорите: около кадра в секунду |
| OpenAI Realtime | свежий кадр прикладывается к каждой вашей реплике |
| GPT-Live | сама не видит: последний кадр получает модель MemuAI, которой GPT-Live передаёт сложные вопросы |
| Grok Voice | не поддерживается: модель принимает только звук — кнопок нет |

Для показа экрана MemuAI сначала открывает системное окно выбора экрана или окна. Если оно недоступно, экран снимает сам MemuAI — целиком основной монитор, раз в секунду; в окне Live при этом видна уменьшенная копия того, что уходит модели.

> [!WARNING]
> Кадры уходят провайдеру Live-модели. Перед показом экрана закройте то, что не должно попасть к нему: переписку, пароли, документы.

### Веб-поиск в разговоре

Переключатель **Веб-поиск в Live** в настройках Live-моделей (включён по умолчанию) разрешает модели искать во время разговора. Пока идёт поиск, под сферой видна строка «Ищу: …»; найденные страницы прикрепляются к ответу в чате как обычный шаг поиска.

| Провайдер | Как ищет |
| --- | --- |
| Gemini Live | собственный Google Search модели. Если модель его не принимает — так бывает на бесплатном тарифе ключа, где на поиск нет квоты, — MemuAI это замечает и ищет сам, источником из раздела [Веб-поиск](doc:web-search); разговор начинается как обычно |
| OpenAI Realtime и свои API | модель просит MemuAI искать и открывать страницы — тем же источником |
| Grok Voice | собственный поиск по вебу и по X; если сервер его не принял — поиск MemuAI |
| GPT-Live | передаёт вопрос бэкенд-модели, а ищет она |

### Сложные вопросы в GPT-Live

GPT-Live ведёт разговор, а задачи, требующие знаний и рассуждений, передаёт бэкенду. По умолчанию бэкенд — **модель MemuAI**: текущая модель чата или выбранная в **Дополнительно → Модель MemuAI для делегированных вопросов** (любой провайдер из Proxy). Ответ возвращается GPT-Live, и она произносит его своими словами; пока идёт делегирование, сфера показывает «Обдумывает ответ». Можно выбрать и **OpenAI Responses** с моделью OpenAI.

> [!NOTE]
> Live-модели платные у провайдеров и расходуют их лимиты. Разговор идёт напрямую к провайдеру через MemuAI; MemuAI Proxy для него не нужен.

## Скрыть кнопки

Микрофон и Live можно убрать из поля ввода переключателями «Микрофон рядом с отправкой» и «Показывать Live рядом с отправкой».

## Ключи и приватность

Ключи API хранятся в локальной папке данных MemuAI. С локальным распознаванием и голосами Windows или Piper звук никуда не отправляется.

См. также: [Поле ввода](doc:composer).

## Голосовые сообщения в чате

В Live обе стороны разговора сохраняются как голосовые сообщения с обычным плеером и транскрипцией. Текст Live появляется по мере получения, если провайдер присылает частичные транскрипции. Плеер можно запускать позже независимо от текущей сессии; её звук продолжает идти в реальном времени. В режиме распознавание → обычная модель → озвучка сохраняются исходная запись и синтезированный ответ; выключенное автовоспроизведение сохраняет озвучку без её запуска. Временные чаты держат запись только до закрытия; обычные — в папке активного профиля. В длинной реплике сохраняются первые три минуты аудио Live.

Выбранная личность Live имеет приоритет над обычной личностью чата. В списке чатов Live отмечен небольшой иконкой; её можно выключить в «Настройки → Общие → Отмечать Live-чаты».

Обе стороны используют широкий плеер: воспроизведение, перемотка и своё меню «⋮» со скоростью, скачиванием записи и копированием транскрипции. Короткая реплика не сжимает элементы управления. Положение воспроизведения сохраняется при обновлении сообщения; клавиши стрелок перематывают на пять секунд, Home и End — в начало и конец.

Личность задаёт способы реагировать, темп разговора, инициативу и примеры реплик. Основной стиль имеет приоритет, дополнительные стили добавляют акценты. Например, романтичный стиль задаёт образную, нежную речь и эмоциональные ответы, а профессиональный — ясные деловые формулировки. Изменение личности во время звонка переподключает Live с обновлёнными инструкциями. Итоговая манера зависит также от выбранной модели.
