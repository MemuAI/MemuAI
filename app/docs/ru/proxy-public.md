# Публичный доступ

Обычный адрес MemuAI Proxy (`127.0.0.1:8317`) рассчитан на программы на этом же компьютере: на нём живут панель и управление аккаунтами. Открывать его в сеть нельзя.

**Публичный доступ** — второй, отдельный адрес. На нём снаружи доступны только запросы к моделям: `/v1/models`, `/v1/chat/completions`, `/v1/responses` и `/v1/messages`. Панели, управления, ваших аккаунтов и ключей провайдеров там нет — любой другой адрес отвечает «не найдено». Входят только по ключам, которые вы создали во вкладке **Публичный доступ**.

Так можно дать моделям пользоваться другу, своему телефону, серверу или боту — и в любой момент ограничить или отозвать доступ.

## Включение

Вкладка **Публичный доступ** устроена как четыре шага сверху вниз:

1. **Публичный сервер** — выберите, **где слушать**, и порт (по умолчанию 8320; допустимы числа от 1 до 65535 — пустое поле или 0 возвращают 8320), затем включите переключатель. Строка состояния покажет «Работает» и адрес; если порт занят или адреса нет на этом компьютере — причину.
2. **Адрес для подключения** — ссылки для этого компьютера и локальной сети, а для интернета проще всего бесплатный [Cloudflare Tunnel](#бесплатный-адрес-через-cloudflare-tunnel). Свой домен, проброс порта и HTTPS спрятаны в «для опытных».
3. **Модели и ключи** — отметьте **модели**, которые будут видны снаружи (без них сервер не включится), и создайте хотя бы один **ключ** — без ключа сервер никого не пустит.
4. **Подключение** — готовые примеры с вашим адресом: curl, OpenAI Python, Node и Anthropic SDK, с кнопкой копирования.

Подключение такое же, как к любому API, совместимому с OpenAI: адрес из шага 2 и ключ `mpk-…`.

## Где слушать

| Вариант | Когда выбирать |
| --- | --- |
| Все сети этого компьютера (`0.0.0.0`) | доступ из локальной сети и, после проброса порта на роутере, из интернета |
| Только этот компьютер (`127.0.0.1`) | перед эндпоинтом стоит туннель или обратный прокси — наружу смотрит он |

**Домен или внешний IP** нужен только для ссылки, которую вы показываете людям: сам Proxy на него не влияет.

### Бесплатный адрес через Cloudflare Tunnel

Самый простой способ открыть доступ из интернета — без роутера, «белого» IP и сертификатов. Нажмите **Запустить туннель**: MemuAI запустит программу `cloudflared` и через несколько секунд покажет адрес вида `https://…trycloudflare.com` с HTTPS. Если `cloudflared` на компьютере нет, MemuAI предложит **Скачать cloudflared** — официальную программу Cloudflare с GitHub, после вашего подтверждения.

- Такой адрес **временный**: после перезапуска туннеля он меняется. Отметьте **Запускать туннель вместе с сервером**, чтобы не запускать его вручную.
- Для постоянного адреса на своём домене выберите **Именованный** туннель: вставьте **токен туннеля** из панели Cloudflare (**Networking → Tunnels → Create a tunnel**: токен есть в команде установки, её можно вставить целиком) и его hostname — его задают на вкладке **Routes → Add route → Published application** с Service URL адреса Proxy. Токен хранится только на этом компьютере и больше не показывается.
- Для туннеля достаточно варианта «Только этот компьютер (`127.0.0.1`)».
- Туннель останавливается вместе с MemuAI Proxy — после закрытия Proxy адрес перестаёт открываться.

### Чтобы адрес открывался из интернета

- При первом включении Windows спросит про брандмауэр — разрешите доступ.
- На роутере пробросьте выбранный порт на этот компьютер. Если провайдер интернета выдаёт «серый» адрес (CGNAT), проброс не поможет.
- Проще и надёжнее — **туннель**: встроенный Cloudflare Tunnel (раздел выше), ngrok, Tailscale Funnel. Слушайте на `127.0.0.1`, а сторонний туннель направьте на `http://127.0.0.1:8320`. Туннель заодно даёт HTTPS.
- **Без HTTPS** ключи и переписка идут по сети открытым текстом. Для интернета используйте туннель или укажите в разделе «HTTPS и браузеры» файл сертификата и его ключ — тогда Proxy сам отвечает по HTTPS.

**Проверить доступность** показывает, отвечает ли сервер на этом компьютере, и ваш внешний адрес. Проверить порт «снаружи» изнутри сети удаётся не всегда: многие роутеры не пускают компьютер на его же внешний адрес. Надёжная проверка — открыть `…/health` с телефона через мобильный интернет.

## Модели

Снаружи видны только отмеченные модели. Запрос к любой другой получает «модель не найдена» и не доходит до ваших аккаунтов. Список можно сужать и для отдельного ключа.

## Общие лимиты

Действуют на всех вместе, поверх лимитов ключей. 0 — без ограничения.

| Лимит | Что ограничивает |
| --- | --- |
| Запросов в минуту | сколько запросов эндпоинт принимает за минуту от всех ключей |
| Одновременных запросов | сколько ответов готовится сразу; лишние получают «сервер занят» |
| Потолок ответа, токенов | запрос с `max_tokens` больше этого отклоняется |

## Ключи

У каждого человека или приложения — свой ключ. Для ключа задаются:

| Поле | Смысл |
| --- | --- |
| Кому выдан, заметка | чтобы отличать ключи в списке |
| Запросов в минуту, в день | личные ограничения частоты |
| Одновременных запросов | сколько ответов для этого ключа готовится сразу |
| Токенов в день, в месяц | сколько токенов (вход + выход) ключ может потратить; дневные лимиты сбрасываются в полночь, месячные — 1-го числа |
| Токенов всего | когда они потрачены, ключ перестаёт работать |
| Макс. токенов в ответе | запрос с большим `max_tokens` отклоняется |
| Бюджет, $ | денежный потолок, оценивается по ценам моделей (вход + выход) |
| Разрешённые IP-адреса | через запятую, можно подсети (CIDR); пусто — с любого адреса. Список с ошибкой (например, `1.2.3.4/40`) не сохраняется: форма остаётся открытой и показывает, какие записи неверны |
| Действует до | после этой даты ключ отклоняется |
| Модели | все модели публичного списка или только выбранные |

**Ключ показывается один раз** — сразу после создания. Скопируйте его: MemuAI хранит только отпечаток ключа и показать его снова не может. Потеряли ключ — нажмите **Ротация**: старый перестанет работать сразу, а новый покажется один раз.

В списке видно, сколько запросов и токенов ключ потратил сегодня, за месяц и всего, примерную стоимость, последнюю активность и сколько раз ему отказали. Ключ можно приостановить переключателем, изменить, выпустить заново (**Ротация**), обнулить статистику или отозвать крестиком ✕ — ключ удаляется, доступ по нему прекращается сразу.

Токены считаются по ответам провайдеров. Если провайдер не сообщает число токенов, Proxy оценивает его по длине текста — лимиты в токенах тогда приблизительны.

Когда лимит исчерпан, клиент получает ошибку 429 с понятной причиной и заголовком `Retry-After`. Неверный ключ — ошибка 401, выключенный или просроченный ключ, чужой IP или модель, недоступная этому ключу, — 403, неопубликованная модель — 404.

### Как определяется адрес клиента

Список IP проверяется по настоящему адресу того, кто прислал запрос. Если запрос пришёл с этого же компьютера (через туннель или обратный прокси), адрес берётся из заголовков:

- `CF-Connecting-IP` учитывается, **только пока работает встроенный туннель MemuAI** — его подставляет сам Cloudflare;
- из `X-Forwarded-For` берётся **последний** адрес — его дописывает ближайший прокси (nginx, свой `cloudflared`); адреса перед ним клиент может написать сам, поэтому им не верят.

Так ключ с ограничением по IP нельзя обойти, подставив чужой адрес в заголовок.

## Что стоит помнить

- Запросы по публичным ключам расходуют ваши аккаунты и их лимиты так же, как ваши собственные. Давайте ключи только тем, кому доверяете, и ставьте лимиты.
- Условия некоторых провайдеров запрещают делиться доступом. Это ваша ответственность.
- Запросы через публичный адрес идут тем же конвейером и видны во вкладке «Логи».
- Настройки и ключи хранятся в `public.json` в папке данных Proxy.
