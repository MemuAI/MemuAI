# Быстрый доступ в Проводнике и программах

Откройте [быстрый доступ](doc:quick-ask) (++Alt+Space++) над окном **Проводника** — и окно сразу знает, где вы: под полем ввода появляется чип вроде «Папка: Загрузки · выбрано 3 файла». Пока чип включён, каждый вопрос идёт вместе с этой папкой: ИИ может посмотреть список файлов, прочитать их (текст, PDF, DOCX), поискать по содержимому и **предложить изменения** — создать, поправить, переименовать, переложить или удалить файлы.

Работа идёт **строго внутри этой папки**: выйти выше (`..`), указать абсолютный путь или пройти через ярлык-ссылку (symlink, junction) нельзя. Системные папки (Windows, Program Files, ProgramData), корень диска и папки без права записи — только для чтения.

## Что можно сделать одним щелчком

Под чипом — кнопки действий (когда разговор уже идёт, они прячутся за стрелкой на чипе):

| Кнопка | Что происходит |
|---|---|
| Кратко о выбранном | ИИ читает выбранные файлы и пересказывает каждый в 1–3 предложениях |
| Объяснить папку | Назначение, структура, ключевые файлы; для проекта — стек и как запустить |
| Переименовать | Вы пишете правило («дата в начале, без пробелов») — ИИ предлагает таблицу «было → станет» |
| Разложить по папкам | По типу (по умолчанию) или по вашему правилу; показывается дерево новых папок |
| Преобразовать текст | Перевод, исправление ошибок, CSV → Markdown… Результат — новые файлы рядом |
| Создать файл | Например, README с описанием папки |
| Дубликаты | Без ИИ: сравнение по содержимому (размер → хеш), выбор, какую копию оставить |
| Поиск в файлах | Без ИИ: имена и текст внутри файлов; ++Enter++ — показать в Проводнике, ++Shift+Enter++ — открыть, ++Tab++ — спросить ИИ |

Можно и просто спросить своими словами: «какие из этих файлов старше года?», «сделай из этих заметок один конспект», «переименуй фото по дате».

## Изменения: предпросмотр, подтверждение, отмена

Всё, что ИИ хочет изменить, приходит **одной карточкой** под ответом: правки текста — как diff (зелёное добавлено, красное удалено), переименования — таблицей, раскладка — деревом папок. Режим доступа выбирается в настройках:

- **С подтверждением** (по умолчанию) — ничего не меняется, пока вы не нажмёте «Применить» (++Alt+Enter++).
- **Полный** — новые файлы, правки, переименования и перемещения применяются сразу. **Удаление и перезапись файла целиком всегда ждут вашей кнопки.**

После применения на карточке есть «Отменить»: файлы возвращаются как были (удалённое хранится в резервной копии, перезаписанное — тоже). Последние 12 наборов изменений можно отменить и из настроек. Если файл успели поменять после предпросмотра, изменение не применится — попросите заново.

> [!NOTE]
> Удаление из быстрого доступа не очищает место сразу: файлы лежат в резервной копии MemuAI, пока набор не вытеснят 12 более новых. Файлы больше 512 МБ отсюда не удаляются — удалите их в Проводнике.

## Другие программы

| Где открыто окно | Что видит быстрый доступ |
|---|---|
| Рабочий стол | Папку «Рабочий стол» |
| VS Code, Cursor, Windsurf, VSCodium | Открытый файл (его текст сразу в контексте) и папку проекта — с теми же инструментами, что для Проводника |
| Notepad++, Sublime Text, Блокнот, JetBrains | Открытый файл, если путь виден в заголовке или в командной строке программы |
| Word, Excel, PowerPoint | Открытый документ — **только чтение**: текст, лист (до 400 строк × 40 столбцов) или слайды читаются по вашему вопросу |
| Терминал (cmd, PowerShell, Windows Terminal) | Папку терминала. PowerShell не сообщает о `cd`, поэтому это может быть папка запуска — чип помечает это |

**Подсказки для программ** — свои кнопки для конкретных программ: например, «Ответ на письмо» над Outlook или «Помощь с формулой» над Excel. Выделенный текст уходит вместе с подсказкой. Настраиваются в разделе ниже.

## Инструменты окна

В ++Ctrl+K++ → «Инструменты»:

- **Валюты под полем ввода** — пишите «100 usd в rub», «€50 to $», «2,5k eur в рублях», «курс доллара»: результат появляется сразу, без ++Enter++ и без модели. Щелчок — копировать. Курсы — open.er-api.com, обновляются раз в 6 часов и работают офлайн по последнему курсу.
- **Пипетка** — цвет под указателем в момент ++Alt+Space++ или «Выбрать на экране»: наведите указатель и нажмите ++Space++. HEX, RGB, HSL, CMYK — щелчок копирует.
- **Текст с экрана без ИИ** — выделите область, и встроенное распознавание Windows вернёт текст: копировать, спросить ИИ, сохранить в заметку. Языки — те, что установлены в Параметрах Windows → Время и язык.
- **Объяснить ошибку на экране** — снимок экрана и вопрос «что это за ошибка и как исправить». Если выделен текст с ошибкой (traceback, `npm ERR!`, `Exception`…), под полем появится кнопка «Объяснить ошибку».
- **Заметка в MemuNote** — строка с датой и временем в файле «Быстрые заметки.md» (Документы\MemuAI Notes), который открывается в MemuNote. Кнопка «В заметку» есть и под ответом. Фраза «заметка: …» по-прежнему пишет в чат «Заметки» ([команды](doc:quick-commands)).
- **Последние загрузки** — свежие файлы из «Загрузок»; ++Enter++ делает файл контекстом вопроса (ИИ прочитает, переименует, перенесёт), ++Shift+Enter++ — показать в Проводнике.

## Настройки

Настройки → Быстрый доступ → «Проводник, программы и инструменты»: папка из Проводника, режим доступа, скрытые файлы, недавние изменения с отменой, редакторы и терминалы, документы Office, подсказки для программ, все инструменты окна и папка заметок. Настройки хранятся в `quick_apps.json`.

## Безопасность

- Папку определяет само приложение в момент ++Alt+Space++; страница окна знает только непрозрачный номер контекста и не может подставить другой путь.
- Программы и скрипты (`.exe`, `.bat`, `.ps1`, `.lnk`…) из быстрого доступа не запускаются.
- Текст файлов для ИИ — данные, а не команды: модель предупреждена не выполнять найденные в них инструкции, а любое изменение всё равно проходит через карточку.
