# Chat export

The export saves a chat the way you see it in MemuAI: formulas, tables, code highlighting, images and diagrams stay in place.

![The Export chat window](docs-img/en/chat-export.webp "Format, messages and options on the left, a live preview of the document on the right")

## How to open it

- ++Ctrl+Shift+S++ — export the current chat (the combination can be changed in [keyboard shortcuts](doc:shortcuts));
- right-click a chat in the list → **Export chat**;
- the **File → Export chat** menu in the window title bar.

A window opens with the format choice, settings and a live preview.

## Formats

| Format | What you get |
|---|---|
| **PDF** | For reading and printing. Microsoft Edge prints it in the background; without Edge the print dialog opens ("Save as PDF") |
| **Word** (DOCX) | An editable document: real tables, lists, coloured code, images and editable Office equations |
| **HTML** | One web page with everything inside: formula fonts, images, interactive charts |
| **Markdown** | Text with markup — for notes and Git |
| **JSON** | Message data — for programs and archives |
| **Text** | Plain text only |

## Which messages

- **All** — the whole chat;
- **Range** — from one message to another;
- **Pick** — tick the ones you need; quick buttons "All", "None", "Mine only", "Answers only".

## What to include

Title and details (name, date, message count, models), message times, images and charts, formulas, code highlighting, reasoning, tool steps, token stats and a table of contents — your questions as a linked list.

## Look

- **Theme** — light, dark, sepia, print or the current MemuAI design;
- **Font** for text and code, **size**;
- **Paper** A4 or Letter, **orientation**, **margins**;
- **Header and footer** — your own text on top and at the bottom (for example, "Confidential") and page numbers.

The last options you chose are remembered and offered next time.

## Where it is saved

By default the file goes to **Downloads/MemuAI**; after saving you can open it or show it in the folder. **Ask where** opens the usual Windows save dialog. Text formats can also be copied to the clipboard with **Copy**.

> [!TIP]
> The whole export runs on your computer: the chat is not sent anywhere.
