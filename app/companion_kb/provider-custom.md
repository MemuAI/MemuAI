# Собственный API (провайдер `custom`, префикс — имя подключения)

Любой OpenAI-совместимый API: OpenAI, OpenRouter, DeepSeek, Groq, Together, Mistral, локальные Ollama/LM Studio и т.д.

## Поля
- **Название** — станет префиксом моделей (`<название>-<модель>`): латиница, цифры, дефис. Имена встроенных провайдеров и `local` заняты.
- **Base URL** — корень API, обычно заканчивается на `/v1` (например `https://openrouter.ai/api/v1`, `http://127.0.0.1:11434/v1` для Ollama).
- **Протокол чата** — `auto` (по умолчанию), `chat` (Chat Completions) или `responses` (Responses API). В `auto` путь, заканчивающийся на `/responses`, выбирает Responses, остальные — Chat Completions.
- **Путь API чата** — пусто для стандартного пути (`Base URL/chat/completions` либо `Base URL/responses`). Путь с `/` считается от корня сайта (`/v1/responses`), без `/` — относительно Base URL (`deployments/my-model/responses?api-version=…`). Можно настроить нестандартный маршрут с выбранным протоколом; другой хост и URL-фрагменты запрещены, чтобы ключ не ушёл на посторонний сервер.
- **API-ключ** или **Пул API-ключей** (по одному в строке). Режим пула: random или failover-on-match — ключ отключается и запрос повторяется, если ошибка содержит одно из «ключевых слов критических ошибок» (например, `insufficient_quota`, `invalid api key`). Временные ошибки (Too many requests) туда не добавлять.
- **Доп. заголовки (JSON)** — например `{"HTTP-Referer": "https://example.com", "x-api-key": "…"}`.
- **Модели** — через запятую; пусто — список берётся из `GET /models` сервиса.
- **Модели генерации изображений** — работают через `/images/generations`.
- Пресеты популярных сервисов доступны при добавлении.

## Responses API
Выберите `responses` и укажите Base URL сервиса. Если путь обычный `/v1/responses`, достаточно Base URL `https://api.example.com/v1`; путь можно оставить пустым. Для нестандартного маршрута задайте «Путь API чата». Поля доступны при добавлении в «Дополнительно» и в редактировании подключения.

Работают потоковые SSE и обычные JSON-ответы, текст/изображения/файлы на вход, функция-инструменты и их результаты, JSON-формат, reasoning effort, учёт входных/выходных/кэшированных токенов. История остаётся под управлением MemuAI; отправляется `store: false`. Ключи и их ротация, сетевой прокси и отмена генерации работают как у Chat Completions. Responses-only сервис может не иметь `/models`: укажите модели вручную. Проверка доступности использует заведомо некорректный запрос и не запускает платную генерацию.

Встроенные серверные инструменты Responses (web/file search и др.), opaque/encrypted reasoning items и параметры сторонних Chat Completions-сэмплеров не переносятся. Клиентские инструменты MemuAI/MemuCode продолжают выполняться самим приложением.

## CORS passthrough
Браузерные приложения могут обращаться к API напрямую через `http://127.0.0.1:8317/p/<название>/<путь>` с заголовком `x-hub-key` — Proxy подставит ключ и заголовки.

## Типичные ошибки
- 401 «The API key was rejected» — неверный ключ или не тот Base URL.
- 402 — закончился баланс у сервиса.
- 404 на модель — такой модели у сервиса нет: уточнить имя.
- 400/415/422 с изображением — модель не поддерживает картинки.
- «The upstream JSON response exceeds 4 MB» — сервис игнорирует stream и шлёт огромный JSON.
