# Локальные модели

Вкладка «Локальные модели» запускает модели формата **GGUF** на компьютере пользователя через движок **llama.cpp** (`llama-server`). Модели появляются в каталоге с префиксом `local-` и в аккаунте «Локальные модели», который создаётся автоматически. Интернет нужен только для загрузки.

## Мастер подбора модели
- Кнопка «Подобрать модель» в карточке сверху вкладки. Шаги: Компьютер (видеокарта/VRAM, ЦП, ОЗУ, диск; «Другой компьютер…» — ввести VRAM/ОЗУ вручную) → Задачи (общение, код, агенты/инструменты, картинки, рассуждения, длинные документы; язык) → Приоритеты (качество↔скорость, контекст, память другим программам, лицензия, MTP-ускоритель) → Рекомендации.
- Каждая рекомендация: квант (можно сменить), ≈ токенов/с (оценка ±25 %), «Целиком на видеокарте» / «Видеокарта + ОЗУ» / «Процессор и ОЗУ», размер, контекст, лицензия, почему и предупреждения. «Не подошли: N» — с причинами (не помещается, нет зрения, нет инструментов, лицензия, короткий контекст).
- «Установить и настроить» ставит движок (если нет, Windows), скачивает файл (+ mmproj для картинок) и применяет настройки (контекст, параметры генерации, потоки). Затем «Запустить и проверить», «Открыть в чате». Ошибка загрузки — «Повторить» (докачка).
- Ничего не подошло — убрать «Картинки»/условие лицензии, уменьшить контекст, сдвинуть ползунок к скорости. «обновить данные» внизу мастера перечитывает каталог с Hugging Face.

## Движок
- «Установить движок» скачивает последнюю сборку llama.cpp с GitHub (ggml-org/llama.cpp) в `%APPDATA%\MemuAI\local-models\runtime`.
- Варианты сборки: **Авто** (NVIDIA → CUDA, AMD/Intel → Vulkan, иначе CPU), **CPU**, **Vulkan** (почти любая видеокарта), **CUDA** (NVIDIA, нужен свежий драйвер).
- Можно указать путь к своему `llama-server.exe` в настройках вкладки.
- Если GitHub недоступен или ограничил частоту запросов — повторить позже, использовать VPN или указать свой `llama-server`.

## Где взять модели
- **Поиск на Hugging Face**: поиск по названию, сортировка по загрузкам/лайкам/свежести. В репозитории видны все файлы GGUF с квантизацией и размером и оценка «потянет ли компьютер»: «Влезет в видеопамять» (быстро), «Пойдёт в ОЗУ» (медленнее), «Впритык», «Слишком большая». Один файл помечен «рекомендую».
- Закрытые (gated) репозитории требуют принять лицензию на сайте и указать токен Hugging Face в настройках вкладки.
- Загрузка докачивается после обрыва (файл `.part`), её можно отменить. Модели из нескольких частей (`-00001-of-00003.gguf`) скачиваются целиком.
- **＋ Файл с диска**: выбрать `.gguf` на диске; можно оставить файл на месте или скопировать в папку MemuAI.

## Квантизация — что выбрать
Q4_K_M — лучший баланс качества и размера; Q5_K_M / Q6_K — качественнее и тяжелее; Q8_0 — почти без потерь; Q3/Q2/IQ — для слабых ПК, с заметной потерей качества. Грубо: модель на 7–8B в Q4_K_M ≈ 4,5–5 ГБ.

## Настройки модели
Название, контекст (токенов; больше — больше памяти), слоёв на GPU (-1 = авто: llama.cpp сам подбирает слои под свободную видеопамять, 0 = только процессор), потоки, batch, температура/top_p/top_k/min_p/repeat penalty по умолчанию, лимит ответа, системный промпт по умолчанию, выгружать после простоя (минут, 0 — не выгружать), проектор изображений (mmproj — для vision-моделей), дополнительные аргументы llama-server.
- Одновременно в памяти держится столько моделей, сколько задано в «Моделей в памяти» (по умолчанию 1): запуск другой выгружает прошлую.
- Модель загружается при первом запросе (первый ответ медленнее), «Загрузить» делает это заранее; «Проверить» отправляет короткий вопрос; меню ⋯ → «Журнал сервера».
- Название, параметры генерации и системный промпт применяются сразу; контекст, слои, потоки, аргументы и mmproj — после перезапуска модели (она выгружается автоматически).

## Ошибки
- «llama-server аварийно завершился: нарушение доступа к памяти (код 0xC0000005)» — чаще всего вместо модели выбран draft-файл (MTP-голова, в имени обычно «draft»/«mtp»): метаданные у него от полной модели, а тензоров всего несколько. Proxy помечает такие файлы и не даёт запустить их отдельно. Скачать основной файл из того же репозитория, а draft указать в настройках модели в поле «Draft-модель для ускорения». Другие причины этого кода — повреждённый файл (скачать заново) или устаревший движок (обновить).
- «llama-server завершился с кодом…» — открыть «Журнал» модели. `failed to allocate` / `out of memory` — уменьшить контекст, слоёв на GPU или взять меньшую квантизацию. `unknown argument` — убрать дополнительный аргумент или обновить движок.
- «Модель не успела загрузиться» — очень большая модель на медленном диске; повторить.
- «Эта локальная модель не видит изображения» — добавить mmproj в настройках или не прикладывать картинку.
- «Разговор не помещается в контекст локальной модели» — увеличить «Длину контекста» в настройках модели или начать новый чат.
- «Шаблон чата этой локальной модели не поддерживает инструменты» — для агентов/MemuCode нужна модель с инструментами (в мастере — отметка «инструменты»). Локальные модели поддерживают function calling через API Proxy.
- Уже работают **Ollama / LM Studio / Jan / llamafile / KoboldCpp / text-generation-webui / vLLM**? Кнопка «Найти на этом компьютере» (порты 11434, 1234, 8080, 1337, 5001, 5000, 8000) находит их, а «Подключить» добавляет их как «Собственный API».
