# MemuAI Proxy — как устроено

MemuAI Proxy — локальное приложение Windows в системном трее. Оно хранит аккаунты AI-сервисов и отдаёт их модели через один OpenAI-совместимый API: `http://127.0.0.1:8317/v1`. Чат MemuAI работает через этот же Proxy.

## Окно Proxy — вкладки
- **Главная** — статус прокси (кнопки «Запустить/Остановить прокси», «Перезапустить», «Открыть MemuAI»), Endpoint и ключ API для копирования, статистика запросов, плитки провайдеров, пример подключения клиента.
- **Аккаунты** — карточки аккаунтов всех провайдеров. «＋ Добавить аккаунт», «✓ Проверить все», «↧ Экспорт». Порядок карточек = приоритет (перетаскивание). ПКМ по карточке — меню: проверить, изменить, включить/выключить, переместить, в резерв, удалить. Выделение: щелчок, Ctrl+щелчок, Shift+щелчок, Ctrl+A; кнопка «Выбрать несколько» включает флажки; панель «Выбрано: N из M» даёт массовые действия; Esc, кнопка «Отменить» или щелчок по пустому месту снимают выделение. При перетаскивании список прокручивается колесом и у края окна. «＋ Добавить аккаунт» → «Готовые подключения»: 100+ сервисов (плитки популярных + «Показать все сервисы» с поиском и фильтром регионов).
- **Локальные модели** — движок llama.cpp, поиск и загрузка GGUF-моделей с Hugging Face, добавление файла с диска, настройки каждой модели.
- **Детектор моделей** — проверка, та ли модель отвечает, что заявлена (токенизатор, скрытые инструкции, дата знаний), и визуальный тест без оценки ИИ: кнопки «Аквариум» и «Пеликан» и ещё 63 задания.
- **Публичный доступ** — отдельный адрес (по умолчанию порт 8320) для других людей и устройств: только `/v1/models`, `/v1/chat/completions`, `/v1/responses`, `/v1/messages`; свои ключи `mpk-…` с лимитами (запросов в минуту и в день, токенов в день, общий бюджет, срок, список моделей), выбранный список моделей, общие лимиты. Панели и управления на этом адресе нет.
- **Чат** — простой разговор с любой моделью Proxy без системных промптов, памяти и инструментов. Запрос идёт через обычный конвейер и виден в «Логах» — удобно, чтобы быстро проверить аккаунт или модель. Свой системный промпт можно задать в «Параметрах» вкладки.
- **ИИ-помощник** — этот чат.
- **Каталог моделей** — отдельная страница в панели слева: все модели, включение/выключение, значки, обновление списков.
- **Настройки** — основное, выбор аккаунта (балансировка), «Дополнительно» (сервер и API, ключи клиентов, надёжность, логи, настройки провайдеров, веб-поиск, пароль), выключение.
- **Логи** — «Запросы» (каждый запрос со стадиями и payload) и «Журнал сервера».

## Путь запроса
Клиент → `/v1/chat/completions` → маршрутизация модели по префиксу (`genspark-…`, `kiro-…`, `local-…`, имя своего API) → выбор аккаунта провайдера (балансировка, пропуск выключенных и невалидных) → адаптер провайдера → сервис. При временной ошибке запрос уходит на следующий аккаунт; число проходов и пауза между попытками — в «Настройки → Надёжность». Ошибка не выключает аккаунт и не отправляет его «на паузу»: он остаётся в очереди, а причина видна в карточке.

## Статусы аккаунта
- **ok** — рабочий; **invalid** — кука/токен не приняты (нужно обновить); **unknown** — ещё не проверялся; **disabled** — выключен пользователем.
- Лимит (429) и временные сбои статус не меняют: текст ошибки лежит в «Последней ошибке» карточки.
- Приоритет «резерв» — аккаунт используется, только когда обычные не ответили.
- Ключ копируется в окне «Изменить» (✎): у поля ключа и других секретных полей есть кнопки «показать» и «копировать». «Ключ не задан» — поле пустое.

## Данные
Всё хранится в `%APPDATA%\MemuAI`: `config.json` (настройки Proxy), `accounts.json`, `models.json`, журналы, `local-models\` (локальные модели и движок), `detector-history.json`. Секреты не показываются в логах и в этом чате.

## Важное о провайдерах
Genspark, Grok, Gemini Web — неофициальные веб-интерфейсы; их протокол может измениться без предупреждения. Kiro и Antigravity используют вход через OAuth IDE. «Собственный API» — любой OpenAI-совместимый сервис. «Локальные модели» работают на компьютере пользователя без интернета.
