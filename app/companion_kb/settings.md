# Настройки MemuAI Proxy (вкладка «Настройки»)

Сохраняются автоматически (справа вверху: «Сохранение…» → «Сохранено» или текст ошибки). Слева — разделы, на экране один раздел; редкие параметры каждого раздела свёрнуты под «Дополнительно». Поле «Найти настройку» (клавиша / или Ctrl+F) ищет по всем разделам на русском и английском и само раскрывает «Дополнительно». Изменённое значение отмечено точкой, кнопка ↺ возвращает значение по умолчанию.

## Общие
- Язык интерфейса; тема панели (тёмная — по умолчанию, светлая, как в системе); «Открывать панель при запуске»; кнопка «Закрыть» — сворачивает в трей или выключает Proxy.

## Маршрутизация
- **Как выбирать аккаунт**: по очереди (round-robin), строго по порядку, сначала проверенные (аккаунты со статусом «работает» первыми), давно не использованный. Порядок = порядок карточек на вкладке «Аккаунты»; аккаунты «в резерве» — после остальных.
- **Провайдер по умолчанию** — куда отправлять модель без префикса, если совпадение неоднозначно.
- **Проверять аккаунты** (мин) — фоновая проверка; 0 выключает.
- Дополнительно: **префикс провайдера в ID моделей** (genspark-claude-opus-5 вместо claude-opus-5), **строгий каталог** (404 на неизвестные модели).

## Каталог моделей
Отдельная страница в панели слева (раньше была в настройках). Поиск, провайдер, состояние, «⟳ Обновить с серверов» — подтянуть живые списки моделей; значки возможностей и фильтры по ним; карточка модели (ⓘ). Под «Дополнительно»: ручное добавление (prefix + model), «Выключить по словам» (preview, audio…) и «Сохранить правило», группировка по провайдеру, экспорт/импорт каталога, для Genspark — «models_config» и «bundle scan».
- **Выбор моделей после добавления аккаунта** — если аккаунт принёс 30 и больше моделей, открывается окно: все отмечены, «Выключить все» + поиск оставляют только нужные. Выключенные не удаляются.
- **Выделение в каталоге моделей** — щелчок выделяет строку, повторный снимает; Ctrl и Shift — как в проводнике; рамка мышью прокручивает список и не теряет выделенное.

## Провайдеры
У каждого провайдера свои параметры (веб-поиск auto/always/off и специфичные). Провайдеры без аккаунтов — под «Дополнительно».

## Веб-поиск
Proxy сам ищет и добавляет найденное для провайдеров без встроенного поиска. Источники: бесплатные без ключа — «Авто» (Kiro, иначе Bing и DuckDuckGo; по умолчанию), Kiro, Bing, DuckDuckGo, Yahoo, Википедия; свой сервер SearXNG; с ключом — Tavily, Brave Search API, Exa, Serper и SerpApi (Google), Google Programmable Search (ключ и cx), Jina, Perplexity, Linkup, Firecrawl, Kagi. Ключ и адрес хранятся для каждого источника отдельно; кнопка «Проверить» делает пробный запрос. Под «Дополнительно» — сколько результатов добавлять. Если DuckDuckGo отвечает «просит подтвердить, что запрос от человека» — это временное ограничение за частые запросы: выбрать «Авто» или Yahoo.

## Доступ и безопасность
- **API-ключи клиентов** — создать/удалить ключи доступа к /v1. Без ключей API открыт всем, кто до него достучится.
- **Пароль панели** — нужен при доступе по сети (кнопка «Сменить…»).
- Ссылка на вкладку «Публичный доступ».
- Дополнительно: **запросы из браузера (CORS)** для /v1.

## Сеть
- **Кто может подключаться**: «Этот компьютер» (127.0.0.1), «Локальная сеть» (0.0.0.0, спрашивает подтверждение), «Другой» (свой адрес). **Порт** (8317). Оба применяются после перезапуска приложения.
- Дополнительно: **общий прокси** (`http://…` или `socks5://…`, для аккаунтов без своего прокси), **проверять сертификаты SSL**.

## Интеграции
Claude Code и Codex CLI: установка моделей Proxy в сторонние CLI.

## Надёжность
- **Ждать начала ответа** (быстрый переход на другой аккаунт), **повторных проходов**.
- Дополнительно: предел на весь запрос, тишина в потоке, пауза между попытками, поддерживать соединение (SSE keep-alive) и интервал сигналов.

## Логи и статистика
- **Журнал запросов**, **статистика**; дополнительно — хранить журнал между запусками, сохранять содержимое стадий (payload).

## Система
Перезапустить службы, версия; опасная зона: сбросить статистику, очистить журнал запросов, выключить Proxy.
