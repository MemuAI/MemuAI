# Провайдер Grok (префикс `grok-`)

grok.com через кука `sso`; чат идёт через WebSocket-шлюз. Модели: grok-fast, grok-auto, grok-expert, grok-heavy (доступность зависит от подписки).

## Подключение
1. Открыть grok.com и войти.
2. F12 → Network → обновить страницу → первый запрос к grok.com → Headers → Request Headers → строка `cookie:`.
3. Скопировать кусок от `sso=` до первой `;` (или всю строку — лишнее отфильтруется).
Поле «Режим по умолчанию» — режим для моделей без явного режима.

## Типичные ошибки
- 401/403 — кука `sso` истекла или Cloudflare требует проверку: открыть grok.com в браузере, пройти проверку, обновить куку.
- grok-heavy/expert недоступны — нужна подписка SuperGrok.
- Обрыв WebSocket — сеть/VPN; повтор.
- Веб-поиск выполняет сам Proxy.
