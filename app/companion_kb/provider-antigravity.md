# Провайдер Antigravity (префикс `antigravity-`)

Google Antigravity: модели Gemini, Claude и GPT-OSS. Доступность зависит от тарифа, аккаунта и клиента. Вход через Google-аккаунт.

## Актуальный каталог
Список приходит из `fetchAvailableModels.agentModelSorts[].groups[].modelIds` — того же серверного селектора, который использует Antigravity. Внутренний реестр `models` сам по себе не является списком доступных моделей: он может содержать старые и служебные записи. Начиная с Round 45, MemuAI не добавляет исторические модели из встроенной таблицы.

Синхронизация работает при запуске Proxy, после добавления аккаунта / OAuth-входа и не реже раза в 15 минут при включённом периодическом обновлении. Общий интервал `0` отключает периодическую проверку. «Каталог моделей → Обновить» запускает её сразу. Ошибка сети или пустой ответ сохраняют последний корректный каталог. Модели, исчезнувшие из селектора, удаляются только после успешной проверки всех рабочих аккаунтов провайдера; добавленные вручную остаются.

Модель с серверным `disabled=true` видна в каталоге Proxy с причиной недоступности, но не предлагается клиентам для запросов. Выключение пользователем сохраняется отдельно. При нескольких аккаунтах достаточно доступа у одного: запрос направляется только подходящим аккаунтам. Новые модели с неизвестными MemuAI именами появляются из ответа сервера с точным upstream ID.

Официальная таблица: https://www.antigravity.google/docs/models/. Например, на 23.10.2026 Gemini 4 Argon объявлена для App, CLI и IDE extensions, но не для отдельной Antigravity IDE. Gemini 3.7 Flash, 3.6 Flash и 3.1 Pro остаются у Enterprise. Поэтому нельзя глобально удалять модель только по её имени или объявлять её доступной всем. Если текущий серверный селектор не объявил модель, MemuAI не придумывает доступ или ID.

## Подключение
«Войти через браузер» → Google-аккаунт. Колбэк входа использует порт `51121`. Можно вставить access/refresh token вручную. Project ID определяется автоматически при первом запросе.

## Имена моделей и уровни размышлений
Google зашифровал уровень размышлений в id модели непоследовательно, поэтому в каталоге единые имена:
- `gemini-3.6-flash-high` / `-medium` / `-low` — Gemini 3.6 Flash, три уровня;
- `gemini-3.1-pro-high` / `-low` — Gemini 3.1 Pro, два уровня (у Google `gemini-pro-agent` — это «High»);
- `gemini-3.7-flash-high` / `-medium` / `-low` и `gemini-3.8-flash-high` / `-medium` / `-low` — новейшие Flash с выбранным уровнем. У Google на все уровни один id (`*-tiered`), уровень уходит в запросе полем `thinkingLevel`;
- `gemini-3.7-flash`, `gemini-3.8-flash` — те же модели без уровня в имени: глубину выбирает Google, а если клиент задал `/effort` — он (minimal/low → Low, medium → Medium, high/max → High);
- `claude-opus-4-6-thinking`, `claude-sonnet-4-6-thinking` — оба Claude «Thinking» названы одинаково (id Google у Sonnet без суффикса);
- `gpt-oss-120b-medium`.
Перечисленные имена — совместимость с ранее сохранёнными чатами, а не обещание текущей доступности. Старый ID переводится в новый, когда модель присутствует в серверном селекторе. Выключенные пользователем модели остаются выключенными. Если Google отвечает «is no longer available», Proxy возвращает ошибку `404 model_unavailable`.

Gemini 3.8 Flash также учитывается, когда её реальный `gemini-3.8-flash-tiered` уже есть в реестре моделей аккаунта, но ещё отсутствует в отстающем селекторе IDE. Удалённые или объявленные устаревшими ID не возвращаются; недоступная модель остаётся отмеченной недоступной. [Официальная таблица Antigravity](https://www.antigravity.google/docs/models/) указывает 3.8 Flash для всех тарифов.

## Размышления
- Claude думает только по бюджету токенов: настройка «Бюджет размышлений Claude» (по умолчанию 8192, 0 — выключить) и `/effort` клиента (low 2048, medium 8192, high 16384, max 32000). Мысли приходят как `reasoning_content`.
- Gemini: уровень — в имени модели (у 3.7/3.8 Flash без уровня в имени — `/effort` или выбор Google); краткое изложение мыслей включается настройкой «Показывать размышления Gemini».

## Лимиты
Лимиты идут по семействам (Gemini отдельно, Claude+GPT отдельно) и видны в карточке аккаунта вместе со временем сброса и тарифом. Google отдаёт одно окно на семейство — скользящие ~5 часов; недельного счётчика для Pro-аккаунтов в API нет, поэтому строка «за 7 дней (оценка)» — это сумма израсходованных 5-часовых окон по замерам, а не процент. Длинное окно, если Google его отдаёт (бесплатные аккаунты), показывается как «неделя» с датой сброса. Если Google ответил «квота исчерпана», хотя 5-часовой счётчик почти полон, появляется пометка: вероятно, недельный лимит тарифа. Если Google просит «Verify your account», в окне лимитов есть предупреждение со ссылкой; вход при этом рабочий.

## Нестабильность сервиса
Antigravity сам нестабилен: 429 «Resource has been exhausted», 503, отказ по региону («User location is not supported»). Proxy пробует оба адреса Google (первым — тот, что отвечал последним), ждёт подсказанную Google паузу (до 8 с), один раз обновляет токен при 401, при 400 про размышления или фильтры безопасности повторяет запрос без них и переходит к следующему аккаунту. Настоящий текст ошибки Google виден в «Логи → Запросы». Аккаунт при этом на «паузу» не уходит.

## Настройки провайдера
- **Максимум токенов ответа** (по умолчанию 64000).
- **Бюджет размышлений Claude** (8192; 0 — выключить).
- **Показывать размышления Gemini**: on/off.
- **Версия клиента Antigravity**: пусто — Proxy берёт актуальную с адреса автообновления Antigravity; введённое вручную (например, 2.0.6) отключает сверку.
- **Фильтры безопасности**: off (как в IDE) или default (настройки Google).
- **Эндпоинт**: auto (оба адреса, первым — последний удачный), prod, daily.
- Веб-поиск встроенный.

## Типичные ошибки
- 401 — refresh token отозван (сменили пароль Google, вышли из сеансов): войти заново.
- 429 / RESOURCE_EXHAUSTED — лимит семейства или нехватка мощности Google: подождать или второй аккаунт; endpoint auto сам пробует второй адрес.
- 403 «Verify your account» — Google просит подтвердить аккаунт: пройти проверку в браузере, затем «Проверить».
- «User location is not supported for the API use» — Google отказывает по региону: повторить позже или задать аккаунту прокси в нужной стране.
- «project not found / permission denied» — очистить Project ID в аккаунте, он определится заново.
- «… is no longer available. Please switch to …» — модель снята: выбрать другую из каталога.
- Пустые ответы Claude через Antigravity — временные сбои сервиса: повтор или другая модель.
