# Ошибки MemuAI Proxy и что с ними делать

Ошибки API приходят в формате OpenAI: `{"error": {"message", "type", "code"}}`, плюс подсказка в панели. В «Логи → Запросы» у каждой ошибки есть стадии: `request_parsed`, `routed`, `account`, `attempt`, `retry`, `finished` — по ним видно, какой аккаунт пробовался и что ответил сервис.

| type | HTTP | Что значит | Что делать |
|---|---|---|---|
| authentication_error | 401 | Кука/токен аккаунта больше не действует | Вкладка «Аккаунты» → ПКМ по аккаунту → «Изменить» → вставить свежую куку/токен (или «Войти через браузер» для Kiro/Antigravity), затем «Проверить» |
| quota_exceeded | 402 | Исчерпан дневной/месячный лимит аккаунта | Добавить ещё аккаунт или дождаться сброса лимита |
| rate_limit_error | 429 | Сервис ограничил частоту запросов (аккаунт остаётся в очереди, Proxy пробует следующий) | Подождать, добавить второй аккаунт, увеличить «Паузу между попытками» |
| network_error | 502/504 | Сервис недоступен по сети, таймаут, обрыв SSL/прокси | Проверить интернет, VPN, «Общий прокси» и «Проверять сертификаты SSL» в Настройки → Сеть → Дополнительно; увеличить таймауты |
| content_filter | 451 | Модель отказалась по фильтрам безопасности | Переформулировать запрос — другой аккаунт не поможет |
| model_unavailable | 404 | Ни у одного аккаунта нет доступа к модели (тариф/регион) | Выбрать другую модель или аккаунт с нужным тарифом |
| model_not_found | 404 | Модель не маршрутизируется: нет префикса или совпадение неоднозначно | Взять точный id из `GET /v1/models` или «Каталог моделей»; задать «Провайдер по умолчанию» |
| model_disabled | 404 | Модель выключена в каталоге | Включить её на странице «Каталог моделей» (панель слева) |
| service_unavailable | 503 | Нет доступных аккаунтов провайдера (все выключены или невалидны) | Добавить/включить аккаунт, обновить вход невалидного, «Проверить все» |
| upstream_error | 5xx | Сервис вернул ошибку | Смотреть стадии запроса: текст ответа сервиса там |
| proxy_disabled | 503 | Прокси выключен главным выключателем | Главная → «Запустить прокси» |
| invalid_request_error | 400 | Некорректное тело запроса клиента | Проверить JSON: нужны `model` и непустой `messages` |
| 401 от /v1 без типа | 401 | Созданы API-ключи, а клиент не передал ключ | Передать `Authorization: Bearer <ключ>` или удалить ключи в Настройки → Доступ и безопасность |

## Частые тексты
- «The upstream sent no data for over N с» — сервис молчит дольше «Таймаута тишины стрима». Увеличить таймаут или сменить модель.
- «Генерация не завершилась» / поток оборвался без `done` — сервис разорвал соединение; повторить, проверить сеть.
- «Модель '…' не маршрутизируется» — см. model_not_found.
- «HTTP 403 … captcha/anti-bot» у Genspark — сервис требует проверку браузера: обновить куку, открыв genspark.ai в браузере и пройдя проверку.
- «The model or API rejected the image» — модель не принимает изображения: выбрать vision-модель или убрать картинку.
- «llama-server завершился с кодом …» — ошибка локального движка: смотреть «Журнал» модели на вкладке «Локальные модели» (часто не хватает памяти — уменьшить контекст или слоёв на GPU, либо выбрать более лёгкую квантизацию).
- «Движок llama.cpp не установлен» — вкладка «Локальные модели» → «Установить движок».
