# Провайдер Kiro (префикс `kiro-`)

AWS Kiro IDE: модели Claude (Sonnet, Haiku, Opus) через AWS CodeWhisperer / Amazon Q. Вход — как в Kiro IDE.

## Подключение (любой способ)
1. **«Войти через браузер»** — OAuth; колбэк слушает `localhost:3128`, порт должен быть свободен (закройте Kiro IDE, если она занимает порт).
2. **Builder ID** — вход без локального порта (подтверждение кода на сайте AWS).
3. Вставить содержимое `kiro-auth-token.json` из `%USERPROFILE%\.aws\sso\cache\` (если Kiro IDE уже вошла).
Поля: регион (обычно us-east-1), свой эндпоинт — обычно не нужен, Proxy сам перебирает хосты.

## Возможности и ограничения
- Изображения передаются нативно: до 20 штук, до 3,75 МБ каждое.
- Веб-поиск выполняет сам Proxy (у Kiro своего нет).
- Модель `auto` — выбор Kiro.

## Настройки провайдера
- **Режим агента**: vibe (обычный чат) или spec (режим спецификаций).
- **Передавать историю диалога** — выключить, если Kiro падает на длинных диалогах.
- **Ограничение ответа, символов** — 0 без ограничения.

## Типичные ошибки
- 401/403 — токен истёк и не обновился: войти заново.
- «порт 3128 занят» при входе — освободить порт или использовать Builder ID.
- ThrottlingException / 429 — лимит AWS: пауза или второй аккаунт.
- Ошибки на длинных диалогах — выключить «Передавать историю диалога» или начать новый чат.
- Нет сети до AWS (корпоративная сеть, блокировки) — network_error.
