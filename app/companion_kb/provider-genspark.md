# Провайдер Genspark (префикс `genspark-`)

AI-воркспейс genspark.ai с моделями GPT, Claude, Gemini, DeepSeek, Kimi, GLM, Grok, MiniMax и др. Неофициальный веб-протокол — самый хрупкий из провайдеров.

## Подключение
Поле **Кука session_id**: открыть genspark.ai и войти → F12 → Application → Cookies → `https://www.genspark.ai` → значение `session_id`. Можно вставить только значение — Proxy сам допишет `session_id=`. Одна и та же кука дважды не добавляется.

## Возможности
- Встроенный веб-поиск (native search).
- Генерация изображений: запрос «нарисуй…» из MemuAI уходит в AI Image (`COPILOT_MOA_IMAGE`). Модель `auto` для картинок раскрывается в набор реальных моделей; `gpt-image-2` — image-модель.
- «Каталог моделей → models_config / bundle scan» ищут новые модели в интерфейсе Genspark.

## Настройки провайдера
- **Бэкенд чата**: agent (по умолчанию), copilot, auto.
- **Режим контекста**: auto, server (история на стороне Genspark), stateless (история транскриптом).
- **Вывод «мышления»**: reasoning_content, think_tags (`<think>` в тексте), hidden.
- **Удалять временные чаты** — чистить созданные Proxy чаты в истории Genspark.
- **Таймаут тишины** — секунд без данных до обрыва.

## Типичные ошибки
- 401 / authentication_error — кука истекла или разлогинились в браузере: получить новую `session_id`.
- 403 с captcha / anti-bot / reCAPTCHA — Genspark требует проверку браузера (чаще для картинок): открыть genspark.ai в браузере, пройти проверку, обновить куку. Гарантировать работу одной кукой нельзя.
- Пустой ответ или «задача не создана» при генерации изображений — сервис изменил протокол; нужна правка адаптера (`providers/genspark.py`, `providers/gs/*`).
- quota / лимит кредитов — у бесплатного плана жёсткие лимиты: добавить ещё аккаунт.
