# Провайдер OpenCode (`opencode-`)

Free использует отдельный opencode2api jasonxu114514, устанавливаемый кнопкой в форме аккаунта. Zen/Go подключаются напрямую по своему ключу. Режим gateway подключает уже запущенный внешний сервер. Никогда не отправляй пользователя искать пункт Console на главной странице opencode.ai.

## Подключение

Proxy → Аккаунты → Добавить аккаунт → OpenCode. Free: Установить шлюз → дождаться Готово → Добавить аккаунт → Проверить. Без регистрации, API-ключа, Node.js и Docker. Windows x64/ARM64; pinned v1.4.3, проверка SHA-256, лицензия GPL-3.0 сохранена рядом. Proxy владеет дочерним процессом на случайном loopback-порту и закрывает его при выходе/удалении аккаунта. Скачивание можно отменить; простое открытие формы ничего не устанавливает.

Zen/Go: ссылка https://opencode.ai/auth ведёт в реальный вход (сейчас /console/login); выбрать workspace, создать API-ключ. Zen требует баланса, Go — активной подписки https://opencode.ai/go. Это не локальный ключ внешнего шлюза.

Gateway: jason обычно http://127.0.0.1:8080/v1 и server_keys из config.json; порт 8081 — WebUI. Tiara обычно http://127.0.0.1:10000/v1 и API_KEY, требует свой OpenCode runtime и Node.js/Docker. Сервер запускается пользователем отдельно. HTTP только на loopback; удалённый API — HTTPS. Вставленный /chat/completions, /responses или /models удаляется из Base URL; пустой путь дополняется /v1.

## Каталог

Источники: `models.opencode.ai/api.json`, нативные каталоги Zen/Go; Free пересекает публичный каталог OpenCode с официальными нулевыми ценами, не запуская шлюз. Имя free не является доказательством бесплатности. Go подтверждает подписку через `/inference/go/v1/usage`. Gateway использует каталог самого шлюза. Старые снимки Free инвалидируются новой версией транспорта.

Статических стартовых моделей нет. При запуске Proxy, добавлении/редактировании аккаунта, ручном обновлении и включённом периодическом обновлении (не реже 15 минут) берётся актуальный список. Сеть/429 сохраняет последнюю хорошую версию; 401/403 убирает доступ этого ключа. Несколько аккаунтов дают объединённый каталог, но запрос направляется только подходящему аккаунту. Смена ключа/тарифа инвалидирует прежний снимок.

## API и инструменты

У прямых Zen/Go метаданные выбирают Chat, Responses, Messages либо Gemini. Free всегда проходит через локальный шлюз, а не напрямую на официальный endpoint. Поддерживаются возможности модели, потоки, инструменты, отмена и usage. Служебный ключ локального шлюза не сохраняется в публичных метаданных аккаунта/моделей и не отправляется наружу.

## Лимиты

Go API возвращает общие окна `rolling`, `weekly`, `monthly`: использованные/оставшиеся проценты и время сброса. Ответ кэшируется на 60 секунд. Это окна одной подписки, а не три баланса или независимые лимиты каждой модели. Ключи одной подписки нельзя складывать. Free, Console/Zen и сторонние шлюзы не объявляются безлимитными: если API не публикует остаток, показывается понятное объяснение. Справочные API-цены не равны списанию включённого Go-пакета.

401 — ключ неверен/отозван; 403 у квот Go — подписка не подтверждена; 429 — временный лимит с паузой из Retry-After. Проверка использует только чтение каталогов/квот, не выполняет платный пробный запрос. Ссылки: https://opencode.ai/v2/docs/console/api/inference/ и https://opencode.ai/v2/docs/console/go/.

429 Free usage limit reached означает отказ публичного Free, но не доказывает расход личной квоты: возможны ограничения клиента/сети. Вторая запись Free, переустановка и перезапуск не создают новую квоту. Не обещать безлимит и не путать удачное чтение каталога с доступностью генерации. Каталог читается без запуска шлюза; при запуске для генерации шлюз ждёт непустой каталог.


Round 48: Free — анонимный public, не аккаунт сайта. 429 не доказывает личный расход квоты: прямой запрос также может получать 403 «free tier can only be used from within OpenCode», а шлюз возвращает последний отказ своего fallback-маршрута. Не обещай сброс лимита, не советуй создавать дубли Free. Каталог читается напрямую без запуска процесса/генерации. Известные модели шлюза переводятся в manual availability до запуска, чтобы исключить его автоматические пробы. Отказ 429/авторизации публичного доступа останавливает собственный процесс; без Retry-After используется локальная пауза 60 с. В настройках сохранённого Free есть явный тест генерации на модели с нулевыми ценами; повтор в течение минуты возвращает результат из памяти. Zen/Go не используются скрытым fallback. Для второго настоящего аккаунта: добавить OpenCode → Zen/Go → ключ нужного рабочего пространства на opencode.ai/auth; ключи одного пространства могут иметь общие лимиты.
