# MemuAI для Chrome

1. Откройте MemuAI → Настройки → Интеграции → Chrome. Скачайте ZIP и распакуйте в постоянную папку.
2. Откройте `chrome://extensions`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите эту папку.
3. В параметрах расширения нажмите **Подключить через MemuAI**. Подтвердите запрос в открывшемся приложении — адрес и код передадутся автоматически. Если `memuai://` не зарегистрирован, раскройте **Подключить по коду или изменить адрес**, укажите адрес из MemuAI и одноразовый код. Для чтения сайтов есть отдельное разрешение.
4. Закрепите значок MemuAI в панели браузера и нажмите его. Если боковая панель слева, в параметрах расширения нажмите **Открыть настройки внешнего вида** и выберите **Боковая панель → Справа**. Chrome не предоставляет расширениям команды изменения этой общей настройки.
5. Нажмите название модели: доступны поиск по имени/провайдеру/ID, сведения о поддержке изображений и закреплённые модели. **Основная модель и закрепления общие с активным профилем MemuAI**: изменения в панели и в приложении синхронизируются в обе стороны. Каталожная модель, недоступная вашему аккаунту, остаётся видна с причиной, но её нельзя выбрать для запроса.
6. Откройте историю кнопкой слева вверху. По умолчанию показаны разговоры **В браузере**; новые чаты хранятся отдельно от главного списка MemuAI. Вкладки **MemuAI** и **Все** открывают остальные чаты активного профиля. В параметрах можно включить **Показывать новые чаты в MemuAI**: следующие разговоры появятся и в приложении, и в браузерной истории. Уже созданные разговоры не переносятся. Чаты проектов доступны для чтения с переходом в приложение для продолжения. Новый чат создаётся кнопкой **+**. История автоматически обновляется при возвращении в панель и каждые 30 секунд.

## Сообщения и вложения

- **Скрепка**, перетаскивание или вставка изображения добавляют файл. Поддерживаются PNG/JPEG/WebP/GIF, PDF, DOCX, текст и исходный код. До 5 МБ на файл, 8 файлов и 4 изображения на сообщение; общий объём ограничен. Вложения сначала читаются локальным MemuAI. Неподдерживаемый формат и ошибку чтения видно до отправки.
- Крупные изображения уменьшаются до 2048 пикселей по длинной стороне; для GIF используется первый кадр. PDF без текстового слоя требует предварительного распознавания. Длинный документ передаётся как ограниченный текстовый фрагмент с явной отметкой.
- Кнопка страницы включает контекст текущей вкладки; он виден над полем ввода и убирается крестиком. Без него можно просто разговаривать с моделью. Явные запросы к страницам выполняются инструментами с разрешениями MemuAI.
- Кнопка со звездой у поля ввода открывает **Инструменты страницы**: краткий пересказ, объяснение простым языком, перевод на русский, факты и действия. Одно нажатие читает текущую страницу и запускает выбранную задачу. Перед отправкой проверьте выбранную модель: запрос использует её обычные лимиты и стоимость.
- Во время работы виден раскрываемый журнал инструментов: что выполняется, завершилось или вернуло ошибку. Он сохраняется в истории ответа. Закрытие нескольких вкладок подтверждается одним списком с заголовками и адресами; перед фактическим закрытием проверяется, что страницы не изменились.
- Enter отправляет сообщение, Shift+Enter добавляет строку. Во время ответа стрелка заменяется кнопкой остановки. Ответ поддерживает Markdown, списки, таблицы и блоки кода; текст ответа и код можно скопировать. При ошибке запрос можно вернуть в поле ввода вместе с вложениями.
- Изображения и документы сохраняются в выбранной истории в формате MemuAI. Подготовленные, но ещё не отправленные файлы доступны 30 минут; после перезапуска приложения их нужно прикрепить снова.
- Панель поддерживает светлую/тёмную тему системы и узкие окна. Видимые полосы прокрутки скрыты; прокрутка колёсиком, касаниями и клавиатурой сохраняется.

MemuAI и Proxy должны быть запущены. Адрес по умолчанию — `http://127.0.0.1:8600`; при занятом порте используйте адрес, показанный в настройках. Ключи провайдеров остаются в Proxy. Расширение не передаёт содержимое страниц внешнему серверу самостоятельно: оно приходит в локальный MemuAI и отправляется выбранной модели только как контекст соответствующего запроса.

## Разрешения

- **Читать страницы**: общий переключатель в MemuAI и в настройках самого расширения. Все разрешения, история, основная модель и закрепления доступны в расширении и сохраняются автоматически. Быстрый доступ предпочитает расширение для Chrome, сохраняя прежний способ для других браузеров и при отсутствии соединения.
- **Управление вкладками и страницами**: спрашивать, разрешить или запретить. В режиме «Спрашивать» каждое действие показывает понятное описание; для группы вкладок — их заголовки и адреса.
- **DFY в моём Chrome**: отдельное добровольное разрешение. DFY создаёт фоновые вкладки с вашими сессиями, использует существующий движок MemuAI и закрывает только собственные вкладки. Chrome показывает стандартное уведомление отладки. Сетевые настройки используются из Chrome, а не из изолированного профиля DFY.
- **Действия по расписанию без запросов**: заранее разрешает сохранённым заданиям изменять страницы и вкладки. Чтение по сохранённому заданию подчиняется разрешению на чтение. Для DFY в Chrome без участия пользователя нужны оба переключателя; если задача требует код входа или иной ручной ответ, она завершается понятной ошибкой и не зависает в ожидании.

В расширении нет content script, принимающего команды от сайтов, и нет доступа сайта к локальному API MemuAI. Подключение привязано к ID расширения, код действует пять минут и используется один раз. Ссылка `memuai://` передаёт только случайный одноразовый идентификатор запроса: код и ключ доступа в ней отсутствуют. Подтверждённый код забирается через loopback API. Отключение в MemuAI или в доступном подключённом расширении отзывает токен. Если приложение недоступно, расширение явно сообщает, что ключ нужно позже отозвать в MemuAI. Поддерживается один подключённый профиль Chrome одновременно. При смене профиля MemuAI история перечитывается; устаревшие запросы и вложения другого профиля отклоняются.

## Ограничения браузера

Требуется Chrome 120+. Служебные страницы Chrome, магазин расширений и некоторые защищённые страницы не позволяют внедрять скрипты. Локальные служебные IP/localhost агенту недоступны. Скриншот обычной вкладки доступен, когда она активна; DFY снимает собственную фоновую вкладку без переключения активной. Чтение iframe зависит от разрешений сайтов, закрытые shadow roots недоступны. Некоторые элементы требуют trusted input: для них используйте DFY. Отключение расширения останавливает текущую задачу, а не переносит её в браузер без ваших входов.

После обновления файлов расширения нажмите **Обновить** на его карточке в `chrome://extensions`.

Если расширение уже установлено, распакуйте новый ZIP в **ту же постоянную папку** и обновите карточку. Это сохраняет ID расширения и подключение. При загрузке из другой папки Chrome может выдать другой ID — тогда получите новый код в MemuAI.

Версия расширения: **3.8.46**. Для синхронизации настроек, отдельной истории и подключения по ссылке требуется MemuAI **3.8 или новее**.
