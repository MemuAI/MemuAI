# Приватные OAuth-настройки MemuAI

OAuth-реквизиты не хранятся в публичном исходном коде. Для Google-интеграций,
Notion и Antigravity используются независимые пары Client ID / Client Secret.

## Запуск из исходников

Перед запуском процесса задайте нужные переменные окружения:

- `MEMUAI_GOOGLE_CLIENT_ID`, `MEMUAI_GOOGLE_CLIENT_SECRET` — Google Drive и другие Google-интеграции.
- `MEMUAI_NOTION_CLIENT_ID`, `MEMUAI_NOTION_CLIENT_SECRET` — Notion.
- `MEMUAI_ANTIGRAVITY_CLIENT_ID`, `MEMUAI_ANTIGRAVITY_CLIENT_SECRET` — Antigravity.

Antigravity требует OAuth-клиент, которому разрешён доступ к соответствующему
сервису Google. Произвольный клиент Google Drive не даёт такого доступа.
Ранее выданные refresh-токены должны обновляться тем же OAuth-клиентом,
который выдал их. Для смены клиента потребуется заново войти в аккаунт.

## Сборка приложения

Скопируйте `oauth_clients.example.json` в `oauth_clients.local.json` в корне
проекта и заполните нужные пары. Этот локальный файл исключён из Git.
Также можно передать те же переменные окружения: при сборке они имеют приоритет.

`build.py` переносит значения в `app/oauth_build.py` перед сборкой EXE.
Этот файл также исключён из Git. Собранное приложение использует встроенные
значения, а переменные окружения при запуске могут переопределить их.
Сам JSON не читается при обычном запуске из исходников: используйте переменные
окружения или заранее созданный сборщиком `app/oauth_build.py`.

Если Antigravity не настроен, вход показывает сообщение до открытия браузера.
Google Drive и Notion продолжают использовать собственные настройки.

## Перед публикацией

Публикуйте исходники и пустой файл-пример. Не добавляйте в Git
`oauth_clients.local.json`, `app/oauth_build.py`, файлы аккаунтов или токены.
Удаление реквизитов только из последнего состояния файлов недостаточно,
если они остаются в предыдущих коммитах отправляемой ветки: такие коммиты нужно
исправить перед повторным push.
