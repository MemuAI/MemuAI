# OpenCode / opencode2api в MemuAI 3.8 — понятное подключение

## Просто попробовать бесплатные модели

1. Откройте **MemuAI Proxy → Аккаунты → Добавить аккаунт → OpenCode**.
2. Оставьте **Бесплатные модели · установить шлюз**.
3. Нажмите **Установить шлюз**. Скачается отдельный opencode2api около 4 МБ; видны прогресс и отмена. Дождитесь **Готово**.
4. Нажмите **Добавить аккаунт**, затем **Проверить** на карточке.
5. Откройте настройки добавленного подключения и нажмите **Проверить генерацию Free**. Это отдельная явная проверка; обычная кнопка «Проверить» читает только каталог.
6. Если тест прошёл, выберите модель в MemuAI.

**Это анонимный публичный доступ, а не вход в ваш аккаунт OpenCode. Регистрация, сайт OpenCode и API-ключ для этого варианта не нужны.** Не требуется устанавливать Node.js, Docker или OpenCode CLI. Proxy запускает скачанный шлюз только для генерации (чтение каталога его не запускает) и закрывает свой процесс при выходе/удалении аккаунта. Чужие серверы он не останавливает. Автоустановка доступна на Windows x64/ARM64.

Используется отдельный [jasonxu114514/opencode2api v1.4.3](https://github.com/jasonxu114514/opencode2api/releases/tag/v1.4.3), проверяемый по SHA-256. Исходники [этого выпуска](https://github.com/jasonxu114514/opencode2api/tree/v1.4.3) и GPL-3.0 доступны по ссылке в форме; LICENSE и README сохраняются рядом с программой в папке данных `opencode2api/`.

## Если у вас есть Zen или Go

Это отдельный способ с собственным аккаунтом:

1. Выберите **Zen · свой API-ключ** либо **Go · подписка**.
2. Нажмите **Войти в OpenCode**: [opencode.ai/auth](https://opencode.ai/auth). Сейчас ссылка ведёт на страницу входа `/console/login`. На главной странице искать пункт Console не нужно.
3. Войдите, выберите рабочее пространство, создайте/скопируйте его API-ключ.
4. Для платных моделей Zen пополните баланс; для [Go](https://opencode.ai/go) нужна активная подписка в этом пространстве.
5. Вставьте ключ в MemuAI Proxy, добавьте аккаунт и нажмите **Проверить**.

Это API-ключ OpenCode, не пароль аккаунта и не локальный ключ стороннего шлюза. Установка бесплатного шлюза для прямых Zen/Go не нужна.

## Если opencode2api уже запущен отдельно

Выберите **Мой шлюз opencode2api**. MemuAI подключится к нему, но не будет запускать и останавливать внешний сервер.

| Проект | Обычный Base URL | Какой ключ вставлять |
| --- | --- | --- |
| [jasonxu114514](https://github.com/jasonxu114514/opencode2api) | `http://127.0.0.1:8080/v1` | локальный ключ из `server_keys` в `config.json` |
| [TiaraBasori](https://github.com/TiaraBasori/OpenCode2API/blob/main/README.en.md) | `http://127.0.0.1:10000/v1` | `API_KEY` из `.env` / конфигурации этого сервера |

У jason порт **8081 — панель управления**, не API. У Tiara порт **10001 — внутренний OpenCode**, а не внешний OpenAI-совместимый API. Ключ OpenCode Zen/Go не заменяет локальный ключ шлюза. В MemuAI выбирается Chat Completions либо Responses согласно настройкам вашего сервера.

Для jason на Windows можно скачать и распаковать готовый exe из Releases. Пример минимального `config.json` для бесплатного доступа:

```json
{
  "listen": "127.0.0.1:8080",
  "server_keys": ["REPLACE_WITH_YOUR_LOCAL_SECRET"],
  "anonymous": true,
  "zen_keys": [],
  "go_keys": [],
  "models": {"free_only": true},
  "webui": {"enabled": false},
  "proxies": ["direct"]
}
```

Откройте PowerShell в распакованной папке и запустите:

```powershell
.\opencode2api.exe -config .\config.json
```

Оставьте этот сервер работающим. В MemuAI укажите `http://127.0.0.1:8080/v1` и тот же секрет из `server_keys`.

У Tiara другой принцип: запускается отдельный OpenCode runtime с Node.js либо Docker. Следуйте именно [инструкции Tiara](https://github.com/TiaraBasori/OpenCode2API/blob/main/README.en.md); затем используйте порт 10000 и `API_KEY`. Если не нужен отдельный сервер, проще выбрать встроенную кнопку установки бесплатного шлюза.

## Как понимать ошибки

- **«Сначала установите opencode2api»** — вернитесь к форме бесплатного аккаунта и нажмите **Установить шлюз**. Создавать API-ключ на сайте не нужно.
- **404 `/models` / HTML вместо JSON** — вероятно, указан адрес панели вместо API. Проверьте порты в таблице. Обычный URL без `/v1` дополняется автоматически; вставленный `/chat/completions`, `/responses` или `/models` убирается.
- **401** у внешнего шлюза — проверьте его локальный ключ. У Zen/Go проверьте API-ключ рабочего пространства.
- **403 у Go** — API не подтвердил подписку для этого ключа.
- **429 / Free usage limit reached** — шлюз получил отказ публичного Free. Это **не доказательство, что вы использовали личную квоту**. Возможны ограничения сервиса, сети или стороннего клиента; точная причина и срок восстановления из этого ответа неизвестны. Вторая запись Free и переустановка не создают отдельную квоту.
- **403 / Free tier can only be used from within OpenCode** — сервис требует официальный клиент OpenCode. Это ограничение доступа, а не ошибка вашего ключа. У шлюза итоговый 429 может скрывать более ранний отказ другой ветки маршрута. MemuAI не может гарантировать стороннему шлюзу доступ к бесплатному тарифу.
- **Не удалось скачать** — проверьте доступ к GitHub и сетевые настройки. После исправления подключения установку можно повторить; неполная загрузка не считается установленной программой.

Каталог обновляется автоматически, но **успешная проверка списка моделей не гарантирует остаток генераций**. Названия и доступность бесплатных моделей меняются; обещания безлимитного доступа нет.


## Почему 429 возможен, даже если вы никогда не использовали Free

Анонимный режим отправляет публичный credential `public`; ваш вход на сайте в нём не участвует. Поэтому ваша личная история использования и эта ошибка — разные вещи. За общим сетевым адресом также могут находиться другие люди; конкретно ваш ответ 429 не позволяет установить причину.

В Round 48 исправлена и собственная проблема MemuAI: раньше фоновое чтение каталога запускало opencode2api, который сам умеет отправлять тестовые генерации. Теперь каталог читается без запуска шлюза; для известных моделей перед его запуском записывается поддерживаемый шлюзом режим ручной проверки. После 429/отказа публичного доступа свой процесс закрывается. Быстрый повтор одного запроса после 429 без Retry-After заменён локальной паузой; это не обещанный сервисом срок восстановления.

**Проверить генерацию Free** отправляет один короткий запрос MemuAI только к модели с подтверждёнными нулевыми ценами. Результат повторного нажатия в течение минуты берётся из памяти, без нового запроса. Платные аккаунты не используются как запасной вариант. Сторонний шлюз может иметь собственные маршруты/внутренние проверки; режим не обещает один HTTP-запрос непосредственно к OpenCode.

## Как подключить второй настоящий аккаунт

Нажмите **Аккаунты → Добавить аккаунт → OpenCode → Zen или Go**. На [странице входа](https://opencode.ai/auth) выберите нужного пользователя и рабочее пространство; вставьте API-ключ этого пространства в новую запись Proxy. Zen использует оплачиваемые модели/баланс, Go — вашу действующую подписку. Новые ключи одного рабочего пространства могут разделять лимиты. Это подключение существующего доступа, а не способ сбросить бесплатные ограничения.

Если нужен именно бесплатный тариф, сначала проверьте его в официальном клиенте OpenCode. Если он работает там, но не в стороннем шлюзе, это указывает на несовместимость/ограничение стороннего доступа; покупать подписку только ради диагностики не требуется.
