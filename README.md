# MemuAI - единое приложение для общения с ИИ, вместе с целой экосистемой (MemuAI Proxy, MemuCode, MemuCode CLI, MemuWork, MemuNote, MemuFiles, MemuMusic и другие модули)
**Русский** · [English](README.en.md)

[Скачать сборку](https://github.com/MemuAI/MemuAI/releases) · [Сообщить об ошибке](https://github.com/MemuAI/MemuAI/issues) · [Исходный код](https://github.com/MemuAI/MemuAI)

  - 🚨 Дисклеймер: использование аккаунтов Genspark, Kiro, Antigravity, Gemini Web и Grok - только на **ВАШ СТРАХ И РИСК**. Использование этих аккаунтов может нарушать политику конфиденциальности компаний. Сам проект приведён исключительно как образовательный продукт. Авторы проекта никак не ручаются за блокировки аккаунтов и прочих ограничений со стороны третьих компаний.

# Что это вообще такое

Главная суть MemuAI - объединить все сервисы для работы с ИИ в один. В одном приложении можно общаться с ИИ, добавлять собственные аккаунты sub2api и удобно управлять API-ключами, создавать собственные приложения, работать с файлами и документами, и многое остальное.

**Проект сделан ИИ** - в частности, при помощи множества ИИ.

## Что входит в MemuAI

| Приложение | Для чего оно нужно |
| --- | --- |
| **MemuAI** | Основной чат: модели, файлы, память, поиск, голосовое общение и работа с проектами. |
| **MemuAI Proxy** | Подключает аккаунты и модели, предоставляет общий API для MemuAI и других программ, показывает расходы и лимиты. |
| **MemuCode CLI** | ИИ-агент в терминале: изучает проект, меняет файлы и запускает команды с выбранными вами разрешениями. |
| **MemuFiles** | Файловый менеджер с вкладками, предпросмотром, архивами и ИИ-помощником. |
| **MemuNote** | Редактор для текста, кода и документов с ИИ-помощником, таблицами, презентациями и инструментами для изображений. |
| **MemuMusic** | Музыкальная библиотека и плеер: плейлисты, обложки, тексты песен, эквалайзер и полноэкранный режим. |
| **Модули** | Сразу же множество приложений внутри MemuAI, от переводчика до персонажей: можно создавать собственные и как угодно работать с имеющимися. |

Proxy обычно достаточно настроить один раз. После этого модели становятся доступны в приложениях комплекта. Если нужен только API для своих программ, Proxy можно установить отдельно, как и MemuCode CLI, MemuFiles и MemuNote. MemuMusic - модуль, его можно удалить как и остальные модули.

## MemuAI Proxy: единое приложение для ИИ

### Удобная работа с API
  - Можно добавлять абсолютно любых провайдеров с API-ключами, а также есть поддержка некоторых sub2api, а именно: Genspark, Kiro, Antigravity, Gemini Web и Grok
  - Пул API-ключей: к каждому аккаунту можно добавить несколько API ключей, при ошибке - они будут автоматически заменяться
  - Планировщик квот: автоматический анализ трат лимитов аккаунта, с прогнозом когда при подобном темпе лимиты закончатся. Можно добавлять как и аккаунты, так и API-ключи, указав стоимость и тарификацию
  - Составные модели: можно создавать кастомные модели, и в этих моделях добавлять другие модели для того, чтобы они автозаменялись при определённых условиях (например в зависимости от кол-ва токенов)
  - Локальные модели: можно удобно устанавливать любые локальные модели, прямо через интерфейс, а также можно удобно подбирать любые локальные модели благодаря мастеру локальных моделей, который подберёт нужную модель в зависимости от характеристик компьютера
  - Публичный доступ: возможность подключить MemuAI Proxy к адресу для того, чтобы доступ был абсолютно всегда и для всех людей
  - Детектор моделей: продвинутая проверка на то, является ли модель в API, заявленная провайдером, настоящей.

## MemuAI: общение с ИИ

### Встроенные инструменты
  - Поддержка веб-поиска через Kiro, Bing, DuckDuckGO и прочие сервисы + режим глубокого исследования
  - Возможность создания видео, изображений, таблиц, визуализаций (как в ChatGPT), карточек товаров и так далее
  - Интеграция с Google, Notion, Github, Telegram (аккаунт)
  - Собственное Chrome расширение, с возможностью суммаризации, работы с вкладками, или просто чат с ИИ прямо в браузере
  - Полноценная поддержка MCP
  - Возможность создания панелей, в которых можно хранить любую информацию
  - Поддержка скиллов
  - Широкая система планирования: можно запускать действия в определённое время, при каких-то событиях или с особыми условиями

### Глубокая настройка
  - Возможность создания своих системных промптов или редактирование имеющихся
  - Практически любую функцию можно отключить или включить, по желанию пользователя

### Мемесы, профили и память
  - Можно создавать свои собственные профили и устанавливать на них пароль
  - У каждого профиля есть своя память, которую собирает ИИ - это можно отключить.
  - Мемесы: собственные ИИ-агенты, которым можно дать инструкцию, ограничить инструменты и многое остальное

### Дизайн и внешний вид
  - По умолчанию доступно более 8 дизайнов интерфейса, 12 акцентных цветов а также, конечно, светлая и тёмная тема
  - У светлой и тёмной темы есть вариации: Графит, Сумерки, Полночь, Чёрная OLED и так далее
  - Редактор тем: можно редактировать элементы в MemuAI как угодно, через отдельный редактор. Доступно множество инструментов для изменения различных параметров.
  - Можно создавать полностью свои кастомные темы, и делиться ими в виде .css файла

### Доступ везде через Telegram
  - Можно подключить Telegram-бота, и тем самым общаться с ИИ прямо через Telegram
  - Поддержка Mini App: можно пользоваться всеми основными функциями прямо через Telegram с приятным интерфейсом. Mini App можно использовать через Cloudflare Tunnel, но и можно использовать свой туннель и адрес

### Быстрый доступ и Live
  - Обратиться к ИИ можно в абсолютно любое время нажатием комбинации клавиш
  - ИИ может работать с файлами, экраном, отвечать на вопросы, а также можно создавать абсолютно любые команды или кнопки для любых событий
  - Live: общение с ИИ в реальном времени. Можно подключить как и Live-модель (например Gemini Live), так и использовать отдельные модели для распознания и озвучки текста. Скачивание локальных моделей доступно прямиком в MemuAI, также есть поддержка API.
  - ИИ Live2D компаньон, которого можно подключить как и для быстрого доступа, так и для режима Live

### Do For You и прочие мелкие функции
  - Do For You (DFY) - имеет собственный браузер, в котором может выполнять любые действия пользователя - логиниться на сайты и заказывать что-либо, просматривать информацию, мониторить и так далее. Все данные передаются через особую защищённую форму - ни ИИ, ни MemuAI не имеют к ним доступ. DFY можно подключить к отдельной машине, тем самым у DFY появится возможность редактировать файлы, либо же можно подключить его к вашему браузеру через расширение.
  - Ссылки и команда (memuai://, memu) - возможность управлять MemuAI через сторонние приложения
  - Browser: ИИ имеет встроенный браузер для проверки работоспособности сайта и многого остального
  - Computer Use: ИИ может управлять компьютером в режиме реального времени
  - Поддержка кастомной модели для распознавания изображений и видео. Если модель в API не умеет распознавать изображения или видео, то можно подключить другую модель, которая уже умеет подобное, и эта модель не заменит первую - она лишь поможет первой модели в распознавании
  - Импорт и экспорт данных: можно импортировать любой чат или просто информацию о себе из MemuAi, а также можно загрузить импорт данных из другого ИИ-сервиса (ChatGPT, Gemini, Claude, ...) для того, чтобы у ИИ была информация о вас
  - Для абсолютно всех функций есть документация, где подробно расписано обо всём

### Модули
  - Можно создавать свои приложения внутри MemuAI, и устанавливать их как отдельные приложения. Модули используют обращения к MemuAI, сами они создаются через HTML + CSS + JS + манифест
  - По умолчанию, доступно 9 модулей:
    - Переводчик: простой перевод текста с глоссарием
    - MemuAI Studio: модуль для создания видео, музыки, озвучки и расшифровки
    - MemuAI Design: модуль для дизайна сайтов и приложений
    - Бенчмарки: сбор всех основных бенчмарков (arena.ai, Artifical Analysis, LiveBench, SimpleBench, EQ-Bench и остальных), а также собственный бенчмарк MemuAI Index
    - Каталог моделей: список всех ИИ-моделей, берутся из Openrouter
    - Новые модели API: уведомления о выходе новых моделей через тот же Openrouter, также есть поддержка OpenAI API, Gemini API, Anthropic API, xAI API, Mistral API, Groq API, DeepSeek API и многих остальных
    - Персонажи: аналог character.ai и в первую очередь SillyTavern, с возможность импортирования ботов в формате PNG и JSON, поддержкой лорбуков, красивым интерфейсом и удобной настройкой
    - MemuMusic: единственный модуль, не содержащее ИИ-функции: это отдельное приложение для музыки, с приятным интерфейсом, возможностью добавлять собственные треки из YouTube и Soundcloud, либо же просто файлами, а также синхронизацией с Telegram Mini App
    - Абсолютно каждый пользователь может создавать свои модули и делиться с остальными

### MemuAI Work
  - Часть MemuAI, созданная для работы с файлами, документами и так далее
  - Может редактировать файлы, работать с крупными документами и остальными проектами

### MemuCode (устарело)
  - Часть MemuAI, созданная для кодинга
  - Ныне особо не развивается, рекомендуется использовать MemuCode CLI.

## MemuCode CLI
**Редактор кода в терминале, во многом схожий на Claude Code, для использования - нужно лишь написать memucode в командной строке**

- Поддерживает более 60 различных команд
- Встроенная поддержка Decisions моделей: модель может решать то, какую основную модель использовать в настоящий момент, подтверждать команды и многое остальное
- Оптимизация контекста: при достижении большого кол-ва токенов, контекст автоматически сжимается, обеспечивая бесперебойную работу

## MemuNote
**Приложение для работы с документами с поддержкой ИИ**

- Работает значительно быстрее блокнота Windows, Notion и остальных, впрочем скорость всё ещё хуже чем у Notepad++ и, вероятно, Obsidian
- Можно редактировать код, с авто-заполнениями и возможность запуска кода, например Python-скриптов, прямо в приложении
- Поддержка практически всех видов файлов, от .txt и .md до .word и остальных, со всеми настройками форматирования. Также, есть поддержка презентаций
- Поддержка изображений: с помощью MemuNote можно открыть любое изображение, и редактировать его либо с помощью ИИ, либо самостоятельно: в MemuNote есть большая часть основного функционала, хотя множество функций отсутствует
- ИИ-ассистент: можно спрашивать ИИ обо всём, просить помощи, оформить документ и многое остальное

## MemuFiles
**Простой, удобный и быстрый аналог официального проводника Windows**

- Можно установить как проводник по умолчанию (на свой страх и риск, но это всегда можно отменить)
- Система вкладок, приятный и настраиваемый дизайн, а также большое кол-во инструментов
- Работает гораздо быстрее проводника Windows, особенно в Windows 11, иногда даже в разы
- Удобный предпросмотр абсолютно любых файлов
- ИИ-ассистент для работы с файлами: может удалять, сортировать, и просто давать информацию по любым файлам и папкам, всё безопасно и делается лишь через подтверждение пользователя
- Множество других удобных функций для повседневной жизни

Перечислена большая часть функционала, но ещё точно не всё. Подробнее можно узнать [скачав сборку](https://github.com/MemuAI/MemuAI/releases) или самостоятельно изучив код. Также, в MemuAI есть встроенная документация: в ней удобно и понятно расписаны все функции.

## Установка

MemuAI рассчитан на **64-битные Windows 10 и Windows 11**. Для интерфейса нужен **Microsoft Edge WebView2 Runtime**. Локальным моделям потребуется дополнительное место на диске и подходящее оборудование.

1. Откройте [Releases](https://github.com/MemuAI/MemuAI/releases) и скачайте установщик `MemuAI-Setup-<версия>.exe`, если сборка уже опубликована.
2. Установите нужные компоненты и запустите MemuAI.
3. Откройте MemuAI Proxy и добавьте аккаунт, свой API или локальную модель.
4. Вернитесь в MemuAI, выберите модель и начните разговор.

### Автообновления

MemuAI проверяет новые версии в GitHub Releases при запуске и каждые 15 минут. Обновление скачивается в фоне; когда оно готово, рядом со статусом Proxy появляется синяя кнопка установки. После вашего подтверждения MemuAI закрывается и открывает установщик.

Управление находится в **Настройки → О программе → Обновления**. Автоматическую проверку можно выключить; кнопка «Проверить» работает и при выключенной автоматической проверке. Ошибки соединения и скачивания показываются отдельно от сообщения об актуальной версии.

## Откуда берутся модели

MemuAI работает с вашими подключениями. В проекте есть поддержка Antigravity, Kiro, Gemini Web, Genspark, Grok, собственных API и локальных моделей. Для многих API-сервисов предусмотрены готовые настройки подключения.

Можно использовать свои ключи, аккаунты или модели на компьютере. MemuAI не предоставляет подписки на сторонние сервисы: доступность моделей, стоимость и квоты зависят от вашего подключения. Некоторые интеграции используют неофициальные интерфейсы сервисов и могут потребовать обновления, если сервис изменит свою работу.

Proxy умеет обновлять каталог моделей, показывать статистику запросов и учитывать собственные цены. В планировщике квот можно задать баланс API-аккаунта и следить за примерным расходом.

## Где хранятся данные

Чаты, настройки и данные основного комплекта сохраняются локально, обычно в `%APPDATA%\MemuAI`. При обращении к облачной модели текст запроса и выбранные для него материалы передаются соответствующему провайдеру. Локальные модели позволяют обрабатывать запросы на своём компьютере; веб-поиск и внешние интеграции по-прежнему используют интернет.

## Запуск из исходников

Нужны Git, 64-битный Python и WebView2 Runtime. Команды ниже рассчитаны на PowerShell в Windows.

```powershell
git clone https://github.com/MemuAI/MemuAI.git
cd MemuAI
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запустите Proxy:

```powershell
.\.venv\Scripts\python.exe main.py
```

В другом терминале, из той же папки, запустите MemuAI:

```powershell
.\.venv\Scripts\python.exe memuai.py
```

Для MemuCode CLI:

```powershell
.\.venv\Scripts\python.exe memucode.py
```

Сборка установщика запускается через `build_installer.bat`, а сборка отдельного Proxy — через `build_proxy_installer.bat`.

OAuth-реквизиты не включены в публичный исходный код. Если нужное подключение требует OAuth-клиента, сначала прочитайте [инструкцию по настройке](OAUTH_SETUP.md).

### Публикация обновления

Чтобы пользователи получили новую версию, измените `APP_VERSION` и `RELEASE_DATE` в `app/version.py`, соберите установщик и опубликуйте обычный GitHub Release с тегом версии, например `v3.8.1`. Прикрепите полный установщик `MemuAI-Setup-3.8.1.exe` к этому релизу. Номер в теге, исходниках и имени установщика должен совпадать и быть выше предыдущего. Исходники или установщик одного Proxy не заменяют полный установщик; черновики и предварительные релизы не предлагаются для автообновления. Для каждой новой версии создавайте новый релиз.

## Ошибки и предложения

Если что-то не работает, создайте [Issue](https://github.com/MemuAI/MemuAI/issues). Полезнее всего указать версию MemuAI, приложение или раздел, шаги до ошибки и то, что должно было произойти. Скриншот и текст ошибки тоже помогут — только уберите из них ключи, токены и личную переписку.

Предложения по удобству тоже приветствуются. Особенно полезны конкретные примеры: что вы пытались сделать, на каком шаге возникла проблема и как этот сценарий мог бы работать лучше.
